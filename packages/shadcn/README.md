# FarsiUI

[Website](https://farsiui.ir) · [Documentation](https://farsiui.ir/docs) · [GitHub](https://github.com/MiladJoodi/FarsiUI)

**A UI component library made for Persian products.**

FarsiUI is built around the parts of a Persian interface that don't fit neatly into an English-first UI: RTL layouts, Persian typography, Jalali dates, Persian content, and the small details that shape the experience.

Components are designed to be added to your project, owned by your codebase, and customized without being locked into a separate UI runtime.

### Built for Persian

* RTL-first components
* Persian typography and content
* Jalali calendar and date support
* Persian-oriented UI patterns
* Customizable design tokens
* MCP support

FarsiUI is based on the shadcn/ui ecosystem, with the interface and tooling adapted for Persian-first development.
