# Sponsor logos

Put sponsor logo files here. Paths are referenced from `apps/v4/sponsors/data.ts`.

## Current slots

| File | Theme | Used by |
| --- | --- | --- |
| `paasta-light.png` | light | Paasta (`logoSrc`) |
| `paasta-dark.png` | dark | Paasta (`logoSrcDark`) |

Preferred: PNG/SVG with transparent background, roughly 240×64 (wide wordmark).
For dual-theme logos, set both `logoSrc` and `logoSrcDark` in `apps/v4/sponsors/data.ts`.
