This directory contains the generated styles for the v4 registry. It is
autogenerated by the registry build process and gitignored — only this
README is tracked.

**Needs [Bun](https://bun.sh) on PATH.** Windows (once):

```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```

Then close and reopen the terminal.

On a fresh clone, from repo root:

```bash
pnpm --filter=v4 registry:build
```

Or from `apps/v4`:

```bash
pnpm registry:build
```

Use a **full** `registry:build` (no `--style` flag).  
`pnpm registry:build --style all` only builds public deploy styles and is **not** enough for local docs (`base-rhea`, `aria-rhea`, …).
