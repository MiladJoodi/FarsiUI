## رویکرد

این فرم از Formisch برای مدیریت فرم به‌صورت Headless و Schema-first استفاده می‌کند. فرم را با کامپوننت **`<Field />`** می‌سازیم که آزادی کاملی برای کنترل Markup و Styling در اختیار شما قرار می‌دهد.

- استفاده از Hook **`useForm`** در Formisch برای مدیریت وضعیت فرم.
- استفاده از کامپوننت **`<Form />`** برای قرار دادن منطق ارسال روی عنصر native **`<form>`**.
- استفاده از کامپوننت **`<Field />`** مبتنی بر Render Prop برای ورودی‌های Controlled.
- اعتبارسنجی Schema با استفاده از [**Valibot**](https://valibot.dev/).
- استنتاج Type-safe مسیر فیلدها مستقیماً از Schema.

## متدهای فرم

Formisch عملیات فرم را به‌صورت **توابع سطح بالا** ارائه می‌کند، نه متدهای یک Object مربوط به فرم. فقط توابع موردنیاز خود را Import کنید:

```ts
import { getInput, insert, reset, submit } from "@formisch/react"
```

همهٔ این توابع Signature یکسانی دارند: **پارامتر اول همیشه Store فرم** و **پارامتر دوم، در صورت نیاز، یک Object تنظیمات** است.

```ts
// خواندن مقدار یک فیلد
const email = getInput(form, { path: ["email"] })

// بازنشانی فرم با مقادیر اولیهٔ جدید
reset(form, { initialInput: { email: "", password: "" } })

// جابه‌جایی یک آیتم در آرایهٔ فیلد
move(form, { path: ["items"], from: 0, to: 3 })
```

این ساختار باعث می‌شود API در تمام توابع انعطاف‌پذیر و یکدست باقی بماند. در ادامه همین الگوی **`(form, config)`** را در بخش‌های مختلف می‌بینید؛ از خواندن وضعیت فرم (**`getInput`**، **`getErrors`**) و تغییر وضعیت (**`setInput`**، **`setErrors`**) گرفته تا کنترل فرم (**`submit`**، **`validate`**، **`focus`**) و عملیات آرایه (**`insert`**، **`remove`**، **`move`**، **`swap`**، **`replace`**).

برای جزئیات بیشتر، [**مرجع کامل متدها**](https://formisch.dev/react/guides/form-methods) را ببینید.

## ساختار

در اینجا یک نمونهٔ ساده از فرمی را می‌بینید که از **`<Field />`** در Formisch و **`<Field />`** در FarsiUI استفاده می‌کند.

```tsx showLineNumbers {3-21}
<Form of={form} onSubmit={handleSubmit}>
  <FieldGroup>
    <FormischField of={form} path={["title"]}>
      {(field) => (
        <Field data-invalid={field.errors !== null}>
          <FieldLabel htmlFor="form-title">عنوان باگ</FieldLabel>
          <Input
            {...field.props}
            id="form-title"
            value={field.input}
            aria-invalid={field.errors !== null}
            placeholder="دکمهٔ ورود در موبایل کار نمی‌کند"
            autoComplete="off"
          />
          <FieldDescription>
            یک عنوان کوتاه برای گزارش باگ بنویسید.
          </FieldDescription>
          {field.errors && (
            <FieldError errors={field.errors.map((message) => ({ message }))} />
          )}
        </Field>
      )}
    </FormischField>
  </FieldGroup>
</Form>
```

## فرم

### ساخت Schema فرم

ابتدا ساختار فرم را با یک Schema از Valibot تعریف می‌کنیم. Formisch تمام Typeهای ورودی و خروجی را مستقیماً از همین Schema استنتاج می‌کند.

```tsx showLineNumbers title="form.tsx"
import * as v from "valibot"

const FormSchema = v.object({
  title: v.pipe(
    v.string(),
    v.minLength(5, "عنوان باگ باید حداقل ۵ کاراکتر باشد."),
    v.maxLength(32, "عنوان باگ باید حداکثر ۳۲ کاراکتر باشد.")
  ),
  description: v.pipe(
    v.string(),
    v.minLength(20, "توضیحات باید حداقل ۲۰ کاراکتر باشد."),
    v.maxLength(100, "توضیحات باید حداکثر ۱۰۰ کاراکتر باشد.")
  ),
})
```

### راه‌اندازی فرم

در مرحلهٔ بعد از Hook **`useForm`** در Formisch برای ساخت Instance فرم استفاده می‌کنیم. Schema مستقیماً به **`useForm`** داده می‌شود و نیازی به Resolver جداگانه نیست.

```tsx showLineNumbers title="form.tsx" {1-2,21-25}
import { Form, Field as FormischField, useForm } from "@formisch/react"
import type { SubmitHandler } from "@formisch/react"
import * as v from "valibot"

const FormSchema = v.object({
  title: v.pipe(
    v.string(),
    v.minLength(5, "عنوان باگ باید حداقل ۵ کاراکتر باشد."),
    v.maxLength(32, "عنوان باگ باید حداکثر ۳۲ کاراکتر باشد.")
  ),
  description: v.pipe(
    v.string(),
    v.minLength(20, "توضیحات باید حداقل ۲۰ کاراکتر باشد."),
    v.maxLength(100, "توضیحات باید حداکثر ۱۰۰ کاراکتر باشد.")
  ),
})

export function BugReportForm() {
  const form = useForm({
    schema: FormSchema,
    initialInput: {
      title: "",
      description: "",
    },
  })

  const handleSubmit: SubmitHandler<typeof FormSchema> = (output) => {
    // با مقادیر اعتبارسنجی‌شدهٔ فرم کاری انجام دهید.
    console.log(output)
  }

  return (
    <Form of={form} onSubmit={handleSubmit}>
      {/* ... */}
      {/* فرم را اینجا بسازید */}
      {/* ... */}
    </Form>
  )
}
```

کامپوننت **`<Form />`** یک عنصر native **`<form>`** را Wrap می‌کند، **`event.preventDefault()`** را اجرا می‌کند، اعتبارسنجی را انجام می‌دهد و فقط در صورت معتبر بودن داده‌ها، **`onSubmit`** را فراخوانی می‌کند. مقدار **`output`** نیز Type خود را مستقیماً از Schema دریافت می‌کند.

### تمام شد

همین! حالا یک فرم کاملاً دسترس‌پذیر با اعتبارسنجی سمت Client دارید.

هنگام ارسال فرم، تابع **`handleSubmit`** با داده‌های اعتبارسنجی‌شدهٔ فرم اجرا می‌شود. اگر داده‌های فرم معتبر نباشند، Formisch مقدار **`field.errors`** را برای هر فیلد نامعتبر پر می‌کند و خطاها در رابط کاربری نمایش داده می‌شوند.

## اعتبارسنجی

### اعتبارسنجی سمت Client

Formisch داده‌های فرم را با استفاده از Schema مربوط به Valibot که به **`useForm`** داده‌اید اعتبارسنجی می‌کند. در اینجا Resolver وجود ندارد؛ Schema تنها منبع حقیقت برای اعتبارسنجی در زمان اجرا و Typeهای استاتیک است.

```tsx showLineNumbers title="form.tsx" {1,3-6,11}
import { useForm } from "@formisch/react"

const FormSchema = v.object({
  title: v.string(),
  description: v.optional(v.string()),
})

export function ExampleForm() {
  const form = useForm({
    schema: FormSchema,
    initialInput: {
      title: "",
      description: "",
    },
  })
}
```

### حالت‌های اعتبارسنجی

Formisch اعتبارسنجی **اولیه** را از اعتبارسنجی‌های **بعدی** جدا می‌کند. این رفتار با Options **`validate`** و **`revalidate`** در **`useForm`** تنظیم می‌شود.

```tsx showLineNumbers title="form.tsx" {3-4}
const form = useForm({
  schema: FormSchema,
  validate: "blur",
  revalidate: "input",
})
```

| Option           | مقدار           | توضیحات                                                                           |
| ---------------- | --------------- | --------------------------------------------------------------------------------- |
| **`validate`**   | **`"submit"`**  | اعتبارسنجی هنگام ارسال فرم. حالت پیش‌فرض.                                         |
| **`validate`**   | **`"blur"`**    | اعتبارسنجی هنگام خارج شدن Focus از فیلد.                                          |
| **`validate`**   | **`"input"`**   | اعتبارسنجی با هر تغییر ورودی.                                                     |
| **`validate`**   | **`"initial"`** | اعتبارسنجی بلافاصله هنگام ایجاد فرم.                                              |
| **`revalidate`** | **`"input"`**   | پس از اولین اعتبارسنجی، با هر تغییر ورودی دوباره اعتبارسنجی می‌شود. حالت پیش‌فرض. |
| **`revalidate`** | **`"blur"`**    | پس از اولین اعتبارسنجی، هنگام Blur دوباره اعتبارسنجی می‌شود.                      |
| **`revalidate`** | **`"submit"`**  | فقط هنگام ارسال فرم دوباره اعتبارسنجی می‌شود.                                     |

## نمایش خطاها

برای نمایش خطا در کنار فیلد از **`<FieldError />`** استفاده کنید. Formisch خطاها را به‌صورت آرایه‌ای از Stringها برمی‌گرداند؛ بنابراین باید آن‌ها را به ساختاری که **`<FieldError />`** انتظار دارد تبدیل کنید.

برای Styling و دسترس‌پذیری:

- Prop **`data-invalid`** را به **`<Field />`** اضافه کنید.
- Prop **`aria-invalid`** را به کنترل فرم، مانند **`<Input />`**، **`<SelectTrigger />`**، **`<Checkbox />`** و موارد مشابه اضافه کنید.

```tsx showLineNumbers title="form.tsx" {3,10,12-14}
<FormischField of={form} path={["email"]}>
  {(field) => (
    <Field data-invalid={field.errors !== null}>
      <FieldLabel htmlFor="form-email">ایمیل</FieldLabel>
      <Input
        {...field.props}
        id="form-email"
        value={field.input}
        type="email"
        aria-invalid={field.errors !== null}
      />
      {field.errors && (
        <FieldError errors={field.errors.map((message) => ({ message }))} />
      )}
    </Field>
  )}
</FormischField>
```

## کار با انواع مختلف فیلدها

Formisch دو روش برای اتصال یک فیلد به یک عنصر ارائه می‌دهد:

- **عناصر Native HTML** مانند **`<Input />`** و **`<Textarea />`**: مقدار **`field.props`** را Spread کنید و **`value={field.input}`** را قرار دهید. Formisch مواردی مانند **`name`**، **`ref`**، **`onChange`**، **`onBlur`** و **`onFocus`** را به‌صورت خودکار مدیریت می‌کند.
- **ورودی‌های کتابخانه‌های کامپوننتی** مانند **`<Select />`**، **`<Checkbox />`**، **`<RadioGroup />`** و **`<Switch />`** مبتنی بر Radix: مقدار را از **`field.input`** بخوانید و برای به‌روزرسانی آن، **`field.onChange(value)`** را فراخوانی کنید.

### Input

- برای فیلدهای Input، مقدار **`field.props`** را Spread کنید و **`value={field.input}`** را قرار دهید.
- برای نمایش خطا، Prop **`aria-invalid`** را به **`<Input />`** و Prop **`data-invalid`** را به **`<Field />`** اضافه کنید.

```tsx showLineNumbers title="form.tsx" {9-13,21}
        ))}
      </RadioGroup>
      {field.errors && (
        <FieldError errors={field.errors.map((message) => ({ message }))} />
      )}
    </FieldSet>
  )}
</FormischField>
```

- برای نمایش خطا، Prop **`aria-invalid`** را به کامپوننت **`<Switch />`** و Prop **`data-invalid`** را به **`<Field />`** اضافه کنید.

## بازنشانی فرم

Formisch یک تابع سطح‌بالای **`reset`** در اختیار شما قرار می‌دهد. با ارسال Store فرم به این تابع، فرم به مقادیر اولیه بازنشانی می‌شود.

```tsx showLineNumbers
<Button type="button" variant="outline" onClick={() => reset(form)}>
  بازنشانی
</Button>
```

همچنین می‌توانید مقادیر اولیهٔ جدیدی تعیین کنید یا فرم را طوری بازنشانی کنید که ورودی فعلی کاربر حفظ شود:

```tsx showLineNumbers
// بازنشانی با مجموعه‌ای جدید از مقادیر اولیه
reset(form, {
  initialInput: { title: "", description: "" },
})

// همگام‌سازی مقدار پایه با داده‌های جدید سرور و حفظ تغییرات کاربر
reset(form, {
  initialInput: serverData,
  keepInput: true,
})
```

### استفاده از FieldArray

**`<FieldArray />`** مانند **`<Field />`** از الگوی Render Prop استفاده می‌کند. آرایهٔ **`items`** برای هر آیتم یک Key پایدار دارد که باید از آن به‌عنوان **`key`** در React استفاده کنید.

```tsx showLineNumbers title="form.tsx" {1,7-22}
import {
  Field as FormischField,
  FieldArray,
  insert,
  remove,
} from "@formisch/react"

export function ExampleForm() {

  return (
    <FieldArray of={form} path={["emails"]}>
      {(fieldArray) => (
        <FieldGroup className="gap-4">

            <FormischField
              key={item}
              of={form}
              path={["emails", index, "address"]}
            >
              {(field) => /* ... */}
            </FormischField>
          ))}
        </FieldGroup>
      )}
    </FieldArray>
```

### افزودن آیتم

برای اضافه کردن آیتم جدید به آرایه از تابع **`insert`** استفاده کنید. به‌صورت پیش‌فرض آیتم جدید به انتهای آرایه اضافه می‌شود. همچنین می‌توانید با تعیین **`at`**، محل قرارگیری آیتم را مشخص کنید.

```tsx showLineNumbers title="form.tsx"
<Button
  type="button"
  variant="outline"
  size="sm"
  onClick={() =>
    insert(form, { path: ["emails"], initialInput: { address: "" } })
  }
  disabled={fieldArray.items.length >= 5}
>
  افزودن آدرس ایمیل
</Button>
```

### حذف آیتم

برای حذف یک آیتم از تابع **`remove`** همراه با **`at`** استفاده کنید.

```tsx showLineNumbers title="form.tsx"
import { remove } from "@formisch/react"

{
  fieldArray.items.length > 1 && (
    <InputGroupAddon align="inline-end">
      <InputGroupButton
        type="button"
        variant="ghost"
        size="icon-xs"
        onClick={() => remove(form, { path: ["emails"], at: index })}
        aria-label={`حذف ایمیل ${index + 1}`}
      >
        <XIcon />
      </InputGroupButton>
    </InputGroupAddon>
  )
}
```

Formisch همچنین توابع **`move`**، **`swap`** و **`replace`** را برای جابه‌جایی و جایگزینی آیتم‌ها ارائه می‌دهد. این توابع نیز از همان الگوی **`(form, config)`** استفاده می‌کنند.

### اعتبارسنجی آرایه

برای محدود کردن فیلدهای آرایه‌ای، از Validatorهای **`array`** و Pipelineهای اعتبارسنجی Valibot استفاده کنید.

```tsx showLineNumbers title="form.tsx"
const FormSchema = v.object({
  emails: v.pipe(
    v.array(
      v.object({
        address: v.pipe(
          v.string(),
          v.nonEmpty("یک آدرس ایمیل وارد کنید."),
          v.email("یک آدرس ایمیل معتبر وارد کنید.")
        ),
      })
    ),
    v.minLength(1, "حداقل یک آدرس ایمیل اضافه کنید."),
    v.maxLength(5, "حداکثر ۵ آدرس ایمیل می‌توانید اضافه کنید.")
  ),
})
```
