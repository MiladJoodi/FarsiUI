## رویکرد

این فرم از TanStack Form برای مدیریت قدرتمند و Headless فرم استفاده می‌کند. فرم را با کامپوننت **`<Field />`** می‌سازیم تا کنترل کاملی روی Markup و Styling داشته باشیم.

- استفاده از Hook **`useForm`** در TanStack Form برای مدیریت وضعیت فرم.
- استفاده از کامپوننت **`form.Field`** با الگوی Render Prop برای ورودی‌های Controlled.
- استفاده از کامپوننت‌های **`<Field />`** برای ساخت فرم‌های دسترس‌پذیر.
- اعتبارسنجی سمت Client با Zod.
- نمایش لحظه‌ای وضعیت اعتبارسنجی.

## ساختار

در مثال پایه، از TanStack Form و کامپوننت **`<Field />`** برای ساخت فرم استفاده می‌کنیم.

```tsx showLineNumbers {15-31}
<form
  onSubmit={(e) => {
    e.preventDefault()
    form.handleSubmit()
  }}
>
  <FieldGroup>
    <form.Field
      name="title"
      children={(field) => {
        const isInvalid =
          field.state.meta.isTouched && !field.state.meta.isValid
        return (
          <Field data-invalid={isInvalid}>
            <FieldLabel htmlFor={field.name}>عنوان باگ</FieldLabel>
            <Input
              id={field.name}
              name={field.name}
              value={field.state.value}
              onBlur={field.handleBlur}
              onChange={(e) => field.handleChange(e.target.value)}
              aria-invalid={isInvalid}
              placeholder="دکمهٔ ورود در موبایل کار نمی‌کند"
              autoComplete="off"
            />
            <FieldDescription>
              عنوانی کوتاه و واضح برای باگ وارد کنید.
            </FieldDescription>
            {isInvalid && <FieldError errors={field.state.meta.errors} />}
          </Field>
        )
      }}
    />
  </FieldGroup>
  <Button type="submit">ارسال</Button>
</form>
```

## فرم

### ساخت Schema

ابتدا ساختار فرم را با یک Schema از Zod تعریف می‌کنیم.

<Callout icon={<InfoIcon />}>
  **نکته:** این مثال از **`zod v3`** برای اعتبارسنجی Schema استفاده می‌کند.
  TanStack Form از Zod و سایر کتابخانه‌های اعتبارسنجی مبتنی بر Standard Schema از
  طریق API مربوط به Validatorها پشتیبانی می‌کند.
</Callout>

```tsx showLineNumbers title="form.tsx"
import * as z from "zod"

const formSchema = z.object({
  title: z
    .string()
    .min(5, "عنوان باگ باید حداقل ۵ کاراکتر باشد.")
    .max(32, "عنوان باگ باید حداکثر ۳۲ کاراکتر باشد."),
  description: z
    .string()
    .min(20, "توضیحات باید حداقل ۲۰ کاراکتر باشد.")
    .max(100, "توضیحات باید حداکثر ۱۰۰ کاراکتر باشد."),
})
```

### راه‌اندازی فرم

برای ساخت نمونهٔ فرم همراه با اعتبارسنجی Zod از Hook **`useForm`** در TanStack Form استفاده کنید.

```tsx showLineNumbers title="form.tsx" {10-21}
import { useForm } from "@tanstack/react-form"
import { toast } from "sonner"
import * as z from "zod"

const formSchema = z.object({
  // ...
})

export function BugReportForm() {
  const form = useForm({
    defaultValues: {
      title: "",
      description: "",
    },
    validators: {
      onSubmit: formSchema,
    },
    onSubmit: async ({ value }) => {
      toast.success("فرم با موفقیت ارسال شد")
    },
  })

  return (
    <form
      onSubmit={(e) => {
        e.preventDefault()
        form.handleSubmit()
      }}
    >
      {/* ... */}
    </form>
  )
}
```

در اینجا از **`onSubmit`** برای اعتبارسنجی داده‌های فرم استفاده می‌کنیم. TanStack Form از حالت‌های اعتبارسنجی دیگری نیز پشتیبانی می‌کند که می‌توانید آن‌ها را در [مستندات](https://tanstack.com/form/latest/docs/framework/react/guides/dynamic-validation) مطالعه کنید.

### تمام شد

تمام شد. حالا یک فرم کاملاً دسترس‌پذیر با اعتبارسنجی سمت Client دارید.

هنگام ارسال فرم، تابع **`onSubmit`** با داده‌های اعتبارسنجی‌شدهٔ فرم اجرا می‌شود. اگر داده‌ها معتبر نباشند، TanStack Form خطاها را در کنار فیلد مربوطه نمایش می‌دهد.

## اعتبارسنجی

### اعتبارسنجی سمت Client

TanStack Form با استفاده از Schema تعریف‌شده در Zod، داده‌های فرم را اعتبارسنجی می‌کند. اعتبارسنجی می‌تواند هم‌زمان با وارد کردن اطلاعات توسط کاربر انجام شود.

```tsx showLineNumbers title="form.tsx" {13-15}
import { useForm } from "@tanstack/react-form"

const formSchema = z.object({
  // ...
})

export function BugReportForm() {
  const form = useForm({
    defaultValues: {
      title: "",
      description: "",
    },
    validators: {
      onSubmit: formSchema,
    },
    onSubmit: async ({ value }) => {
      console.log(value)
    },
  })

  return <form onSubmit={/* ... */}>{/* ... */}</form>
}
```

### حالت‌های اعتبارسنجی

TanStack Form از طریق گزینهٔ **`validators`** از استراتژی‌های مختلف اعتبارسنجی پشتیبانی می‌کند:

| **حالت**         | **توضیحات**                                           |
| ---------------- | ----------------------------------------------------- |
| **`"onChange"`** | اعتبارسنجی با هر تغییر مقدار انجام می‌شود.            |
| **`"onBlur"`**   | اعتبارسنجی هنگام خارج شدن Focus از فیلد انجام می‌شود. |
| **`"onSubmit"`** | اعتبارسنجی هنگام ارسال فرم انجام می‌شود.              |

```tsx showLineNumbers title="form.tsx" {6-9}
const form = useForm({
  defaultValues: {
    title: "",
    description: "",
  },
  validators: {
    onSubmit: formSchema,
    onChange: formSchema,
    onBlur: formSchema,
  },
})
```

## نمایش خطاها

برای نمایش خطا در کنار فیلد از **`<FieldError />`** استفاده کنید. برای Styling و دسترس‌پذیری:

- Prop **`data-invalid`** را به کامپوننت **`<Field />`** اضافه کنید.
- Prop **`aria-invalid`** را به کنترل فرم، مانند **`<Input />`**، **`<SelectTrigger />`**، **`<Checkbox />`** و موارد مشابه اضافه کنید.

```tsx showLineNumbers title="form.tsx" {4,18}
<form.Field
  name="email"
  children={(field) => {
    const isInvalid = field.state.meta.isTouched && !field.state.meta.isValid

    return (
      <Field data-invalid={isInvalid}>
        <FieldLabel htmlFor={field.name}>ایمیل</FieldLabel>
        <Input
          id={field.name}
          name={field.name}
          value={field.state.value}
          onBlur={field.handleBlur}
          onChange={(e) => field.handleChange(e.target.value)}
          type="email"
          aria-invalid={isInvalid}
        />
        {isInvalid && <FieldError errors={field.state.meta.errors} />}
      </Field>
    )
  }}
/>
```

### Checkbox

- برای Checkbox از **`field.state.value`** و **`field.handleChange`** در کامپوننت **`<Checkbox />`** استفاده کنید.
- برای نمایش خطا، Prop **`aria-invalid`** را به **`<Checkbox />`** و Prop **`data-invalid`** را به **`<Field />`** اضافه کنید.
- برای آرایه‌ای از Checkboxها، از **`mode="array"`** در کامپوننت **`<form.Field />`** و Helperهای آرایه‌ای TanStack Form استفاده کنید.
- برای اعمال صحیح Styling و فاصله‌گذاری، حتماً **`data-slot="checkbox-group"`** را به کامپوننت **`<FieldGroup />`** اضافه کنید.

```tsx showLineNumbers title="form.tsx" {12,17,22-24,44}
<form.Field
  name="tasks"
  mode="array"
  children={(field) => {
    const isInvalid =
      field.state.meta.isTouched && !field.state.meta.isValid

    return (
      <FieldSet>
        <FieldLegend variant="label">وظایف</FieldLegend>
        <FieldDescription>
          برای به‌روزرسانی وظایفی که ایجاد کرده‌اید، اعلان دریافت کنید.
        </FieldDescription>
        <FieldGroup data-slot="checkbox-group">
          {tasks.map((task) => (
            <Field
              key={task.id}
              orientation="horizontal"
              data-invalid={isInvalid}
            >
              <Checkbox
                id={`form-tanstack-checkbox-${task.id}`}
                name={field.name}
                aria-invalid={isInvalid}
                checked={field.state.value.includes(task.id)}
                onCheckedChange={(checked) => {
                  if (checked) {
                    field.pushValue(task.id)
                  } else {
                    const index = field.state.value.indexOf(task.id)
                    if (index > -1) {
                      field.removeValue(index)
                    }
                  }
                }}
              />
              <FieldLabel
                htmlFor={`form-tanstack-checkbox-${task.id}`}
                className="font-normal"
              >
                {task.label}
              </FieldLabel>
            </Field>
          ))}
        </FieldGroup>
        {isInvalid && <FieldError errors={field.state.meta.errors} />}
      </FieldSet>
    )
  }}
/>
```

## فیلدهای آرایه‌ای

در این مثال نحوهٔ مدیریت چند آدرس ایمیل با استفاده از فیلدهای آرایه‌ای را می‌بینید. کاربر می‌تواند حداکثر ۵ آدرس ایمیل اضافه کند، هر آدرس را به‌صورت جداگانه حذف کند و هر آدرس نیز به‌صورت مستقل اعتبارسنجی می‌شود.

### ساختار فیلدهای آرایه‌ای

برای فعال کردن مدیریت فیلدهای آرایه‌ای، از **`mode="array"`** در فیلد والد استفاده کنید.

```tsx showLineNumbers title="form.tsx" {3,12-14}
<form.Field
  name="emails"
  mode="array"
  children={(field) => {
    return (
      <FieldSet>
        <FieldLegend variant="label">آدرس‌های ایمیل</FieldLegend>
        <FieldDescription>
          حداکثر ۵ آدرس ایمیل اضافه کنید تا بتوانیم با شما در تماس باشیم.
        </FieldDescription>
        <FieldGroup>
          {field.state.value.map((_, index) => (
            // فیلد تو در تو برای هر آیتم آرایه
          ))}
        </FieldGroup>
      </FieldSet>
    )
  }}
/>
```

### فیلدهای تو در تو

برای دسترسی به آیتم‌های آرایه از Notation براکت استفاده کنید: **`fieldName[index].propertyName`**.

در این مثال از **`InputGroup`** برای نمایش دکمهٔ حذف در کنار ورودی استفاده شده است.

```tsx showLineNumbers title="form.tsx"
<form.Field
  name={`emails[${index}].address`}
  children={(subField) => {
    const isSubFieldInvalid =
      subField.state.meta.isTouched && !subField.state.meta.isValid

    return (
      <Field orientation="horizontal" data-invalid={isSubFieldInvalid}>
        <FieldContent>
          <InputGroup>
            <InputGroupInput
              id={`form-tanstack-array-email-${index}`}
              name={subField.name}
              value={subField.state.value}
              onBlur={subField.handleBlur}
              onChange={(e) => subField.handleChange(e.target.value)}
              aria-invalid={isSubFieldInvalid}
              placeholder="ali@example.com"
              type="email"
            />
            {field.state.value.length > 1 && (
              <InputGroupAddon align="inline-end">
                <InputGroupButton
                  type="button"
                  variant="ghost"
                  size="icon-xs"
                  onClick={() => field.removeValue(index)}
                  aria-label={`حذف ایمیل ${index + 1}`}
                >
                  <XIcon />
                </InputGroupButton>
              </InputGroupAddon>
            )}
          </InputGroup>
          {isSubFieldInvalid && (
            <FieldError errors={subField.state.meta.errors} />
          )}
        </FieldContent>
      </Field>
    )
  }}
/>
```

### افزودن آیتم

برای اضافه کردن آیتم به فیلد آرایه‌ای از **`field.pushValue(item)`** استفاده کنید. زمانی که تعداد آیتم‌ها به حداکثر مجاز برسد، می‌توانید دکمه را غیرفعال کنید.

```tsx showLineNumbers title="form.tsx"
<Button
  type="button"
  variant="outline"
  size="sm"
  onClick={() => field.pushValue({ address: "" })}
  disabled={field.state.value.length >= 5}
>
  افزودن آدرس ایمیل
</Button>
```

### حذف آیتم

برای حذف یک آیتم از فیلد آرایه‌ای از **`field.removeValue(index)`** استفاده کنید. می‌توانید دکمهٔ حذف را فقط زمانی نمایش دهید که بیش از یک آیتم وجود داشته باشد.

```tsx showLineNumbers title="form.tsx"
{
  field.state.value.length > 1 && (
    <InputGroupButton
      onClick={() => field.removeValue(index)}
      aria-label={`حذف ایمیل ${index + 1}`}
    >
      <XIcon />
    </InputGroupButton>
  )
}
```

### اعتبارسنجی آرایه

برای اعتبارسنجی فیلدهای آرایه‌ای از متدهای آرایه در Zod استفاده کنید.

```tsx showLineNumbers title="form.tsx"
const formSchema = z.object({
  emails: z
    .array(
      z.object({
        address: z.string().email("یک آدرس ایمیل معتبر وارد کنید."),
      })
    )
    .min(1, "حداقل یک آدرس ایمیل اضافه کنید.")
    .max(5, "حداکثر می‌توانید ۵ آدرس ایمیل اضافه کنید."),
})
```
