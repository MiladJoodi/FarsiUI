کامپوننت `MessageScroller` برای ساخت رابط‌های پیام‌رسان، چت و خروجی‌های Streaming طراحی شده است.

`MessageScroller` در پکیج `@farsiui/react` به‌صورت یک primitive بدون استایل ارائه می‌شود. این primitive مدیریت اسکرول، حفظ موقعیت کاربر هنگام اضافه شدن پیام‌های قدیمی، دنبال کردن خروجی در حال Streaming، لنگر کردن پیام‌ها و تشخیص پیام‌های قابل مشاهده را بر عهده دارد.

ظاهر و استایل کامپوننت را می‌توانید کاملاً مطابق نیاز پروژه خود پیاده‌سازی کنید.

برای راهنمای رفتار و مثال‌های زنده، صفحهٔ [Message Scroller](/docs/components/base/message-scroller) را ببینید.

## نصب

پکیج `@farsiui/react` را نصب کنید:

```bash
pnpm add @farsiui/react
```

## استفاده

```tsx
import {
  MessageScroller,
  useMessageScroller,
  useMessageScrollerScrollable,
  useMessageScrollerVisibility,
} from "@farsiui/react/message-scroller"
```

`MessageScroller` به‌صورت یک namespace ارائه می‌شود و بخش‌های مختلف آن از طریق همین namespace در دسترس هستند.

```tsx
<MessageScroller.Provider>
  <MessageScroller.Root>
    <MessageScroller.Viewport>
      <MessageScroller.Content>
        {messages.map((message) => (
          <MessageScroller.Item
            key={message.id}
            messageId={message.id}
            scrollAnchor={message.role === "user"}
          >
            {/* رابط کاربری پیام */}
          </MessageScroller.Item>
        ))}
      </MessageScroller.Content>
    </MessageScroller.Viewport>

    <MessageScroller.Button />
  </MessageScroller.Root>
</MessageScroller.Provider>
```

## بخش‌ها

اگر قبلاً از نسخهٔ استایل‌دار استفاده کرده‌اید، معادل بخش‌های آن در نسخهٔ بدون استایل به شکل زیر است:

| کامپوننت                  | بخش بدون استایل            |
| ------------------------- | -------------------------- |
| `MessageScrollerProvider` | `MessageScroller.Provider` |
| `MessageScroller`         | `MessageScroller.Root`     |
| `MessageScrollerViewport` | `MessageScroller.Viewport` |
| `MessageScrollerContent`  | `MessageScroller.Content`  |
| `MessageScrollerItem`     | `MessageScroller.Item`     |
| `MessageScrollerButton`   | `MessageScroller.Button`   |

Hookها نیز از همان Provider استفاده می‌کنند:

```tsx
import {
  useMessageScroller,
  useMessageScrollerScrollable,
  useMessageScrollerVisibility,
} from "@farsiui/react/message-scroller"
```

## مثال

در این مثال، `MessageScroller` همراه با AI SDK استفاده شده است:

```tsx showLineNumbers
"use client"

import { useChat } from "@ai-sdk/react"
import { DefaultChatTransport } from "ai"
import { MessageScroller } from "@farsiui/react/message-scroller"

import { ChatInput } from "@/components/chat-input"

export function Chat() {
  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: "/api/chat",
    }),
  })

  return (
    <div className="flex h-svh w-full flex-col">
      <MessageScroller.Provider>
        <MessageScroller.Root className="relative flex flex-1 flex-col overflow-hidden">
          <MessageScroller.Viewport className="flex flex-1 flex-col overflow-y-auto">
            <MessageScroller.Content className="flex flex-col gap-4 p-6 text-base">
              {messages.map((message, index) => (
                <MessageScroller.Item
                  key={message.id}
                  messageId={`message-${index}`}
                  scrollAnchor={message.role === "user"}
                >
                  <div className="rounded-lg bg-muted p-4">
                    {message.parts.map((part, i) =>
                      part.type === "text" ? (
                        <span key={i}>{part.text}</span>
                      ) : null
                    )}
                  </div>
                </MessageScroller.Item>
              ))}
            </MessageScroller.Content>
          </MessageScroller.Viewport>

          <MessageScroller.Button className="absolute bottom-2 left-1/2 z-10 -translate-x-1/2 rounded-full border bg-background px-3 py-1 text-sm font-medium inert:opacity-0">
            رفتن به آخرین پیام
          </MessageScroller.Button>
        </MessageScroller.Root>
      </MessageScroller.Provider>

      <ChatInput
        onSend={sendMessage}
        disabled={status !== "ready"}
      />
    </div>
  )
}
```

## جلوگیری از پرش هنگام بارگذاری مجدد

یک container اسکرول‌شونده در اولین رندر به ابتدای محتوا می‌رود. بنابراین اگر Transcript از سمت سرور رندر شده باشد، ابتدا پیام‌های قدیمی نمایش داده می‌شوند و بعد از اجرای JavaScript، موقعیت اسکرول تغییر می‌کند.

اگر مقدار `defaultScrollPosition` برابر `"end"` یا `"last-anchor"` باشد، Viewport تا زمان اعمال موقعیت اولیه دارای ویژگی `data-pending-scroll` است.

برای جلوگیری از نمایش این پرش، Viewport را تا زمان آماده شدن موقعیت مخفی کنید:

```css
#messages[data-pending-scroll] {
  visibility: hidden;
}
```

شناسه را روی Viewport قرار دهید:

```tsx
<MessageScroller.Viewport id="messages">
  <MessageScroller.Content>
    {/* پیام‌ها */}
  </MessageScroller.Content>
</MessageScroller.Viewport>
```

اگر می‌خواهید موقعیت `"end"` از همان اولین Paint قابل مشاهده باشد، می‌توانید یک اسکریپت کوچک بعد از Viewport اجرا کنید:

```tsx
const scrollToEndScript = `
  (function () {
    var viewport = document.getElementById("messages")

    if (!viewport) {
      return
    }

    viewport.scrollTop = viewport.scrollHeight
    viewport.removeAttribute("data-pending-scroll")
  })()
`

<MessageScroller.Root>
  <MessageScroller.Viewport
    id="messages"
    suppressHydrationWarning
  >
    <MessageScroller.Content>
      {/* transcript */}
    </MessageScroller.Content>
  </MessageScroller.Viewport>

  <script
    dangerouslySetInnerHTML={{
      __html: scrollToEndScript,
    }}
  />

  <MessageScroller.Button />
</MessageScroller.Root>
```

این روش فقط برای `"end"` مناسب است و زمانی کاربرد دارد که پیام‌ها از ابتدا در HTML وجود داشته باشند.

برای `"last-anchor"` از این اسکریپت استفاده نکنید. همچنین اگر پیام‌ها در سمت کلاینت بارگذاری می‌شوند، نیازی به این روش نیست.

اگر پروژه شما Content Security Policy دارد، برای اسکریپت `nonce` در نظر بگیرید.

## API

### MessageScroller.Provider

ریشهٔ بدون استایل `MessageScroller` است. وضعیت اسکرول و تنظیمات رفتاری را مدیریت می‌کند و آن‌ها را در اختیار سایر بخش‌ها و Hookها قرار می‌دهد.

خود Provider هیچ DOMای رندر نمی‌کند.

| ویژگی                    | نوع                                 | مقدار پیش‌فرض | توضیح                                                                           |
| ------------------------ | ----------------------------------- | ------------- | ------------------------------------------------------------------------------- |
| `autoScroll`             | `boolean`                           | `false`       | محتوای جدید را فقط زمانی دنبال می‌کند که کاربر در انتهای زندهٔ Transcript باشد. |
| `defaultScrollPosition`  | `"start" \| "end" \| "last-anchor"` | `"end"`       | موقعیت اولیهٔ اسکرول را مشخص می‌کند.                                            |
| `scrollEdgeThreshold`    | `number`                            | `8`           | فاصله‌ای که همچنان به‌عنوان رسیدن به ابتدا یا انتها در نظر گرفته می‌شود.        |
| `scrollMargin`           | `number`                            | `0`           | فاصلهٔ اعمال‌شده هنگام هم‌تراز کردن پیام‌ها و اهداف اسکرول.                     |
| `scrollPreviousItemPeek` | `number`                            | `64`          | مقدار فضای اضافه برای نمایش بخشی از پیام قبلی هنگام قرار دادن Anchor جدید.      |

#### `defaultScrollPosition`

مقدار `"last-anchor"` Viewport را روی آخرین پیام دارای `scrollAnchor` قرار می‌دهد و در صورت نبود Anchor یا مناسب بودن اندازهٔ محتوا، به `"end"` برمی‌گردد.

برای `"end"` و `"last-anchor"`، ویژگی `data-pending-scroll` تا زمان اعمال موقعیت اولیه روی Viewport باقی می‌ماند. جزئیات بیشتر در [جلوگیری از پرش هنگام بارگذاری مجدد](#جلوگیری-از-پرش-هنگام-بارگذاری-مجدد).

### MessageScroller.Root

قاب و container اصلی layout است. فضای والد خود را پر می‌کند؛ بنابراین آن را داخل یک layout با ارتفاع مشخص و درون `MessageScroller.Provider` قرار دهید.

| ویژگی      | نوع                           | مقدار پیش‌فرض | توضیح                               |
| ---------- | ----------------------------- | ------------- | ----------------------------------- |
| `...props` | `React.ComponentProps<"div">` | -             | به عنصر قاب منتقل می‌شود.           |

Root نیز attributeهای وضعیت اسکرول زیر را منعکس می‌کند (Viewport هم آن‌ها را دارد)، تا بتوانید container را بر اساس وضعیت اسکرول استایل دهید؛ مثلاً fade لبه‌ها روی قاب. در استفادهٔ headless، Viewport را تا زمان وجود `data-pending-scroll` با `visibility: hidden` مخفی کنید تا layout برای اسکرول اولیه حفظ شود.

| ویژگی داده            | مقدار                                             | توضیح                                                                                                                                                         |
| --------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data-scrollable`     | `"start"` \| `"end"` \| `"start end"` \| _absent_ | لبه‌هایی که Viewport می‌تواند به سمت آن‌ها اسکرول کند. برای یک لبه از `[data-scrollable~="end"]` استفاده کنید؛ نبود مقدار یعنی محتوا در viewport جا می‌شود. |
| `data-autoscrolling`  | present                                           | هنگام اسکرول برنامه‌ای به آخرین پیام.                                                                                                                         |
| `data-pending-scroll` | present                                           | تا اعمال `defaultScrollPosition` با مقدار `"end"` یا `"last-anchor"`؛ برای Transcript خالی اعمال نمی‌شود.                                                     |

### MessageScroller.Viewport

Viewport اسکرول‌شونده.

| ویژگی                     | نوع                           | مقدار پیش‌فرض | توضیح                                                              |
| ------------------------- | ----------------------------- | ------------- | ------------------------------------------------------------------ |
| `preserveScrollOnPrepend` | `boolean`                     | `true`        | هنگام اضافه شدن پیام‌های قدیمی، اولین آیتم قابل مشاهده را ثابت نگه می‌دارد. |
| `role`                    | `string`                      | `"region"`    | نقش landmark برای Viewport برچسب‌دار Transcript.                   |
| `aria-label`              | `string`                      | `"Messages"`  | نام دسترس‌پذیر برای Transcript چت.                                 |
| `tabIndex`                | `number`                      | `0`           | امکان اسکرول با کیبورد.                                            |
| `...props`                | `React.ComponentProps<"div">` | -             | به عنصر Viewport منتقل می‌شود.                                     |

| ویژگی داده            | مقدار                                             | توضیح                                                                                                                                                         |
| --------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data-scrollable`     | `"start"` \| `"end"` \| `"start end"` \| _absent_ | لبه‌هایی که Viewport می‌تواند به سمت آن‌ها اسکرول کند. برای یک لبه از `[data-scrollable~="end"]` استفاده کنید؛ نبود مقدار یعنی محتوا در viewport جا می‌شود. |
| `data-autoscrolling`  | present                                           | هنگام اسکرول برنامه‌ای به آخرین پیام.                                                                                                                         |
| `data-pending-scroll` | present                                           | تا اعمال `defaultScrollPosition` با مقدار `"end"` یا `"last-anchor"`؛ برای Transcript خالی اعمال نمی‌شود.                                                     |

### MessageScroller.Content

عنصر محتوای Transcript. هر فرزند مستقیم باید یک `MessageScroller.Item` باشد.

| ویژگی             | نوع                           | مقدار پیش‌فرض | توضیح                                                              |
| ----------------- | ----------------------------- | ------------- | ------------------------------------------------------------------ |
| `role`            | `string`                      | `"log"`       | نقش ARIA برای اعلام زندهٔ لیست پیام‌ها.                            |
| `aria-relevant`   | `string`                      | `"additions"` | به‌روزرسانی‌های live region؛ پیش‌فرض فقط ردیف‌های جدید.            |
| `aria-busy`       | `boolean`                     | -             | در صورت نیاز، هنگام Streaming یک turn، منطقه را busy علامت می‌زند. |
| `spacerClassName` | `string`                      | -             | کلاس spacer داخلی برای فضای ردیف‌های Anchor‌شده.                   |
| `...props`        | `React.ComponentProps<"div">` | -             | به عنصر محتوا منتقل می‌شود.                                        |

### MessageScroller.Item

یک ردیف Transcript: پیام، marker، ردیف تایپ، جداکننده یا ردیف بارگذاری بیشتر.

| ویژگی          | نوع                           | مقدار پیش‌فرض | توضیح                                                                           |
| -------------- | ----------------------------- | ------------- | ------------------------------------------------------------------------------- |
| `messageId`    | `string`                      | -             | شناسهٔ پایدار برای `scrollToMessage`، visibility و حفظ موقعیت هنگام prepend.    |
| `scrollAnchor` | `boolean`                     | `false`       | این ردیف را به‌عنوان مرز turn علامت می‌زند تا turnهای جدید بتوانند به آن لنگر شوند. |
| `...props`     | `React.ComponentProps<"div">` | -             | به عنصر Item منتقل می‌شود.                                                      |

| ویژگی داده           | مقدار                 | توضیح                          |
| -------------------- | --------------------- | ------------------------------ |
| `data-message-id`    | `string`              | معادل `messageId` در صورت وجود. |
| `data-scroll-anchor` | `"true"` \| `"false"` | معادل `scrollAnchor`.          |

### MessageScroller.Button

دکمه‌ای که به ابتدا یا انتهای Transcript اسکرول می‌کند. وقتی مقصدی برای اسکرول نباشد، inert می‌شود و از ترتیب تب خارج می‌گردد.

| ویژگی       | نوع                                     | مقدار پیش‌فرض | توضیح                                                              |
| ----------- | --------------------------------------- | ------------- | ------------------------------------------------------------------ |
| `behavior`  | `ScrollBehavior`                        | `"smooth"`    | رفتار اسکرول بومی هنگام رفتن به لبهٔ هدف.                          |
| `direction` | `"start" \| "end"`                      | `"end"`       | لبه‌ای که دکمه به سمت آن اسکرول می‌کند.                            |
| `children`  | `React.ReactNode`                       | -             | محتوای سفارشی دکمه. در غیر این صورت آیکون و برچسب دسترس‌پذیر پیش‌فرض. |
| `render`    | `React.ReactElement \| render function` | -             | هدف رندر سفارشی.                                                   |
| `...props`  | `React.ComponentProps<"button">`        | -             | به دکمه منتقل می‌شود.                                              |

| ویژگی داده       | مقدار                 | توضیح                          |
| ---------------- | --------------------- | ------------------------------ |
| `data-direction` | `"start"` \| `"end"`  | معادل `direction`.             |
| `data-active`    | `"true"` \| `"false"` | آیا دکمه در حال حاضر می‌تواند اسکرول کند. |

### useMessageScroller

کنترل‌های دستوری Transcript.

| متد               | نوع                                        | توضیح                      |
| ----------------- | ------------------------------------------ | -------------------------- |
| `scrollToMessage` | `(messageId: string, options?) => boolean` | اسکرول به یک `messageId` نصب‌شده. |
| `scrollToEnd`     | `(options?) => boolean`                    | اسکرول به آخرین پیام.      |
| `scrollToStart`   | `(options?) => boolean`                    | اسکرول به ابتدا.           |

همهٔ دستورها در صورت عدم امکان اجرا `false` برمی‌گردانند.
`scrollToStart` و `scrollToEnd` فقط وقتی Viewport هنوز mount نشده `false` می‌دهند.
`scrollToMessage` وقتی هدف mount نشده و قابل صف‌بندی نیست `false` برمی‌گرداند.

گزینه‌های دستور:

| گزینه          | نوع                                               | مقدار پیش‌فرض           | توضیح                                          |
| -------------- | ------------------------------------------------- | ----------------------- | ---------------------------------------------- |
| `align`        | `"start"` \| `"center"` \| `"end"` \| `"nearest"` | `"start"`               | نحوهٔ هم‌ترازی پیام هدف در Viewport.           |
| `behavior`     | `ScrollBehavior`                                  | `"auto"`                | رفتار اسکرول بومی برای دستور.                  |
| `scrollMargin` | `number`                                          | `scrollMargin` مربوط به Provider | فاصلهٔ اعمال‌شده روی لبهٔ هم‌تراز برای این دستور. |

### useMessageScrollerScrollable

لبه‌هایی که Viewport می‌تواند به سمت آن‌ها اسکرول کند؛ برای UIهای هم‌جوار که به این مقادیر در JavaScript نیاز دارند. برای استایل خود scroller، attribute `data-scrollable` را ترجیح دهید.

| مقدار   | نوع       | توضیح                                                                                                                                      |
| ------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `start` | `boolean` | آیا می‌توان به سمت ابتدا اسکرول کرد. محتوا بالای viewport پنهان است (`!start` یعنی در بالای لیست هستید).                                    |
| `end`   | `boolean` | آیا می‌توان به سمت انتها اسکرول کرد. محتوا پایین viewport پنهان است (`!end` یعنی در پایین هستید). هنگام follow-output در لبهٔ زنده `false` می‌ماند. |

### useMessageScrollerVisibility

وضعیت visibility برای outline، جستجو و UI مربوط به turn فعال. جدا از `useMessageScrollerScrollable` مشترک می‌شود تا هزینهٔ visibility فقط وقتی پرداخت شود که مصرف‌کننده به آن نیاز دارد.

| مقدار               | نوع              | توضیح                                                                                         |
| ------------------- | ---------------- | --------------------------------------------------------------------------------------------- |
| `currentAnchorId`   | `string \| null` | turn فعلی Anchor‌شده، بر اساس آخرین آیتم `scrollAnchor` در یا بالای خط خواندن.                |
| `visibleMessageIds` | `string[]`       | شناسهٔ پیام‌هایی که با Viewport تقاطع دارند، به ترتیب سند.                                    |

در صورت نیاز به outline محدودتر (مثلاً فقط پیام‌های کاربر، turnهای Anchor‌شده یا نتایج جستجو)، `visibleMessageIds` را در اپلیکیشن فیلتر کنید.
