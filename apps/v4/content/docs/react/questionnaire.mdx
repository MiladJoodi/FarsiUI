`Questionnaire` یک primitive فرم بدون استایل است که هر بار یک سؤال را نمایش می‌دهد و مدیریت پاسخ‌ها، پیشرفت، اعتبارسنجی و جابه‌جایی بین مراحل را بر عهده دارد.

برای سناریوهایی مثل پرسش‌های تکمیلی Agentها، Onboarding، نظرسنجی، فرم‌های دریافت اطلاعات و تنظیمات چندمرحله‌ای مناسب است.

نسخهٔ بدون استایل کنترل کاملی روی ساختار HTML و ظاهر در اختیار شما قرار می‌دهد. برای نسخهٔ استایل‌دار و نمونه‌های دارای Theme، صفحهٔ
[Questionnaire](/docs/components/base/questionnaire) را ببینید.

## نصب

پکیج `@farsiui/react` را نصب کنید:

```bash
npm install @farsiui/react
```

## Import

```tsx
import { Questionnaire } from "@farsiui/react/questionnaire"
```

`Questionnaire` تمام بخش‌های خود را از طریق یک namespace ارائه می‌کند. هر بخش نیز Props مربوط به Element پیش‌فرض خود را می‌پذیرد.

## ساختار

```tsx
<Questionnaire.Root>
  <Questionnaire.Progress />
  <Questionnaire.Item name="question">
    <Questionnaire.Title />
    <Questionnaire.Description />
    <Questionnaire.Choices>
      <Questionnaire.Choice>
        <Questionnaire.ChoiceInput />
        <Questionnaire.ChoiceLabel />
        <Questionnaire.ChoiceShortcut />
      </Questionnaire.Choice>
      <Questionnaire.Input />
    </Questionnaire.Choices>
    <Questionnaire.Error />
  </Questionnaire.Item>
  <Questionnaire.Previous />
  <Questionnaire.Skip />
  <Questionnaire.Next />
  <Questionnaire.Submit />
</Questionnaire.Root>
```

`Root` یک فرم ایجاد می‌کند. هر `Item` یک `fieldset` است و `Title` به‌عنوان `legend` آن استفاده می‌شود.

`ChoiceInput` نیز از ورودی‌های Native رادیویی و چک‌باکس استفاده می‌کند.

## نسخهٔ استایل‌دار

کامپوننت استایل‌دار از نام‌های تخت استفاده می‌کند:

| کامپوننت استایل‌دار                                                                      | بخش بدون استایل                                                                              |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `Questionnaire`                                                                          | `Questionnaire.Root`                                                                         |
| `QuestionnaireProgress`                                                                  | `Questionnaire.Progress`                                                                     |
| `QuestionnaireItem`                                                                      | `Questionnaire.Item`                                                                         |
| `QuestionnaireTitle`                                                                     | `Questionnaire.Title`                                                                        |
| `QuestionnaireDescription`                                                               | `Questionnaire.Description`                                                                  |
| `QuestionnaireChoices`                                                                   | `Questionnaire.Choices`                                                                      |
| `QuestionnaireChoice`                                                                    | `Questionnaire.Choice` + `ChoiceInput` + `ChoiceLabel` + `ChoiceShortcut`                    |
| `QuestionnaireInput`                                                                     | `Questionnaire.Input`                                                                        |
| `QuestionnaireError`                                                                     | `Questionnaire.Error`                                                                        |
| `QuestionnaireActions`                                                                   | ندارد؛ فقط برای Layout است و می‌توانید Container دلخواه خود را استفاده کنید.                 |
| `QuestionnairePrevious`، `QuestionnaireSkip`، `QuestionnaireNext`، `QuestionnaireSubmit` | `Questionnaire.Previous`، `Questionnaire.Skip`، `Questionnaire.Next`، `Questionnaire.Submit` |

در نسخهٔ استایل‌دار، `QuestionnaireChoice` ورودی، Label، میانبر و نشانگر بصری را برای شما ترکیب می‌کند. در نسخهٔ بدون استایل باید این بخش‌ها را خودتان کنار هم قرار دهید.

```tsx showLineNumbers
"use client"

import * as React from "react"
import { Questionnaire } from "@farsiui/react/questionnaire"

export function ProjectQuestionnaire() {
  function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault()

    const formData = new FormData(event.currentTarget)

    console.log({
      prototype: formData.get("prototype"),
      detail: formData.get("detail"),
    })
  }

  return (
    <Questionnaire.Root items={items} onSubmit={handleSubmit}>
      <Questionnaire.Progress />
      {items.map((question) => (
        <Questionnaire.Item
          key={question.name}
          name={question.name}
          required={question.required}
        >
          <Questionnaire.Title>{question.prompt}</Questionnaire.Title>
          <Questionnaire.Description>
            {question.description}
          </Questionnaire.Description>
          <Questionnaire.Choices>
            {question.choices.map((choice) => (
              <Questionnaire.Choice key={choice.value} value={choice.value}>
                <Questionnaire.ChoiceInput />
                <Questionnaire.ChoiceLabel>
                  <span>{choice.label}</span>
                  {"description" in choice ? (
                    <span>{choice.description}</span>
                  ) : null}
                </Questionnaire.ChoiceLabel>
                <Questionnaire.ChoiceShortcut />
              </Questionnaire.Choice>
            ))}
            {"input" in question ? (
              <Questionnaire.Input
                aria-label={question.input.label}
                placeholder={question.input.placeholder}
              />
            ) : null}
          </Questionnaire.Choices>
          <Questionnaire.Error />
        </Questionnaire.Item>
      ))}
      <Questionnaire.Previous />
      <Questionnaire.Skip />
      <Questionnaire.Next />
      <Questionnaire.Submit />
    </Questionnaire.Root>
  )
}
```

همان مجموعهٔ `items` را به `Root` بدهید که در بخش‌های `Item` و `Choice` رندر می‌کنید. با این کار ترتیب مراحل، وضعیت پیشرفت، نمایش دکمه‌های کنترلی و میانبرهای پاسخ در HTML رندرشده از سمت سرور در دسترس خواهند بود.

```tsx showLineNumbers
"use client"

import * as React from "react"
import {
  Questionnaire,
  type QuestionnaireItemStatus,
} from "@farsiui/react/questionnaire"

export function PlanningQuestionnaire() {
  const [timingStatus, setTimingStatus] =
    React.useState<QuestionnaireItemStatus>("unanswered")

  function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault()

    const formData = new FormData(event.currentTarget)

    console.log({
      timing:
        timingStatus === "skipped"
          ? { status: "skipped" }
          : {
              status: "answered",
              value: formData.get("timing"),
            },
    })
  }

  return (
    <Questionnaire.Root defaultItem="timing" onSubmit={handleSubmit}>
      <Questionnaire.Item name="timing" onStatusChange={setTimingStatus}>
        <Questionnaire.Title>
          When should this be revisited?
        </Questionnaire.Title>
        <Questionnaire.Description>
          Skip this if timing has not been decided.
        </Questionnaire.Description>
        <Questionnaire.Choices>
          <Questionnaire.Choice value="week">
            <Questionnaire.ChoiceInput />
            <Questionnaire.ChoiceLabel>This week</Questionnaire.ChoiceLabel>
            <Questionnaire.ChoiceShortcut />
          </Questionnaire.Choice>
          <Questionnaire.Choice value="cycle">
            <Questionnaire.ChoiceInput />
            <Questionnaire.ChoiceLabel>Next cycle</Questionnaire.ChoiceLabel>
            <Questionnaire.ChoiceShortcut />
          </Questionnaire.Choice>
        </Questionnaire.Choices>
      </Questionnaire.Item>
      <Questionnaire.Skip />
      <Questionnaire.Submit />
    </Questionnaire.Root>
  )
}
```

## اعتبارسنجی

`Questionnaire` قبل از رفتن به مرحلهٔ بعد، مرحلهٔ فعلی را اعتبارسنجی می‌کند و هنگام ارسال فرم، تمام مراحل فعال را بررسی می‌کند.

- یک مرحلهٔ الزامی زمانی معتبر است که پاسخ داشته باشد.
- یک مرحلهٔ اختیاری زمانی معتبر است که پاسخ داشته باشد یا صراحتاً رد شده باشد.
- مراحل و پاسخ‌های غیرفعال نادیده گرفته می‌شوند.

استفاده از `required` متن قابل مشاهدهٔ «الزامی» به فرم اضافه نمی‌کند. در صورت نیاز، این موضوع را در `Title` یا `Description` مشخص کنید.

اگر اعتبارسنجی ناموفق باشد، `Questionnaire` همان مرحله را نگه می‌دارد یا دوباره باز می‌کند و فوکوس را روی یکی از گزینه‌های پاسخ قرار می‌دهد. برای نمایش پیام خطا، `Error` را اضافه کنید.

```tsx
<Questionnaire.Item name="scope" required>
  <Questionnaire.Title>
    What should the project include? (Required)
  </Questionnaire.Title>
  <Questionnaire.Choices>{/* choices */}</Questionnaire.Choices>
  <Questionnaire.Error />
</Questionnaire.Item>
```

`Error` تا زمانی که مرحله نامعتبر نباشد نمایش داده نمی‌شود. برای جایگزین کردن پیام پیش‌فرض، متن دلخواه خود را داخل آن قرار دهید.

```tsx
<Questionnaire.Error>Please choose a project scope.</Questionnaire.Error>
```

اعتبارسنجی حتی بدون `Error` نیز انجام می‌شود. در صورت رندر شدن پیام خطا، متن آن برای Screen Readerها نیز اعلام می‌شود.

اگر از Zod یا Validator خارجی دیگری استفاده می‌کنید، مقدار `Item.invalid` را تنظیم کنید، پیام را داخل `Error` نمایش دهید و `Root.item` را روی اولین مرحلهٔ نامعتبر قرار دهید.

## وضعیت جابه‌جایی

اگر می‌خواهید خودتان یک دکمه را غیرفعال کنید، از وضعیت رندر کامپوننت استفاده کنید.

## رندر سفارشی

با `render` می‌توانید Element پیش‌فرض هر بخش را جایگزین کنید. یک Element بدهید، یا وقتی به وضعیت آن نیاز دارید از یک تابع استفاده کنید.

```tsx
<Questionnaire.Next render={<Button />}>Next</Questionnaire.Next>
```

`Root` و `Item` همیشه به‌ترتیب یک `form` و یک `fieldset` رندر می‌کنند. اگر `Title` دیگر `legend` رندر نکند، به آن `id` بدهید و همان شناسه را با `aria-labelledby` به `Item` پاس دهید.

این primitive مقدار `data-slot` منتشر نمی‌کند. Wrapperهای استایل‌دار مالک slotها و نشانگرهای بصری هستند.

## فرم‌های Native

`Root` همیشه یک فرم Native رندر می‌کند و از `onSubmit`، `onReset`، `action` و سایر props فرم پشتیبانی می‌کند. Questionnaire را داخل فرم دیگری قرار ندهید.

پاسخ‌ها از طریق کنترل‌های Native سریالایز می‌شوند:

- `FormData.get(itemName)` یک پاسخ تکی را می‌خواند.
- `FormData.getAll(itemName)` چند پاسخ را می‌خواند.
- مراحل ردشده در `FormData` حضور ندارند.
- برای تمایز رد کردن از پاسخِ مفقود، از `Item.onStatusChange` استفاده کنید.

`Root` به‌صورت پیش‌فرض `noValidate` را تنظیم می‌کند تا اعتبارسنجی از `Questionnaire.Error` استفاده کند، نه از UI اعتبارسنجی مرورگر.

`form.reset()` مرحلهٔ اولیه، پاسخ‌های پیش‌فرض، وضعیت رد کردن و وضعیت اعتبارسنجی را بازیابی می‌کند.

## ناوبری با صفحه‌کلید

Questionnaire روی رفتار Native رادیو، چک‌باکس، ورودی و دکمه بنا شده است.

| کلید                     | رفتار                                                                                                                           |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `Tab`                    | فوکوس را بین کنترل‌های پاسخ و اکشن‌های قابل‌مشاهده جابه‌جا می‌کند.                                                              |
| `Shift` + `Tab`          | فوکوس را به کنترل یا اکشن قبلی می‌برد.                                                                                          |
| `ArrowUp`                | به پاسخ قبلی از مرحله، پاسخ ثابت، یا ورودی متنی خالی می‌رود. رادیوهای Native آن را انتخاب هم می‌کنند.                          |
| `ArrowDown`              | به پاسخ بعدی از مرحله، پاسخ ثابت، یا ورودی متنی خالی می‌رود. رادیوهای Native آن را انتخاب هم می‌کنند.                          |
| `ArrowLeft`              | وقتی فوکوس بیرون از کنترل رادیو یا ورود متن است، به مرحلهٔ قبلی می‌رود.                                                         |
| `ArrowRight`             | وقتی مرحلهٔ فعال پاسخ داده یا رد شده و فوکوس بیرون از کنترل رادیو یا ورود متن است، به مرحلهٔ بعد می‌رود.                         |
| `Space`                  | رادیو را انتخاب، چک‌باکس را toggle، یا اکشن فوکوس‌شده را فعال می‌کند.                                                           |
| `Enter`                  | از گزینهٔ انتخاب‌شده یا ورودی پرشدهٔ انتخاب‌شده ادامه می‌دهد؛ اکشن فوکوس‌شده را فعال می‌کند.                                   |
| `Command/Ctrl` + `Enter` | از هر جای پرسش‌نامه اعتبارسنجی و ادامه می‌دهد، یا مرحلهٔ آخر را ارسال می‌کند.                                                  |

میانبرها و ناوبری با کلیدهای جهت‌دار هنگام تایپ در فیلد متنی متوقف می‌شوند.
جلوگیری از رویداد `onKeyDown` ریشه، مدیریت کلیدهای پرسش‌نامه را خاموش می‌کند.

دکمه‌های جابه‌جایی به‌صورت پیش‌فرض فعال می‌مانند تا اقدام نافرجام بتواند بازخورد اعتبارسنجی را نشان دهد. برای غیرفعال یا تغییر ظاهر اکشنِ بدون‌پاسخ، [وضعیت جابه‌جایی](#وضعیت-جابه‌جایی) را ببینید.

## دسترسی‌پذیری

- `Item` یک `fieldset` رندر می‌کند.
- `Title` به‌صورت پیش‌فرض `legend` همان fieldset را رندر می‌کند. اگر هدف رندر سفارشی داشته باشد، `id` آن را با `aria-labelledby` به مرحله وصل کنید.
- `Description` و `Error` فعال با `aria-describedby` متصل می‌شوند.
- مراحل و کنترل‌های پاسخِ نامعتبر `aria-invalid` دارند.
- `Progress` یک progressbar نام‌دار با مقادیر جاری، حداقل، حداکثر و متن رندر می‌کند.
- گزینه‌های ثابت از رادیو و چک‌باکس Native استفاده می‌کنند.
- کلیدهای میانبر اختصاص‌یافته و ناوبری در دسترس با `aria-keyshortcuts` اعلام می‌شوند.
- مراحل و اکشن‌های غیرفعال پنهان و inert هستند.
- جابه‌جایی، fieldset تازه‌فعال را فوکوس می‌کند.
- اعتبارسنجی اولین کنترل پاسخ در دسترس را فوکوس می‌کند.
- مراحل غیرفعال از پیشرفت و جابه‌جایی حذف می‌شوند.

همیشه به `Input` یک نام دسترس‌پذیر بدهید. از `id` صریح همراه با برچسب قابل‌مشاهده استفاده کنید:

```tsx
<Label htmlFor="other-answer">Other answer</Label>
<Questionnaire.Input
  id="other-answer"
  placeholder="Type another answer…"
/>
```

وقتی طراحی برچسب قابل‌مشاهده ندارد، از `aria-label` یا `aria-labelledby` استفاده کنید:

```tsx
<Questionnaire.Input
  aria-label="Other answer"
  placeholder="Type another answer…"
/>
```

Placeholder یک برچسب نیست.

## ویژگی‌های Data

از این attributeها برای استایل‌دهی استفاده کنید. attributeهای Boolean وقتی true باشند حاضرند و وقتی false باشند غایب‌اند.

### Root و Progress

| ویژگی Data       | مقدار                                            |
| ---------------- | ------------------------------------------------ |
| `data-current`   | موقعیت یک‌مبنایی مرحلهٔ فعال.                     |
| `data-total`     | تعداد مراحل فعال.                                |
| `data-first`     | روی اولین مرحله حاضر است.                        |
| `data-last`      | روی آخرین مرحله حاضر است.                        |
| `data-shortcuts` | `"letters"` \| `"numbers"` روی Root وقتی فعال باشد. |

### Item

| ویژگی Data      | مقدار                                         |
| --------------- | --------------------------------------------- |
| `data-active`   | وقتی فعال باشد حاضر است.                      |
| `data-status`   | `"unanswered"` \| `"answered"` \| `"skipped"` |
| `data-required` | وقتی الزامی باشد حاضر است.                    |
| `data-multiple` | وقتی چندانتخابی باشد حاضر است.                |
| `data-disabled` | وقتی غیرفعال باشد حاضر است.                   |
| `data-invalid`  | پس از اعتبارسنجی ناموفق حاضر است.             |

### Choice

| ویژگی Data       | مقدار                             |
| ---------------- | --------------------------------- |
| `data-type`      | `"radio"` \| `"checkbox"`         |
| `data-checked`   | وقتی انتخاب شده باشد حاضر است.    |
| `data-unchecked` | وقتی انتخاب نشده باشد حاضر است.   |
| `data-disabled`  | وقتی غیرفعال باشد حاضر است.       |
| `data-invalid`   | وقتی مرحله‌اش نامعتبر باشد حاضر است. |
| `data-shortcut`  | حرف یا عدد اختصاص‌یافته.          |

### Choices

| ویژگی Data       | مقدار                                    |
| ---------------- | ---------------------------------------- |
| `data-shortcuts` | `"letters"` \| `"numbers"` وقتی فعال باشد. |

### Input

| ویژگی Data      | مقدار                                      |
| --------------- | ------------------------------------------ |
| `data-filled`   | وقتی ورودی متن غیرخالی دارد حاضر است.      |
| `data-empty`    | وقتی ورودی متن پاسخ ندارد حاضر است.        |
| `data-disabled` | وقتی غیرفعال باشد حاضر است.                |
| `data-invalid`  | وقتی مرحله‌اش نامعتبر باشد حاضر است.       |

### Error

| ویژگی Data     | مقدار                              |
| -------------- | ---------------------------------- |
| `data-invalid` | تا وقتی خطا فعال است حاضر است.     |

### Previous، Skip، Next و Submit

| ویژگی Data      | مقدار                                                      |
| --------------- | ---------------------------------------------------------- |
| `data-visible`  | وقتی اکشن به مرحلهٔ فعال مربوط باشد حاضر است.              |
| `data-hidden`   | وقتی اکشن اعمال نشود حاضر است.                             |
| `data-disabled` | وقتی غیرفعال باشد حاضر است.                                |
| `data-shortcut` | `"Enter"` روی Next یا Submit فعال و قابل‌مشاهده.           |
| `data-status`   | مرحلهٔ فعال: `"unanswered"`، `"answered"` یا `"skipped"`. |

`Title` و `Description` ویژگی وضعیت ندارند. بخش‌های headless مقدار `data-slot` منتشر نمی‌کنند.

## مرجع API

### `Questionnaire.Root`

ریشهٔ فرم و مسئول هماهنگی مراحل پرسش‌نامه.

| Prop               | Type                                         | Default           | توضیحات                                                                                     |
| ------------------ | -------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------- |
| `item`         | `string`                                 | -                 | نام مرحلهٔ فعال در حالت Controlled.                                                         |
| `defaultItem`  | `string`                                 | اولین مرحلهٔ فعال | نام مرحله‌ای که در ابتدا فعال است.                                                          |
| `items`        | `readonly QuestionnaireItemDefinition[]` | -                 | دادهٔ اختیاری مراحل برای رندر سمت سرور و تعیین ترتیب مراحل.                                 |
| `onItemChange` | `(item: string) => void`                 | -                 | هنگام درخواست جابه‌جایی به مرحلهٔ دیگر اجرا می‌شود.                                         |
| `shortcuts`    | `"letters" \| "numbers"`                 | -                 | میانبرهای پاسخ را بر اساس ترتیب تعریف یا DOM اختصاص می‌دهد.                                 |
| `noValidate`   | `boolean`                                | `true`        | رابط اعتبارسنجی Native مرورگر را غیرفعال می‌کند و اعتبارسنجی `Questionnaire` را حفظ می‌کند. |
| `onSubmit`     | `FormEventHandler<HTMLFormElement>`      | -                 | Handler ارسال Native فرم، پس از اعتبارسنجی همهٔ مراحل.                                      |
| `onReset`      | `FormEventHandler<HTMLFormElement>`      | -                 | Handler بازنشانی Native فرم. برای جلوگیری از Reset شدن پرسش‌نامه، `preventDefault` کنید.    |

`Root` مقادیر `current`، `total`، `first`، `last` و `shortcuts` را از طریق Data Attributeها در اختیار می‌گذارد.

Typeهای مربوط به مجموعه‌ها از `@farsiui/react/questionnaire` قابل Import هستند:

```ts
type QuestionnaireChoiceDefinition = {
  value: string
  disabled?: boolean
}

type QuestionnaireItemDefinition = {
  name: string
  required?: boolean
  disabled?: boolean
  choices?: readonly QuestionnaireChoiceDefinition[]
}
```

### `Questionnaire.Progress`

موقعیت فعلی در میان مراحل فعال پرسش‌نامه.

| Prop             | Type                                                 | Default                             | توضیحات                               |
| ---------------- | ---------------------------------------------------- | ----------------------------------- | ------------------------------------- |
| `children`   | `React.ReactNode`                                | `Question {current} of {total}` | محتوای سفارشی برای نمایش پیشرفت.      |
| `aria-label` | `string`                                         | `Questionnaire progress`        | نام قابل دسترس برای progressbar.      |
| `render`     | `ReactElement \| (props, state) => ReactElement` | `<div>`                         | Element سفارشی همراه با وضعیت پیشرفت. |

وضعیت `render` شامل `current`، `total`، `first` و `last` است.

### `Questionnaire.Item`

یک مرحله از پرسش‌نامه.

| Prop                 | Type                                            | Default     | توضیحات                                                                                  |
| -------------------- | ----------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------- |
| `name`           | `string`                                    | الزامی      | شناسهٔ یکتای مرحله و نام فیلد Native فرم.                                                |
| `invalid`        | `boolean`                                   | `false` | مرحله را از طریق Validator خارجی نامعتبر اعلام می‌کند.                                   |
| `required`       | `boolean`                                   | `false` | پاسخ را الزامی می‌کند و اجازهٔ `Skip` نمی‌دهد.                                           |
| `multiple`       | `boolean`                                   | `false` | گزینه‌های ثابت را به Checkbox تبدیل می‌کند.                                              |
| `disabled`       | `boolean`                                   | `false` | مرحله را از پیشرفت و جابه‌جایی حذف می‌کند.                                               |
| `onStatusChange` | `(status: QuestionnaireItemStatus) => void` | -           | تغییر وضعیت بین `"unanswered"`، `"answered"` و `"skipped"` را دریافت می‌کند. |

`Item` وضعیت‌های `active`، `disabled`، `invalid`، `multiple`، `required` و `status` را از طریق Data Attributeها ارائه می‌کند.

نام مراحل باید در یک `Root` یکتا باشد. `name` متعلق به کنترل‌های پاسخ است، نه `fieldset`.

### `Questionnaire.Title`

عنوان مرحله. به‌صورت پیش‌فرض یک `legend` معنایی رندر می‌کند.

| Prop         | Type                                  | Default        | توضیحات                                                           |
| ------------ | ------------------------------------- | -------------- | ----------------------------------------------------------------- |
| `render` | `ReactElement \| render function` | `<legend>` | Element سفارشی. `id` آن را با `aria-labelledby` مرحله مرتبط کنید. |

### `Questionnaire.Description`

متن توضیحی که از طریق `aria-describedby` به مرحله متصل می‌شود.

| Prop         | Type                                  | Default   | توضیحات         |
| ------------ | ------------------------------------- | --------- | --------------- |
| `render` | `ReactElement \| render function` | `<p>` | Element سفارشی. |

### `Questionnaire.Choices`

Container چیدمان برای پاسخ‌های ثابت و متنی.

| Prop         | Type                                  | Default     | توضیحات         |
| ------------ | ------------------------------------- | ----------- | --------------- |
| `render` | `ReactElement \| render function` | `<div>` | Element سفارشی. |

وضعیت `render` شامل `shortcuts` است.

### `Questionnaire.Choice`

Container یک پاسخ ثابت. داخل آن یک `ChoiceInput`، یک `ChoiceLabel` و در صورت نیاز یک `ChoiceShortcut` قرار دهید.

`<label>` پیش‌فرض باعث می‌شود کل ردیف به کنترل Native مربوط متصل باشد.

| Prop                 | Type                                                 | Default       | توضیحات                               |
| -------------------- | ---------------------------------------------------- | ------------- | ------------------------------------- |
| `value`          | `string`                                         | الزامی        | مقدار پاسخ Native.                    |
| `checked`        | `boolean`                                        | -             | وضعیت انتخاب در حالت Controlled.      |
| `defaultChecked` | `boolean`                                        | `false`   | وضعیت انتخاب اولیه.                   |
| `disabled`       | `boolean`                                        | `false`   | کنترل پاسخ Native را غیرفعال می‌کند.  |
| `onChange`       | `ChangeEventHandler<HTMLInputElement>`           | -             | Handler تغییر Native input.           |
| `render`         | `ReactElement \| (props, state) => ReactElement` | `<label>` | Element سفارشی همراه با وضعیت Choice. |

وضعیت `render` شامل `checked`، `disabled`، `invalid`، `shortcut` و `type` است.

### `Questionnaire.ChoiceInput`

رادیو یا چک‌باکس Native مربوط به `Choice` والد.

`Questionnaire` Props لازم برای انتخاب، ارسال فرم، اعتبارسنجی و تعامل با کیبورد را مدیریت می‌کند. این بخش همچنین `className`، `id`، `ref`، `render` و سایر Props غیرمتعارض Native input را می‌پذیرد.

`ChoiceInput` باید داخل `Choice` استفاده شود. وضعیت `render` آن با `Choice` یکسان است.

### `Questionnaire.ChoiceLabel`

محتوای Label قابل مشاهده برای یک پاسخ ثابت.

این بخش یک `<span>` داخل Label مربوط به `Choice` رندر می‌کند و Props مربوط به `span` و `render` را می‌پذیرد.

### `Questionnaire.ChoiceShortcut`

میانبر قابل مشاهدهٔ یک پاسخ ثابت.

یک `<span>` شامل حرف یا عدد اختصاص‌یافته رندر می‌کند و اگر میانبری برای Choice وجود نداشته باشد، مخفی می‌ماند.

Props مربوط به `span` و `render` را می‌پذیرد و وضعیت `render` شامل `shortcut` است.

### `Questionnaire.Input`

پاسخ متنی آزاد. مقدار Native `name` آن توسط `Item` والد مدیریت می‌شود.

| Prop               | Type                                                 | Default       | توضیحات                                                              |
| ------------------ | ---------------------------------------------------- | ------------- | -------------------------------------------------------------------- |
| `value`        | `string \| number \| readonly string[]`          | -             | مقدار Controlled برای Native input.                                  |
| `defaultValue` | `string \| number \| readonly string[]`          | -             | مقدار اولیهٔ Native input.                                           |
| `disabled`     | `boolean`                                        | `false`   | ورودی را غیرفعال می‌کند.                                             |
| `onChange`     | `ChangeEventHandler<HTMLInputElement>`           | -             | Handler تغییر Native input.                                          |
| `type`         | `QuestionnaireInputType`                         | `"text"`  | نوع ورودی متنی، مانند `"email"`، `"number"` یا `"date"`. |
| `render`       | `ReactElement \| (props, state) => ReactElement` | `<input>` | Element سفارشی همراه با وضعیت Input.                                 |

وضعیت `render` شامل `disabled`، `filled` و `invalid` است.

### `Questionnaire.Error`

پیام اعتبارسنجی که تا زمانی که مرحله نامعتبر نشود، مخفی است.

| Prop           | Type                                                 | Default              | توضیحات                                     |
| -------------- | ---------------------------------------------------- | -------------------- | ------------------------------------------- |
| `children` | `React.ReactNode`                                | پیام متناسب با وضعیت | پیام اعتبارسنجی سفارشی.                     |
| `render`   | `ReactElement \| (props, state) => ReactElement` | `<p>`            | Element سفارشی همراه با وضعیت نامعتبر بودن. |

### اقدامات جابه‌جایی

`Previous`، `Skip`، `Next` و `Submit` دکمه‌های Native رندر می‌کنند و با تغییر وضعیت نمایش، همچنان در DOM باقی می‌مانند.

| Part           | نوع پیش‌فرض    | زمان نمایش               | زمان غیرفعال بودن                          |
| -------------- | -------------- | ------------------------ | ------------------------------------------ |
| `Previous` | `"button"` | در اولین مرحله نیستیم.   | وقتی `disabled` توسط مصرف‌کننده تنظیم شود. |
| `Skip`     | `"button"` | مرحلهٔ فعال اختیاری است. | وقتی `disabled` توسط مصرف‌کننده تنظیم شود. |
| `Next`     | `"button"` | در آخرین مرحله نیستیم.   | وقتی `disabled` توسط مصرف‌کننده تنظیم شود. |
| `Submit`   | `"submit"` | در آخرین مرحله هستیم.    | وقتی `disabled` توسط مصرف‌کننده تنظیم شود. |

هرکدام از این بخش‌ها Props مربوط به دکمه‌های Native را می‌پذیرند و شامل Prop زیر هستند:

| Prop         | Type                                                 | توضیحات                                  |
| ------------ | ---------------------------------------------------- | ---------------------------------------- |
| `render` | `ReactElement \| (props, state) => ReactElement` | Element سفارشی همراه با وضعیت جابه‌جایی. |

وضعیت `render` شامل `visible`، `disabled`، `shortcut` و `status` مرحلهٔ فعال است.
