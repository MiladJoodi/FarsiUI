سرور MCP مربوط به FarsiUI به‌صورت پیش‌فرض با هر رجیستری سازگار با FarsiUI / shadcn کار می‌کند. برای فعال‌سازی پشتیبانی MCP در رجیستری خود نیازی به کار خاصی ندارید.

برای راهنمای استفاده از سمت مصرف‌کننده، صفحهٔ [**سرور MCP**](/docs/mcp) را ببینید.

## پیش‌نیازها

سرور MCP با درخواست ایندکس رجیستری شما کار می‌کند. مطمئن شوید در ریشهٔ رجیستری یک فایل آیتم با نام **`registry`** دارید.

برای مثال، اگر رجیستری شما در آدرس `https://acme.com/r/[name].json` میزبانی می‌شود، باید فایلی در مسیر `https://acme.com/r/registry.json` داشته باشید؛ یا اگر از پسوند JSON استفاده نمی‌کنید، در مسیر `https://acme.com/r/registry`.

این فایل باید یک JSON معتبر و مطابق Schema رجیستری باشد.

## بهترین روش‌ها

برای رجیستری‌های سازگار با MCP این نکات را رعایت کنید:

1. **توضیحات واضح:** توضیح‌های کوتاه و مفید بنویسید تا دستیارهای AI بفهمند هر آیتم رجیستری برای چه کاری است و چگونه استفاده می‌شود.
2. **وابستگی‌های درست:** همهٔ **`dependencies`** را دقیق فهرست کنید تا MCP بتواند آن‌ها را به‌صورت خودکار نصب کند.
3. **وابستگی‌های رجیستری:** از **`registryDependencies`** برای نشان دادن رابطه بین آیتم‌ها استفاده کنید.
4. **نام‌گذاری یکدست:** برای نام کامپوننت‌ها از kebab-case استفاده کنید و در کل رجیستری یکدست بمانید.
