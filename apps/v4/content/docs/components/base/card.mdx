## استفاده

```tsx showLineNumbers
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
```

```tsx showLineNumbers
<Card>
  <CardHeader>
    <CardTitle>عنوان کارت</CardTitle>
    <CardDescription>توضیح کارت</CardDescription>
    <CardAction>اقدام</CardAction>
  </CardHeader>
  <CardContent>
    <p>محتوای کارت</p>
  </CardContent>
  <CardFooter>
    <p>پاورقی کارت</p>
  </CardFooter>
</Card>
```

## فاصله‌گذاری

</div>

<DocsCollapsible title="فاصله‌گذاری">

علاوه بر `size`، می‌توانید با متغیر CSS `--card-spacing` فاصله بین بخش‌ها و حاشیه داخلی کارت را تنظیم کنید.

<ComponentPreview
  styleName="base-nova"
  name="card-spacing"
  direction="rtl"
  previewClassName="h-auto! min-h-0 py-6 px-6"
/>

با استفاده از حاشیه منفی `-mx-(--card-spacing)` می‌توانید محتوا را لبه‌به‌لبه کنید و با حاشیه داخلی کارت هم‌تراز نگه دارید. برای محتوای لبه‌به‌لبه در پایین کارت، از `-mb-(--card-spacing)` روی `CardContent` استفاده کنید تا فاصله بین بخش‌ها حذف شود.
