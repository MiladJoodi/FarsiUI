<DocsCollapsible title="تغییرات">

### ۱۴۰۵-۰۲-۲۷ فاصلهٔ پیش‌فرض

مقدار پیش‌فرض `spacing` از `0` به `2` تغییر کرد تا بین آیتم‌ها فاصله باشد. برای آیتم‌های به‌هم‌چسبیده از `spacing={0}` استفاده کنید.
