## اکشن

</div>

<DocsCollapsible title="اکشن">

با `actionProps` پراپ‌های دکمه را بدهید تا اکشن رندر شود.

```tsx
const id = toast.add({
  title: "رویداد ساخته شد",
  actionProps: {
    children: "بازگردانی",
    onClick() {
      toast.close(id)
    },
  },
})
```

</DocsCollapsible>
