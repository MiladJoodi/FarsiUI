## ساختار

</div>

<DocsCollapsible title="ساختار">

- **SidebarProvider** — حالت جمع‌شونده را مدیریت می‌کند و context نوار کناری را به فرزندان می‌دهد.
- **Sidebar** — پنل اصلی نوار کناری جمع‌شونده.
- **SidebarHeader** — چسبیده به بالا؛ برای برند، عنوان یا تعویض فضای کاری.
- **SidebarFooter** — چسبیده به پایین؛ برای منوی کاربر، تنظیمات یا اقدام‌ها.
- **SidebarContent** — ناحیهٔ قابل‌پیمایش بین هدر و فوتر.
- **SidebarGroup** — گروه‌بندی ناوبری مرتبط با برچسب، اقدام و محتوای اختیاری.
- **SidebarMenu** / **SidebarMenuItem** — ساختار منو برای لینک، نشان، اقدام و زیرمنو.
- **SidebarRail** — دستگیرهٔ تغییر عرض نوار کناری در صورت نیاز.
- **SidebarInset** — محتوا را هنگام استفاده از واریانت `inset` می‌پیچد.
- **SidebarTrigger** — کنترل باز و بسته کردن نوار کناری.

## SidebarProvider

</div>

<DocsCollapsible title="SidebarProvider">

`SidebarProvider` context نوار کناری را به `Sidebar` می‌دهد. همیشه اپلیکیشن را داخل `SidebarProvider` بپیچید.

### Props

| نام            | نوع                       | توضیح                             |
| -------------- | ------------------------- | --------------------------------- |
| `defaultOpen`  | `boolean`                 | حالت باز پیش‌فرض نوار کناری.      |
| `open`         | `boolean`                 | حالت باز کنترل‌شده.               |
| `onOpenChange` | `(open: boolean) => void` | تنظیم حالت باز (کنترل‌شده).       |

### عرض

اگر یک نوار کناری دارید، از متغیرهای `SIDEBAR_WIDTH` و `SIDEBAR_WIDTH_MOBILE` در `sidebar.tsx` استفاده کنید.

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_WIDTH = "16rem"
const SIDEBAR_WIDTH_MOBILE = "18rem"
```

برای چند نوار کناری، از متغیرهای CSS `--sidebar-width` و `--sidebar-width-mobile` در prop به نام `style` استفاده کنید.

```tsx showLineNumbers
<SidebarProvider
  style={
    {
      "--sidebar-width": "20rem",
      "--sidebar-width-mobile": "20rem",
    } as React.CSSProperties
  }
>
  <Sidebar />
</SidebarProvider>
```

### میانبر صفحه‌کلید

برای باز و بسته کردن نوار کناری از `cmd+b` در مک و `ctrl+b` در ویندوز استفاده می‌شود.

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_KEYBOARD_SHORTCUT = "b"
```

## Sidebar

</div>

<DocsCollapsible title="Sidebar">

کامپوننت اصلی برای رندر نوار کناری جمع‌شونده.

### Props

| ویژگی         | نوع                               | توضیح                    |
| ------------- | --------------------------------- | ------------------------ |
| `side`        | `left` یا `right`                 | سمت نوار کناری.          |
| `variant`     | `sidebar`، `floating` یا `inset`  | واریانت نوار کناری.      |
| `collapsible` | `offcanvas`، `icon` یا `none`     | حالت جمع‌شوندگی.         |

| Prop        | توضیح                                                      |
| ----------- | ---------------------------------------------------------- |
| `offcanvas` | نوار کناری جمع‌شونده که از چپ یا راست می‌آید.              |
| `icon`      | نواری که به آیکون جمع می‌شود.                              |
| `none`      | نوار کناری غیرجمع‌شونده.                                   |

<Callout>
  **توجه:** اگر از واریانت `inset` استفاده می‌کنید، محتوای اصلی را داخل
  `SidebarInset` بپیچید.
</Callout>

```tsx showLineNumbers
<SidebarProvider>
  <Sidebar variant="inset" />
  <SidebarInset>
    <main>{children}</main>
  </SidebarInset>
</SidebarProvider>
```

</DocsCollapsible>

## useSidebar

</div>

<DocsCollapsible title="useSidebar">

هوک `useSidebar` برای کنترل نوار کناری است.

```tsx showLineNumbers
import { useSidebar } from "@/components/ui/sidebar"

export function AppSidebar() {
  const {
    state,
    open,
    setOpen,
    openMobile,
    setOpenMobile,
    isMobile,
    toggleSidebar,
  } = useSidebar()
}
```

| ویژگی           | نوع                       | توضیح                                      |
| --------------- | ------------------------- | ------------------------------------------ |
| `state`         | `expanded` یا `collapsed` | حالت فعلی نوار کناری.                      |
| `open`          | `boolean`                 | باز بودن نوار کناری.                       |
| `setOpen`       | `(open: boolean) => void` | تنظیم حالت باز.                            |
| `openMobile`    | `boolean`                 | باز بودن در موبایل.                        |
| `setOpenMobile` | `(open: boolean) => void` | تنظیم حالت باز در موبایل.                  |
| `isMobile`      | `boolean`                 | نمایش در موبایل.                           |
| `toggleSidebar` | `() => void`              | باز و بسته کردن؛ دسکتاپ و موبایل.          |

### پشتیبانی RTL

اگر از نسخهٔ قبلی `Sidebar` ارتقا می‌دهید، برای پشتیبانی RTL این به‌روزرسانی‌ها را اعمال کنید:

<Steps>

<Step>prop به نام `dir` را به کامپوننت Sidebar اضافه کنید.</Step>

`dir` را در props تجزیه کنید و برای موبایل به `SheetContent` بدهید:

```diff
  function Sidebar({
    side = "left",
    variant = "sidebar",
    collapsible = "offcanvas",
    className,
    children,
+   dir,
    ...props
  }: React.ComponentProps<"div"> & {
    side?: "left" | "right"
    variant?: "sidebar" | "floating" | "inset"
    collapsible?: "offcanvas" | "icon" | "none"
  }) {
```

سپس در نمای موبایل به `SheetContent` بدهید:

```diff
  <Sheet open={openMobile} onOpenChange={setOpenMobile} {...props}>
    <SheetContent
+     dir={dir}
      data-sidebar="sidebar"
      data-slot="sidebar"
      data-mobile="true"
```

<Step>صفت `data-side` را به ظرف نوار کناری اضافه کنید.</Step>

`data-side={side}` را روی عنصر ظرف بگذارید:

```diff
  <div
    data-slot="sidebar-container"
+   data-side={side}
    className={cn(
```

<Step>کلاس‌های موقعیت ظرف نوار کناری را به‌روز کنید.</Step>

شرط‌های سه‌تایی جاوااسکریپت را با سلکتورهای صفت دادهٔ CSS جایگزین کنید:

```diff
  className={cn(
-   "fixed inset-y-0 z-10 hidden h-svh w-(--sidebar-width) transition-[left,right,width] duration-200 ease-linear md:flex",
-   side === "left"
-     ? "left-0 group-data-[collapsible=offcanvas]:left-[calc(var(--sidebar-width)*-1)]"
-     : "right-0 group-data-[collapsible=offcanvas]:right-[calc(var(--sidebar-width)*-1)]",
+   "fixed inset-y-0 z-10 hidden h-svh w-(--sidebar-width) transition-[left,right,width] duration-200 ease-linear md:flex data-[side=left]:left-0 data-[side=right]:right-0 data-[side=left]:group-data-[collapsible=offcanvas]:left-[calc(var(--sidebar-width)*-1)] data-[side=right]:group-data-[collapsible=offcanvas]:right-[calc(var(--sidebar-width)*-1)]",
```

<Step>کلاس‌های موقعیت SidebarRail را به‌روز کنید.</Step>

`SidebarRail` را با موقعیت فیزیکی برای ریل به‌روز کنید:
