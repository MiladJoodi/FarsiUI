  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,

  <Button>دکمه ۱</Button>

</ButtonGroup>

## دسترس‌پذیری

</div>

<DocsCollapsible title="دسترس‌پذیری">

- روی `ButtonGroup` مقدار `role="group"` تنظیم شده است.
- با <Kbd>Tab</Kbd> بین دکمه‌های گروه جابه‌جا شوید.
- برای برچسب‌گذاری گروه از `aria-label` یا `aria-labelledby` استفاده کنید.

```tsx showLineNumbers
<ButtonGroup aria-label="گروه دکمه‌ها">
  <Button>دکمه ۱</Button>
  <Button>دکمه ۲</Button>
</ButtonGroup>
```

</DocsCollapsible>

## تفاوت با ToggleGroup

</div>

<DocsCollapsible title="تفاوت با ToggleGroup">

- از `ButtonGroup` وقتی استفاده کنید که دکمه‌ها یک **عمل** انجام می‌دهند.
- از `ToggleGroup` وقتی استفاده کنید که دکمه‌ها یک **وضعیت** را روشن/خاموش می‌کنند.
