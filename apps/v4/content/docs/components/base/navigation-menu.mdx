## کامپوننت لینک

</div>

<DocsCollapsible title="کامپوننت لینک">

با prop به نام `render` یک کامپوننت لینک سفارشی مثل `Link` در Next.js بسازید.

```tsx showLineNumbers
import Link from "next/link"

import {
  NavigationMenuItem,
  NavigationMenuLink,
  navigationMenuTriggerStyle,
} from "@/components/ui/navigation-menu"

export function NavigationMenuDemo() {
  return (
    <NavigationMenuItem>
      <NavigationMenuLink
        render={<Link href="/docs" />}
        className={navigationMenuTriggerStyle()}
      >
        مستندات
      </NavigationMenuLink>
    </NavigationMenuItem>
  )
}
```
