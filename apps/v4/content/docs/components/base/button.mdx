<DocsCollapsible title="نشانگر ماوس">

در Tailwind v4، مقدار پیش‌فرض `cursor` برای دکمه از `cursor: pointer` به `cursor: default` تغییر کرده است.

اگر می‌خواهید هنگام قرار گرفتن ماوس روی دکمه، نشانگر به شکل دست نمایش داده شود، کد زیر را به فایل CSS پروژه اضافه کنید:

```css showLineNumbers title="globals.css"
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

می‌توانید این قابلیت را هنگام راه‌اندازی پروژه نیز با گزینه `--pointer` فعال کنید:

```bash
npx farsiui@latest init --pointer
```

</DocsCollapsible>

با استفاده از `buttonVariants` می‌توانید ظاهر یک لینک را شبیه دکمه کنید.

**برای لینک‌ها از `<Button render={<a />} nativeButton={false} />` استفاده نکنید.** کامپوننت `Button` در Base UI همیشه `role="button"` را روی عنصر اعمال می‌کند و این موضوع باعث می‌شود نقش اصلی لینک روی `<a>` از بین برود.

به‌جای آن، از `buttonVariants` همراه با یک تگ ساده `<a>` استفاده کنید.
