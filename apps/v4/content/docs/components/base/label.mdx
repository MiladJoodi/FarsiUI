## برچسب در فیلد

</div>

<DocsCollapsible title="برچسب در فیلد">

برای فیلدهای فرم از کامپوننت [فیلد](/docs/components/base/field) استفاده کنید که `FieldLabel`، `FieldDescription` و `FieldError` را از قبل دارد.

```tsx
<Field>
  <FieldLabel htmlFor="email">آدرس ایمیل شما</FieldLabel>
  <Input id="email" />
</Field>
```
