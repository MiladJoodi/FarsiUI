## حالت انتخاب

</div>

<DocsCollapsible title="حالت انتخاب">

برای حالت کنترل‌نشده از `defaultChecked` و برای کنترل‌شده از `checked` و `onCheckedChange` استفاده کنید.

```tsx showLineNumbers
import * as React from "react"

export function Example() {
  const [checked, setChecked] = React.useState(false)

  return <Checkbox checked={checked} onCheckedChange={setChecked} />
}
```
