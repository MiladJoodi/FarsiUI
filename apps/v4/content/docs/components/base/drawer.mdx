## اندازه‌های سفارشی

</div>

<DocsCollapsible title="اندازه‌های سفارشی">

کشوی عمودی اندازهٔ محتوا را می‌گیرد و سقف پیش‌فرضش `calc(100dvh - 6rem)` است. کشوی کناری ۷۵٪ عرض ویوپورت، یا در صفحهٔ بزرگ‌تر `24rem` است.

ارتفاع کشوی عمودی را با `h-*` و `max-h-*` روی `DrawerContent` تنظیم کنید:

```tsx
<DrawerContent className="h-[50vh]">
```

عرض کشوی کناری را با `w-*` و `max-w-*` تنظیم کنید:

```tsx
<DrawerContent className="w-96">
```

اگر همان کامپوننت در چند جهت رندر می‌شود، با واریانت‌های `data-[swipe-axis=*]` فقط یک محور را override کنید:

```tsx
<DrawerContent className="data-[swipe-axis=y]:max-h-[50vh] data-[swipe-axis=x]:w-96">
```

برای اسکرول، ظرف اسکرول را flex item کنید. از `h-full` پرهیز کنید؛ داخل کشوی content-sized جواب نمی‌دهد.

```tsx
<DrawerContent>
  <DrawerHeader>...</DrawerHeader>
  <div className="flex-1 overflow-y-auto p-4">{/* محتوای اسکرول‌شونده */}</div>
  <DrawerFooter>...</DrawerFooter>
</DrawerContent>
```

</DocsCollapsible>

## استایل‌دهی

</div>

<DocsCollapsible title="استایل‌دهی">

کشو متغیرهای CSS برای سفارشی‌سازی دارد. متغیرهای اندازه را روی `DrawerContent` بگذارید. متغیر پوشش را روی `[data-slot=drawer-overlay]` در CSS تنظیم کنید.

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `--drawer-inset` | `0px` | فاصلهٔ کشو از لبه‌های ویوپورت |
| `--drawer-bleed-background` | `var(--color-popover)` | پر کردن شکاف پشت کشو در overshoot |
| `--drawer-overlay-min-opacity` | `0` | حداقل شفافیت پوشش؛ با اسنپ معمولاً `0.5` |

همچنین data attributeهایی دارید که با واریانت‌هایی مثل `data-[swipe-direction=down]:` روی `DrawerContent` یا `group-data-[swipe-axis=y]/drawer-popup:` روی فرزندان هدف می‌گیرید.

| ویژگی | مقادیر | زمان تنظیم |
| --- | --- | --- |
| `data-swipe-direction` | `up`, `right`, `down`, `left` | همیشه |
| `data-swipe-axis` | `x`, `y` | همیشه |
| `data-snap-points` | حاضر | وقتی اسنپ فعال است |
| `data-expanded` | حاضر | در نقطهٔ اسنپ کامل |
| `data-swiping` | حاضر | هنگام کشیدن |
| `data-nested-drawer-open` | حاضر | وقتی کشوی تو در تو باز است |

</DocsCollapsible>

## مهاجرت از Vaul

</div>

<DocsCollapsible title="مهاجرت از Vaul">

کشوی base الان از [Base UI](https://base-ui.com/react/components/drawer) به‌جای Vaul استفاده می‌کند. اگر نسخهٔ قبلی را داشتید، API را به‌روز کنید.

<Steps>

<Step>وابستگی را به‌روز کنید.</Step>

```diff
- npm install vaul
+ npm install @base-ui/react
```

<Step>`direction` را با `swipeDirection` عوض کنید.</Step>

به‌جای `bottom` از `down` و به‌جای `top` از `up` استفاده کنید. `left` و `right` همان می‌مانند.

```diff
- <Drawer direction="bottom">
+ <Drawer swipeDirection="down">
```

<Step>`asChild` را با `render` عوض کنید.</Step>

```diff
- <DrawerTrigger asChild>
-   <Button variant="outline">Open</Button>
- </DrawerTrigger>
+ <DrawerTrigger render={<Button variant="outline" />}>
+   باز کردن
+ </DrawerTrigger>
```

```diff
- <DrawerClose asChild>
-   <Button variant="outline">Cancel</Button>
- </DrawerClose>
+ <DrawerClose render={<Button variant="outline" />}>
+   انصراف
+ </DrawerClose>
```

<Step>پراپ‌های اسنپ را به‌روز کنید.</Step>

```diff
  <Drawer
    snapPoints={[0.25, 0.5, 1]}
-   activeSnapPoint={snapPoint}
-   setActiveSnapPoint={setSnapPoint}
-   snapToSequentialPoint
+   snapPoint={snapPoint}
+   onSnapPointChange={setSnapPoint}
+   snapToSequentialPoints
  >
```

<Step>پراپ‌های انیمیشن و فوکوس را به‌روز کنید.</Step>

```diff
- <Drawer onAnimationEnd={(open) => setDone(open)}>
+ <Drawer onOpenChangeComplete={(open) => setDone(open)}>
```

```diff
- <DrawerContent onOpenAutoFocus={(event) => event.preventDefault()}>
+ <DrawerContent initialFocus={false}>
```

<Step>پراپ‌های فقط‌Vaul را مرور کنید.</Step>

پراپ‌هایی مثل `handleOnly`، `repositionInputs` و `shouldScaleBackground` جایگزین یک‌به‌یک ندارند. از `disablePointerDismissal`، `modal`، `snapPoints` یا `open` کنترل‌شده استفاده کنید.

```diff
- <Drawer handleOnly repositionInputs={false} shouldScaleBackground>
+ <Drawer>
```

```diff
- <Drawer dismissible={false}>
+ <Drawer disablePointerDismissal>
```

<Step>سلکتورهای data attribute را به‌روز کنید.</Step>

```diff
- <DrawerContent className="data-[vaul-drawer-direction=bottom]:max-h-[50vh]">
+ <DrawerContent className="data-[swipe-direction=down]:max-h-[50vh]">
```

Base UI ویژگی‌هایی مثل `data-swiping`، `data-starting-style` و `data-ending-style` هم دارد. فرزندان داخل `DrawerContent` می‌توانند از `group-data-[swipe-axis=x]/drawer-popup` و `group-data-[swipe-axis=y]/drawer-popup` استفاده کنند.

</Steps>

</DocsCollapsible>
