## استفاده

```tsx showLineNumbers
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"
```

```tsx showLineNumbers
const items = [
  { label: "روشن", value: "light" },
  { label: "تیره", value: "dark" },
  { label: "سیستم", value: "system" },
]

<Select items={items}>
  <SelectTrigger className="w-[180px]">
    <SelectValue placeholder="تم" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      {items.map((item) => (
        <SelectItem key={item.value} value={item.value}>
          {item.label}
        </SelectItem>
      ))}
    </SelectGroup>
  </SelectContent>
</Select>
```

## تراز آیتم با تریگر

</div>

<DocsCollapsible title="تراز آیتم با تریگر">

با `alignItemWithTrigger` روی `SelectContent` مشخص کنید که آیتم انتخاب‌شده با تریگر تراز شود یا نه. وقتی `true` باشد (پیش‌فرض)، پاپ‌آپ طوری قرار می‌گیرد که آیتم انتخاب‌شده روی تریگر دیده شود. وقتی `false` باشد، پاپ‌آپ با لبهٔ تریگر تراز می‌شود.

## نامعتبر

</div>

<DocsCollapsible title="نامعتبر">

صفت `data-invalid` را روی `Field` و `aria-invalid` را روی `SelectTrigger` بگذارید تا حالت خطا نمایش داده شود.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <FieldLabel>میوه</FieldLabel>
  <SelectTrigger aria-invalid>
    <SelectValue />
  </SelectTrigger>
</Field>
```
