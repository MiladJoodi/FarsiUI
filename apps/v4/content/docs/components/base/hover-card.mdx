## استفاده

```tsx showLineNumbers
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card"
```

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger>نگه دارید</HoverCardTrigger>
  <HoverCardContent>
    فریم‌ورک ری‌اکت — ساخته و نگهداری‌شده توسط ورسل.
  </HoverCardContent>
</HoverCard>
```

## تأخیر تریگر

</div>

<DocsCollapsible title="تأخیر تریگر">

با `delay` و `closeDelay` روی تریگر، زمان باز و بسته شدن کارت را کنترل کنید.

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger delay={100} closeDelay={200}>
    نگه دارید
  </HoverCardTrigger>
  <HoverCardContent>محتوا</HoverCardContent>
</HoverCard>
```

</DocsCollapsible>

<div className="hidden">

## موقعیت‌یابی

</div>

<DocsCollapsible title="موقعیت‌یابی">

با propهای `side` و `align` روی `HoverCardContent` جایگاه کارت را تنظیم کنید.

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger>نگه دارید</HoverCardTrigger>
  <HoverCardContent side="top" align="start">
    محتوا
  </HoverCardContent>
</HoverCard>
```

</DocsCollapsible>

## پشتیبانی RTL

</div>

<DocsCollapsible title="پشتیبانی RTL">

برای پشتیبانی RTL در FarsiUI، [راهنمای پیکربندی RTL](/docs/rtl) را ببینید.

<ComponentPreview
  styleName="base-nova"
  name="hover-card-rtl"
  direction="rtl"
  previewClassName="h-80"

با `side="inline-end"` کارت را در سمت منطقی انتها (چپ در RTL) نسبت به تریگر قرار دهید.

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger>نگه دارید</HoverCardTrigger>
  <HoverCardContent side="inline-end">
    فریم‌ورک ری‌اکت — ساخته و نگهداری‌شده توسط ورسل.
  </HoverCardContent>
</HoverCard>
```
