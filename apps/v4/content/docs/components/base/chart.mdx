## کامپوننت

</div>

<DocsCollapsible title="کامپوننت">

زیرساخت ما [Recharts](https://recharts.org/) است.

کامپوننت `chart` با ترکیب‌پذیری طراحی شده است. **نمودار را با کامپوننت‌های Recharts می‌سازید و فقط وقتی لازم است، کامپوننت‌های سفارشی مثل `ChartTooltip` را اضافه می‌کنید.**

```tsx showLineNumbers /ChartContainer/ /ChartTooltipContent/
import { Bar, BarChart } from "recharts"

import { ChartContainer, ChartTooltipContent } from "@/components/ui/chart"

export function MyChart() {
  return (
    <ChartContainer>
      <BarChart data={data}>
        <Bar dataKey="value" />
        <ChartTooltip content={<ChartTooltipContent />} />
      </BarChart>
    </ChartContainer>
  )
}
```

Recharts را wrap نمی‌کنیم؛ بنابراین به abstraction قفل نمی‌شوید. با نسخهٔ جدید Recharts می‌توانید مسیر رسمی ارتقا را دنبال کنید.

**کامپوننت‌ها مال خودتان‌اند.**

## به‌روزرسانی به Recharts v3

</div>

<a id="updating-to-recharts-v3"></a>

<DocsCollapsible title="به‌روزرسانی به Recharts v3">

اگر کد قدیمی نمودار را به Recharts v3 می‌برید:

- به‌جای `hsl(var(--chart-1))` از `var(--chart-1)` برای توکن‌های CSS استفاده کنید.
- `ChartTooltip.defaultIndex` فقط برای حالت اولیهٔ راهنماست؛ شکل فعال پایدار را در state خود نگه دارید.
- اگر `<BarChart>` خودش `layout` دارد، `layout` را از `<Bar>` بردارید.
- روی `ChartContainer` ارتفاع، `min-h-*` یا `aspect-*` بگذارید تا `ResponsiveContainer` در رندر اول اندازه بگیرد.

</DocsCollapsible>


</div>

راهنمای نمودار شامل برچسب، نام، نشانگر و مقدار است.

با `hideLabel` و `hideIndicator` می‌توانید بخش‌ها را خاموش کنید و با `indicator` ظاهر نشانگر را عوض کنید.

با `labelKey` و `nameKey` کلید سفارشی برای برچسب و نام بگذارید.

```tsx title="components/example-chart.tsx"
import { ChartTooltip, ChartTooltipContent } from "@/components/ui/chart"
```

```tsx title="components/example-chart.tsx"
<ChartTooltip content={<ChartTooltipContent />} />
```

### Props

| Prop            | Type                     | Description                                      |
| :-------------- | :----------------------- | :----------------------------------------------- |
| `labelKey`      | string                   | کلید config یا داده برای برچسب                   |
| `nameKey`       | string                   | کلید config یا داده برای نام                     |
| `indicator`     | `dot` `line` یا `dashed` | ظاهر نشانگر                                      |
| `hideLabel`     | boolean                  | مخفی کردن برچسب                                  |
| `hideIndicator` | boolean                  | مخفی کردن نشانگر                                 |

### رنگ‌ها

رنگ‌ها به‌صورت خودکار از `chartConfig` خوانده می‌شوند.

### سفارشی

```tsx showLineNumbers /browser/
const chartData = [
  { browser: "chrome", visitors: 187, fill: "var(--color-chrome)" },
  { browser: "safari", visitors: 200, fill: "var(--color-safari)" },
]

const chartConfig = {
  visitors: {
    label: "کل بازدیدکنندگان",
  },
  chrome: {
    label: "کروم",
    color: "var(--chart-1)",
  },
  safari: {
    label: "سافاری",
    color: "var(--chart-2)",
  },
} satisfies ChartConfig
```

```tsx title="components/example-chart.tsx"
<ChartTooltip
  content={<ChartTooltipContent labelKey="visitors" nameKey="browser" />}
/>
```

برچسب `کل بازدیدکنندگان` و نام‌های `کروم` و `سافاری` نمایش داده می‌شود.
