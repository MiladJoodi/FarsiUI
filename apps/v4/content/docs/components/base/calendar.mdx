## منطقه زمانی

</div>

<DocsCollapsible title="منطقه زمانی">

کامپوننت `Calendar` از prop به نام `timeZone` پشتیبانی می‌کند تا تاریخ‌ها بر اساس منطقهٔ زمانی محلی کاربر نمایش داده و انتخاب شوند.

```tsx showLineNumbers
export function CalendarWithTimezone() {
  const [date, setDate] = React.useState<Date | undefined>(undefined)
  const [timeZone, setTimeZone] = React.useState<string | undefined>(undefined)

  React.useEffect(() => {
    setTimeZone(Intl.DateTimeFormat().resolvedOptions().timeZone)
  }, [])

  return (
    <Calendar
      mode="single"
      selected={date}
      onSelect={setDate}
      timeZone={timeZone}
    />
  )
}
```

**نکته:** اگر تاریخ انتخاب‌شده یک روز جابه‌جا نمایش داده می‌شود (مثلاً با انتخاب ۲۰ام، ۱۹ام هایلایت می‌شود)، `timeZone` را روی منطقهٔ زمانی محلی کاربر تنظیم کنید.

**چرا سمت کلاینت؟** منطقهٔ زمانی با `Intl.DateTimeFormat().resolvedOptions().timeZone` داخل `useEffect` خوانده می‌شود تا با SSR سازگار باشد. تشخیص منطقهٔ زمانی هنگام رندر می‌تواند باعث ناسازگاری هیدراته شود، چون منطقهٔ زمانی سرور و کلاینت ممکن است متفاوت باشد.

</DocsCollapsible>

### پشتیبانی RTL

اگر از نسخهٔ قبلی `Calendar` استفاده می‌کنید، برای پشتیبانی از locale تغییرات زیر را اعمال کنید:

<Steps>

<Step>نوع `Locale` را import کنید</Step>

نوع `Locale` را به importهای `react-day-picker` اضافه کنید:

```diff
  import {
    DayPicker,
    getDefaultClassNames,
    type DayButton,
+   type Locale,
  } from "react-day-picker"
```

<Step>prop `locale` را به `Calendar` اضافه کنید</Step>

```diff
  function Calendar({
    className,
    classNames,
    showOutsideDays = true,
    captionLayout = "label",
    buttonVariant = "ghost",
+   locale,
    formatters,
    components,
    ...props
  }: React.ComponentProps<typeof DayPicker> & {
    buttonVariant?: React.ComponentProps<typeof Button>["variant"]
  }) {
```

<Step>`locale` را به `DayPicker` بدهید</Step>

```diff
    <DayPicker
      showOutsideDays={showOutsideDays}
      className={cn(...)}
      captionLayout={captionLayout}
+     locale={locale}
      formatters={{
        formatMonthDropdown: (date) =>
-         date.toLocaleString("default", { month: "short" }),
+         date.toLocaleString(locale?.code, { month: "short" }),
        ...formatters,
      }}
```

<Step>`locale` را در `CalendarDayButton` دریافت کنید</Step>

```diff
  function CalendarDayButton({
    className,
    day,
    modifiers,
+   locale,
    ...props
- }: React.ComponentProps<typeof DayButton>) {
+ }: React.ComponentProps<typeof DayButton> & { locale?: Partial<Locale> }) {
```

<Step>فرمت تاریخ را در `CalendarDayButton` به‌روز کنید</Step>

```diff
    <Button
      variant="ghost"
      size="icon"
-     data-day={day.date.toLocaleDateString()}
+     data-day={day.date.toLocaleDateString(locale?.code)}
      ...
    />
```

<Step>`locale` را به `DayButton` منتقل کنید</Step>

```diff
      components={{
        ...
-       DayButton: CalendarDayButton,
+       DayButton: ({ ...props }) => (
+         <CalendarDayButton locale={locale} {...props} />
+       ),
        ...
      }}
```

<Step>کلاس‌های CSS را برای RTL به‌روز کنید</Step>

در کلاس‌های `day`:

```diff
- [&:last-child[data-selected=true]_button]:rounded-r-(--cell-radius)
+ [&:last-child[data-selected=true]_button]:rounded-e-(--cell-radius)

- [&:nth-child(2)[data-selected=true]_button]:rounded-l-(--cell-radius)
+ [&:nth-child(2)[data-selected=true]_button]:rounded-s-(--cell-radius)

- [&:first-child[data-selected=true]_button]:rounded-l-(--cell-radius)
+ [&:first-child[data-selected=true]_button]:rounded-s-(--cell-radius)
```

در کلاس‌های `range_start`:

```diff
- rounded-l-(--cell-radius) ... after:right-0
+ rounded-s-(--cell-radius) ... after:end-0
```

در کلاس‌های `range_end`:

```diff
- rounded-r-(--cell-radius) ... after:left-0
+ rounded-e-(--cell-radius) ... after:start-0
```

در کلاس `CalendarDayButton`:

```diff
- data-[range-end=true]:rounded-r-(--cell-radius)
+ data-[range-end=true]:rounded-e-(--cell-radius)

- data-[range-start=true]:rounded-l-(--cell-radius)
+ data-[range-start=true]:rounded-s-(--cell-radius)
```

</Steps>
