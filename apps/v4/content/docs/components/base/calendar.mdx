اگر به تقویم میلادی نیاز دارید، در `components/ui/calendar.tsx` ایمپورت `DayPicker` را به نسخه معمولی تغییر دهید:

## منطقه زمانی

</div>

<DocsCollapsible title="منطقه زمانی">

با prop به نام `timeZone` می‌توانید منطقه زمانی مورد استفاده برای نمایش و انتخاب تاریخ را مشخص کنید.

اگر تاریخ انتخاب‌شده یک روز جابه‌جا نمایش داده می‌شود، `timeZone` را روی منطقه زمانی محلی کاربر تنظیم کنید.

برای سازگاری با SSR، منطقه زمانی داخل `useEffect` از طریق `Intl.DateTimeFormat().resolvedOptions().timeZone` دریافت می‌شود. این کار از ناسازگاری بین رندر سرور و کلاینت جلوگیری می‌کند.

```tsx showLineNumbers
export function CalendarWithTimezone() {
  const [date, setDate] = React.useState<Date | undefined>(undefined)
  const [timeZone, setTimeZone] = React.useState<string | undefined>(undefined)

  React.useEffect(() => {
    setTimeZone(Intl.DateTimeFormat().resolvedOptions().timeZone)
  }, [])

  return (
    <Calendar
      mode="single"
      selected={date}
      onSelect={setDate}
      timeZone={timeZone}
    />
  )
}
```

</div>

<DocsCollapsible title="اندازه سلول">

اندازه سلول‌های تقویم را با متغیر CSS به نام `--cell-size` تنظیم کنید. می‌توانید برای breakpointهای مختلف اندازه‌های متفاوتی تعیین کنید.

```tsx showLineNumbers

  mode="single"
  selected={date}
  onSelect={setDate}
  className="rounded-lg border [--cell-size:--spacing(11)] md:[--cell-size:--spacing(12)]"
/>
```
