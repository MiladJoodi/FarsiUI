`DirectionProvider` جهت متن (`ltr` یا `rtl`) را برای اپ تنظیم می‌کند. برای زبان‌های راست‌چین مثل فارسی ضروری است.

پیش‌نمایش چند کامپوننت در حالت RTL:

## استفاده

```tsx showLineNumbers
import { DirectionProvider } from "@/components/ui/direction"
```

```tsx showLineNumbers
<html dir="rtl">
  <body>
    <DirectionProvider direction="rtl">
      {/* محتوای اپ */}
    </DirectionProvider>
  </body>
</html>
```

## useDirection

</div>

<DocsCollapsible title="useDirection">

هوک `useDirection` جهت فعلی اپ را برمی‌گرداند.

```tsx showLineNumbers
import { useDirection } from "@/components/ui/direction"

function MyComponent() {
  const direction = useDirection()
  return <div>جهت فعلی: {direction}</div>
}
```

## پشتیبانی RTL

</div>

<DocsCollapsible title="پشتیبانی RTL">

روی `<html>` مقدار `dir="rtl"` بگذارید و اپ را داخل `DirectionProvider` با `direction="rtl"` بپیچید تا کامپوننت‌های Base UI جهت را درست اعمال کنند.

برای جزئیات بیشتر، [راهنمای پیکربندی RTL](/docs/rtl) را ببینید.

</DocsCollapsible>
