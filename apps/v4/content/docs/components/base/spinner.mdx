## سفارشی‌سازی

</div>

<DocsCollapsible title="سفارشی‌سازی">

با ویرایش کامپوننت `Spinner` می‌توانید آیکون پیش‌فرض را با آیکون دیگری جایگزین کنید.

<ComponentPreview
  styleName="base-nova"
  name="spinner-custom"
  direction="rtl"
/>

```tsx showLineNumbers title="components/ui/spinner.tsx"
import { cn } from "cn"
import { LoaderIcon } from "lucide-react"

function Spinner({ className, ...props }: React.ComponentProps<"svg">) {
  return (
    <LoaderIcon
      role="status"
      aria-label="در حال بارگذاری"
      className={cn("size-4 animate-spin", className)}
      {...props}
    />
  )
}

export { Spinner }
```
