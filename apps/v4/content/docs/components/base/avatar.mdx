<DocsCollapsible title="ترکیب">

برای ساخت یک آواتار، می‌توانید بخش‌های مختلف آن را به این شکل ترکیب کنید:

<div className="flex flex-col gap-3 [&_p]:my-0! [&_[data-rehype-pretty-code-figure]]:my-0!">

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

برای نمایش چند آواتار کنار هم، آن‌ها را داخل `AvatarGroup` قرار دهید:

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
└── AvatarGroupCount
```
