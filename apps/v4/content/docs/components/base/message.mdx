کامپوننت `Message` چیدمان یک پیام در گفتگو را می‌سازد؛ آواتار، تراز، هدر و فوتر را دور حباب مدیریت می‌کند.

در اپ‌های هوش مصنوعی می‌توانید مراحل استدلال، فراخوانی ابزار و پیام‌های دستیار را با `Message` نشان دهید.

## استفاده

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { Bubble, BubbleContent } from "@/components/ui/bubble"
import { Message, MessageAvatar, MessageContent } from "@/components/ui/message"
```

```tsx showLineNumbers
<Message>
  <MessageAvatar>
    <Avatar>
      <AvatarImage src="/avatars/02.png" alt="رضا" />
      <AvatarFallback>ر</AvatarFallback>
    </Avatar>
  </MessageAvatar>
  <MessageContent>
    <Bubble>
      <BubbleContent>چطور می‌تونم کمکتون کنم؟</BubbleContent>
    </Bubble>
  </MessageContent>
</Message>
```

**توجه:** `Message` چیدمان ردیف را می‌سازد — آواتار، تراز، هدر و فوتر.
خود حباب را با [`حباب`](/docs/components/bubble) داخلش بگذارید.
برای اسکرول گفتگو از [`پیمایشگر پیام`](/docs/components/message-scroller) استفاده کنید.

## قابلیت‌ها

</div>

<DocsCollapsible title="قابلیت‌ها">

- تراز `start` و `end` برای پیام طرف مقابل و پیام خودتان
- اسلات آواتار که به پایین پیام می‌چسبد و از فوتر فاصله می‌گیرد
- هدر و فوتر برای نام فرستنده، وضعیت و اقدام‌ها
- فوتر سمت همان پیام می‌ماند؛ روی `align="end"` هم درست تراز می‌شود
- `MessageGroup` برای پیام‌های پشت‌سرهم یک نفر
- استایل اضافه با `className` روی هر بخش

</DocsCollapsible>

## دسترس‌پذیری

</div>

<DocsCollapsible title="دسترس‌پذیری">

`Message` فقط چیدمان را می‌سازد؛ دسترس‌پذیری از محتوایی که داخلش می‌گذارید می‌آید.

### برچسب اقدام‌های فقط‌آیکون

دکمه‌های فوتر معمولاً فقط آیکون‌اند؛ به هرکدام `aria-label` بدهید.

```tsx showLineNumbers
<MessageFooter>
  <Button variant="ghost" size="icon" aria-label="کپی">
    <CopyIcon />
  </Button>
</MessageFooter>
```

### به‌روزرسانی وضعیت

برای پیام در حال انجام، از [`نشانگر`](/docs/components/marker) با `role="status"` استفاده کنید تا صفحه‌خوان وضعیت را اعلام کند.

```tsx showLineNumbers
<Message>
  <Marker role="status">
    <MarkerIcon>
      <Spinner />
    </MarkerIcon>
    <MarkerContent>در حال چک کردن لاگ‌ها...</MarkerContent>
  </Marker>
</Message>
```
