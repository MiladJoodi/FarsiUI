کامپوننت `Message` چیدمان یک پیام در گفتگو را می‌سازد؛ آواتار، تراز، هدر و فوتر را اطراف سطح پیام مدیریت می‌کند.

در اپ‌های هوش مصنوعی می‌توانید مراحل استدلال، فراخوانی ابزار و پیام‌های دستیار را با `Message` رندر کنید.

## استفاده

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { Bubble, BubbleContent } from "@/components/ui/bubble"
import { Message, MessageAvatar, MessageContent } from "@/components/ui/message"
```

```tsx showLineNumbers
<Message>
  <MessageAvatar>
    <Avatar>
      <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
      <AvatarFallback>CN</AvatarFallback>
    </Avatar>
  </MessageAvatar>
  <MessageContent>
    <Bubble>
      <BubbleContent>چطور می‌توانم کمکتان کنم؟</BubbleContent>
    </Bubble>
  </MessageContent>
</Message>
```

**توجه:** `Message` مالک چیدمان ردیف است — آواتار، تراز، هدر و فوتر.
سطح دیده‌شدهٔ پیام را داخل آن با [`حباب`](/docs/components/bubble) رندر کنید.
برای ظرف اسکرول اطراف گفتگو از
[`پیمایشگر پیام`](/docs/components/message-scroller) استفاده کنید.

## قابلیت‌ها

</div>

<DocsCollapsible title="قابلیت‌ها">

- تراز شروع و پایان برای ردیف فرستنده و گیرنده با prop به نام `align`
- اسلات آواتار که به پایین پیام لنگر می‌شود و از فوتر فاصله می‌گیرد
- اسلات هدر و فوتر برای نام فرستنده، وضعیت و اقدام‌های پیام
- فوتر سمت پیام را دنبال می‌کند؛ اقدام‌ها روی ردیف‌های `align="end"` تراز می‌مانند
- ظرف گروه برای چیدن پیام‌های پشت‌سرهم یک فرستنده
- استایل‌دهی سفارشی از طریق `className` روی هر بخش

</DocsCollapsible>

## دسترس‌پذیری

</div>

<DocsCollapsible title="دسترس‌پذیری">

`Message` یک ظرف چیدمان نمایشی است. دسترس‌پذیری از محتوایی که داخلش می‌گذارید می‌آید.

### برچسب اقدام‌های فقط‌آیکون

دکمه‌های اقدام در `MessageFooter` معمولاً فقط‌آیکون‌اند؛ به هرکدام `aria-label` بدهید.

```tsx showLineNumbers
<MessageFooter>
  <Button variant="ghost" size="icon" aria-label="کپی">
    <CopyIcon />
  </Button>
</MessageFooter>
```

### به‌روزرسانی وضعیت

برای پیام‌های در حال انجام، از [`نشانگر`](/docs/components/marker) با `role="status"` استفاده کنید تا فناوری کمکی به‌روزرسانی را اعلام کند.

```tsx showLineNumbers
<Message>
  <Marker role="status">
    <MarkerIcon>
      <Spinner />
    </MarkerIcon>
    <MarkerContent>در حال بررسی لاگ‌ها...</MarkerContent>
  </Marker>
</Message>
```
