## استفاده

```tsx showLineNumbers
import {
  Field,
  FieldContent,
  FieldDescription,
  FieldError,
  FieldGroup,
  FieldLabel,
  FieldLegend,
  FieldSeparator,
  FieldSet,
  FieldTitle,
} from "@/components/ui/field"
```

```tsx showLineNumbers
<FieldSet>
  <FieldLegend>پروفایل</FieldLegend>
  <FieldDescription>این در فاکتور و ایمیل نمایش داده می‌شود.</FieldDescription>
  <FieldGroup>
    <Field>
      <FieldLabel htmlFor="name">نام کامل</FieldLabel>
      <Input id="name" autoComplete="off" placeholder="علی رضایی" />
      <FieldDescription>این در فاکتور و ایمیل نمایش داده می‌شود.</FieldDescription>
    </Field>
    <Field>
      <FieldLabel htmlFor="username">نام کاربری</FieldLabel>
      <Input id="username" autoComplete="off" aria-invalid />
      <FieldError>نام کاربری دیگری انتخاب کنید.</FieldError>
    </Field>
    <Field orientation="horizontal">
      <Switch id="newsletter" />
      <FieldLabel htmlFor="newsletter">عضویت در خبرنامه</FieldLabel>
    </Field>
  </FieldGroup>
</FieldSet>
```

## ترکیب

</div>

<DocsCollapsible title="ترکیب">

### Field

یک کنترل با برچسب، متن کمکی و اعتبارسنجی:

```text
Field
├── FieldLabel
├── Input / Textarea / Switch / Select
├── FieldDescription
└── FieldError
```

### FieldGroup

فیلدهای مرتبط در یک گروه. در صورت نیاز بین بخش‌ها از `FieldSeparator` استفاده کنید:

```text
FieldGroup
├── Field
│   ├── FieldLabel
│   ├── Input / Textarea / Switch / Select
│   ├── FieldDescription
│   └── FieldError
├── FieldSeparator
└── Field
    ├── FieldLabel
    └── Input / Textarea / Switch / Select
```

### FieldSet

گروه‌بندی معنایی با legend و توضیح؛ معمولاً شامل `FieldGroup`:

```text
FieldSet
├── FieldLegend
├── FieldDescription
└── FieldGroup
    ├── Field
    │   ├── FieldLabel
    │   ├── Input / Textarea / Switch / Select
    │   ├── FieldDescription
    │   └── FieldError
    └── Field
        ├── FieldLabel
        └── Input / Textarea / Switch / Select
```

</DocsCollapsible>

## آناتومی

</div>

<DocsCollapsible title="آناتومی">

خانوادهٔ `Field` برای ساخت فرم‌های دسترس‌پذیر طراحی شده. ساختار معمول یک فیلد:

```tsx showLineNumbers
<Field>
  <FieldLabel htmlFor="input-id">برچسب</FieldLabel>
  {/* Input, Select, Switch و غیره */}
  <FieldDescription>متن کمکی اختیاری.</FieldDescription>
  <FieldError>پیام اعتبارسنجی.</FieldError>
</Field>
```

- `Field` پوشش اصلی یک فیلد است.
- `FieldContent` ستون flex برای گروه‌بندی برچسب و توضیح است؛ اگر توضیح ندارید لازم نیست.
- فیلدهای مرتبط را با `FieldGroup` بپیچید و برای گروه‌بندی معنایی از `FieldSet` با `FieldLegend` استفاده کنید.

</DocsCollapsible>

## چیدمان ریسپانسیو

</div>

<DocsCollapsible title="چیدمان ریسپانسیو">

- **عمودی:** جهت پیش‌فرض؛ برچسب، کنترل و متن کمکی زیر هم — مناسب موبایل.
- **افقی:** با `orientation="horizontal"` برچسب و کنترل کنار هم. با `FieldContent` توضیحات هم‌تراز می‌مانند.
- **ریسپانسیو:** با `orientation="responsive"` چیدمان ستونی خودکار داخل والدین container-aware. روی `FieldGroup` کلاس‌های `@container/field-group` بگذارید تا در breakpointها جهت عوض شود.

## اعتبارسنجی و خطا

</div>

<DocsCollapsible title="اعتبارسنجی و خطا">

- روی `Field` مقدار `data-invalid` بگذارید تا کل بلوک حالت خطا بگیرد.
- روی خود ورودی `aria-invalid` بگذارید تا فناوری‌های کمکی مطلع شوند.
- `FieldError` را بلافاصله بعد از کنترل یا داخل `FieldContent` رندر کنید تا پیام با فیلد هم‌تراز بماند.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <FieldLabel htmlFor="email">ایمیل</FieldLabel>
  <Input id="email" type="email" aria-invalid />
  <FieldError>یک ایمیل معتبر وارد کنید.</FieldError>
</Field>
```

</DocsCollapsible>

<div className="hidden">

## دسترس‌پذیری

</div>

<DocsCollapsible title="دسترس‌پذیری">

- `FieldSet` و `FieldLegend` کنترل‌های مرتبط را برای صفحه‌کلید و فناوری‌های کمکی گروه‌بندی می‌کنند.
- `Field` با `role="group"` خروجی می‌دهد تا کنترل‌های تو در تو برچسب را از `FieldLabel` و `FieldLegend` بگیرند.
- `FieldSeparator` را کم به‌کار ببرید تا مرز بخش‌ها برای صفحه‌خوان واضح بماند.

</DocsCollapsible>
