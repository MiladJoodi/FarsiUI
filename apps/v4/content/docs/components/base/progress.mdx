## ترکیب

</div>

<DocsCollapsible title="ترکیب">

برای ساخت `Progress` از این ترکیب استفاده کنید:

```text
Progress
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

با `ProgressLabel` و `ProgressValue` برچسب و مقدار را نمایش دهید. مقدار با `locale="fa-IR"` به‌صورت پیش‌فرض فارسی است (مثلاً ۵۶٪):

```tsx showLineNumbers
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@/components/ui/progress"

;<Progress value={56} className="w-full max-w-sm">
  <ProgressLabel>پیشرفت آپلود</ProgressLabel>
  <ProgressValue />
</Progress>
```
