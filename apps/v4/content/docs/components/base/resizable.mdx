### ۲۰۲۵-۰۲-۰۲ — `react-resizable-panels` نسخهٔ ۴

به `react-resizable-panels` نسخهٔ ۴ به‌روز شد. جزئیات کامل را در [یادداشت انتشار v4.0.0](https://github.com/bvaughn/react-resizable-panels/releases/tag/4.0.0) ببینید.

اگر مستقیماً از primitiveهای `react-resizable-panels` استفاده می‌کنید، به این تغییرات توجه کنید:

| نسخهٔ ۳                      | نسخهٔ ۴                 |
| ---------------------------- | ----------------------- |
| `PanelGroup`                 | `Group`                 |
| `PanelResizeHandle`          | `Separator`             |
| prop به نام `direction`      | prop به نام `orientation` |
| `defaultSize={50}`           | `defaultSize="50%"`     |
| `onLayout`                   | `onLayoutChange`        |
| `ImperativePanelHandle`      | `PanelImperativeHandle` |
| prop به نام `ref` روی Panel  | prop به نام `panelRef`  |
| `data-panel-group-direction` | `aria-orientation`      |

<Callout>
  کامپوننت‌های wrapper در FarsiUI (`ResizablePanelGroup`، `ResizablePanel`،
  `ResizableHandle`) بدون تغییر باقی می‌مانند.
</Callout>

</DocsCollapsible>
