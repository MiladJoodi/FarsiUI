## دسترس‌پذیری

</div>

<DocsCollapsible title="دسترس‌پذیری">

`Marker` به‌صورت پیش‌فرض نمایشی است. معنای درست به نحوهٔ استفاده بستگی دارد؛ نقش را بر اساس نیت انتخاب کنید، نه یک پیش‌فرض واحد.

### وضعیت و پیشرفت

برای نشانگرهای جریانی یا پیشرفت مثل «در حال فکر کردن...» یا ابزار در حال اجرا، `role="status"` بگذارید تا فناوری کمکی به‌روزرسانی را اعلام کند. `Marker` مقدار `role` را به عنصر زیرین پاس می‌دهد.

```tsx showLineNumbers
<Marker role="status">
  <MarkerIcon>
    <Spinner />
  </MarkerIcon>
  <MarkerContent>در حال فشرده‌سازی گفتگو</MarkerContent>
</Marker>
```

### جداکننده‌های برچسب‌دار

جداکننده‌ای که متن دارد (مثل تاریخ یا برچسب بخش) نیازی به نقش ندارد. خطوط جداکننده با CSS تزئینی‌اند و متن مثل محتوای معمولی اعلام می‌شود.

```tsx showLineNumbers
<Marker variant="separator">
  <MarkerContent>امروز</MarkerContent>
</Marker>
```

<Callout>
  **توجه:** به جداکنندهٔ برچسب‌دار `role="separator"` ندهید. جداکننده نام
  دسترس‌پذیر را از `aria-label` می‌گیرد نه از متن، و محتوایش نمایشی تلقی
  می‌شود؛ پس برچسب دیده‌شده اعلام نمی‌شود. `role="separator"` را برای
  جداکننده بدون متن معنادار نگه دارید.
</Callout>

### نشانگرهای حاشیه‌دار

نشانگر حاشیه‌دار همان معنای نشانگر پیش‌فرض را دارد. حاشیهٔ پایین تزئینی است؛ بر اساس هدف نشانگر `role="status"`، `render` یا بدون نقش را انتخاب کنید.

```tsx showLineNumbers
<Marker variant="border">
  <MarkerIcon>
    <FileTextIcon />
  </MarkerIcon>
  <MarkerContent>یادداشت‌های پیاده‌سازی باز شد</MarkerContent>
</Marker>
```

### آیکون‌های تزئینی

`MarkerIcon` تزئینی است و با `aria-hidden` از فناوری کمکی پنهان می‌شود؛ معنای معنایی را `MarkerContent` مجاور می‌برد. برای نشانگر فقط‌آیکون، `aria-label` یا متن دیده‌شده بگذارید تا خالی اعلام نشود.

```tsx showLineNumbers
<Marker aria-label="همگام شد">
  <MarkerIcon>
    <CheckIcon />
  </MarkerIcon>
</Marker>
```

### نشانگرهای تعاملی

وقتی نشانگر لینک می‌دهد یا اقدامی را اجرا می‌کند، با `render` آن را به‌صورت `<button>` یا `<a>` واقعی رندر کنید تا فوکوس‌پذیر باشد و نقش درست داشته باشد. نام دسترس‌پذیر از متن نشانگر می‌آید.

```tsx showLineNumbers
<Marker render={<a href="/files" />}>
  <MarkerIcon>
    <FileTextIcon />
  </MarkerIcon>
  <MarkerContent>۴ فایل بررسی شد</MarkerContent>
</Marker>
```
