## استفاده

```tsx showLineNumbers
import { Bubble, BubbleContent, BubbleReactions } from "@/components/ui/bubble"
```

```tsx showLineNumbers
<Bubble>
  <BubbleContent>
    خروجی رجیستری را بررسی کردم و مسیر قدیمی را حذف کردم.
  </BubbleContent>
  <BubbleReactions>
    <span>👍</span>
  </BubbleReactions>
</Bubble>
```

کامپوننت `Bubble` محتوای گفتگو را داخل یک حباب نمایش می‌دهد و برای پیام‌های کوتاه، خروجی‌های ساختاریافته، نقل‌قول‌ها، پیشنهادها و واکنش‌ها مناسب است.

برای ساخت رابط‌های کامل چت، از کامپوننت [`پیام`](/docs/components/message) استفاده کنید. `Bubble` فقط خود حباب را نمایش می‌دهد؛ اطلاعاتی مثل آواتار، نام، زمان و اکشن‌های پیام را می‌توانید در `Message` قرار دهید.

## دسترس‌پذیری

</div>

<DocsCollapsible title="دسترس‌پذیری">

`Bubble` ظاهر پیام را رندر می‌کند. معنا و ساختار کلی گفتگو باید در ظرف والد مدیریت شود.

### برچسب‌گذاری واکنش‌ها

اگر واکنش‌ها فقط برای نمایش هستند، آن‌ها را با `role="img"` و یک `aria-label` توصیفی گروه‌بندی کنید تا صفحه‌خوان آن‌ها را به‌صورت یک واحد اعلام کند.

<div className="flex flex-col gap-3 [&_p]:my-0! [&_[data-rehype-pretty-code-figure]]:my-0!">

```tsx showLineNumbers
<BubbleReactions role="img" aria-label="واکنش‌ها: پسند، آتش و ۸ مورد دیگر">
  <span>👍</span>
  <span>🔥</span>
  <span>+۸</span>
</BubbleReactions>
```

اگر واکنش‌ها تعاملی هستند، از دکمه استفاده کنید و برای دکمه‌های فقط‌آیکون `aria-label` قرار دهید.

```tsx showLineNumbers
<BubbleReactions>
  <Button aria-label="پسندیدن" variant="secondary" size="icon-xs">
    <ThumbsUpIcon />
  </Button>
</BubbleReactions>
```

</div>
### حباب‌های تعاملی

برای حباب‌های قابل کلیک، با `render` آن را به یک `<button>` یا `<a>` واقعی تبدیل کنید تا فوکوس‌پذیر باشد و نقش معنایی مناسبی داشته باشد.

```tsx showLineNumbers
<Bubble variant="muted" align="end">
  <BubbleContent render={<button type="button" onClick={onReply} />}>
    رمز عبورم را فراموش کرده‌ام
  </BubbleContent>
</Bubble>
```

### معنا فراتر از رنگ

واریانت‌ها نباید تنها راه انتقال معنا باشند. برای پیام‌های مهم، در کنار رنگ از متن، تراز یا آیکون مناسب هم استفاده کنید.
