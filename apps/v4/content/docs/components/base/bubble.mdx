## استفاده

```tsx showLineNumbers
import { Bubble, BubbleContent, BubbleReactions } from "@/components/ui/bubble"
```

```tsx showLineNumbers
<Bubble>
  <BubbleContent>
    خروجی رجیستری را بررسی کردم و مسیر قدیمی را حذف کردم.
  </BubbleContent>
  <BubbleReactions>
    <span>👍</span>
  </BubbleReactions>
</Bubble>
```

کامپوننت `Bubble` محتوای گفتگو را داخل یک قاب نمایش می‌دهد و برای متن چت، خروجی‌های کوتاه و ساختاریافته، نقل‌قول، پیشنهاد و واکنش مناسب است.

برای رابط‌های کامل چت، از کامپوننت [`پیام`](/docs/components/message) استفاده کنید. `Bubble` فقط خود حباب پیام را نمایش می‌دهد؛ آواتار، نام، زمان، متادیتا و اکشن‌های پیام را داخل [`پیام`](/docs/components/message) قرار دهید.

## دسترس‌پذیری

</div>

<DocsCollapsible title="دسترس‌پذیری">

`Bubble` سطح بصری پیام را رندر می‌کند. معناشناسی سطح گفتگو را روی ظرف اطراف نگه دارید و راهنمای زیر را رعایت کنید.

### برچسب‌گذاری واکنش‌ها

واکنش‌ها به‌صورت ردیفی از ایموجی نمایش داده می‌شوند. صفحه‌خوان هر نماد را بدون زمینه می‌خواند و شمارنده‌هایی مثل `+۸` را «به‌علاوه هشت» اعلام می‌کند. ردیف را با `role="img"` و یک `aria-label` توصیفی گروه‌بندی کنید تا یک‌بار اعلام شود.

<div className="flex flex-col gap-3 [&_p]:my-0! [&_[data-rehype-pretty-code-figure]]:my-0!">

```tsx showLineNumbers
<BubbleReactions role="img" aria-label="واکنش‌ها: پسند، آتش و ۸ مورد دیگر">
  <span>👍</span>
  <span>🔥</span>
  <span>+۸</span>
</BubbleReactions>
```

اگر واکنش‌ها تعاملی‌اند، به‌جای آن دکمه بگذارید و برای دکمه‌های فقط‌آیکون `aria-label` تنظیم کنید.

```tsx showLineNumbers
<BubbleReactions>
  <Button aria-label="پسندیدن" variant="secondary" size="icon-xs">
    <ThumbsUpIcon />
  </Button>
</BubbleReactions>
```

</div>
### حباب‌های تعاملی

وقتی حباب قابل کلیک است، با prop به نام `render` آن را به‌صورت `<button>` یا `<a>` واقعی رندر کنید تا فوکوس‌پذیر باشد و نقش درست داشته باشد. نام دسترس‌پذیر از متن حباب گرفته می‌شود.

```tsx showLineNumbers
<Bubble variant="muted" align="end">
  <BubbleContent render={<button type="button" onClick={onReply} />}>
    رمز عبورم را فراموش کرده‌ام
  </BubbleContent>
</Bubble>
```

### معنا فراتر از رنگ

واریانت‌ها نقش و لحن را با رنگ نشان می‌دهند. آن‌ها را با متن، تراز یا آیکون همراه کنید تا معنا فقط با رنگ منتقل نشود. برای حباب `destructive`، زمینه خطا را در متن پیام نگه دارید.
