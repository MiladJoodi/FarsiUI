## تراز

</div>

<DocsCollapsible title="تراز">

با prop به نام `align` روی `InputGroupAddon` جایگاه addon نسبت به ورودی را تنظیم کنید.

<Callout>
  برای مدیریت درست فوکوس، `InputGroupAddon` باید همیشه بعد از
  `InputGroupInput` یا `InputGroupTextarea` در DOM قرار بگیرد. با `align`
  جایگاه بصری را تنظیم کنید.
</Callout>

### شروع خط

با `align="inline-start"` addon را در شروع ورودی قرار دهید. این مقدار پیش‌فرض است.

<Callout icon={<IconInfoCircle />} title="ناوبری فوکوس">
  برای ناوبری درست فوکوس، `InputGroupAddon` باید بعد از ورودی قرار بگیرد.
  با `align` جایگاه addon را تنظیم کنید.
</Callout>

```tsx
<InputGroupAddon align="inline-end">
  <SearchIcon />
</InputGroupAddon>
```

برای `<InputGroupInput />` از `inline-start` یا `inline-end` استفاده کنید. برای `<InputGroupTextarea />` از `block-start` یا `block-end` استفاده کنید.

`InputGroupAddon` می‌تواند چند `InputGroupButton` و آیکون داشته باشد.

```tsx
<InputGroupAddon>
  <InputGroupButton>دکمه</InputGroupButton>
  <InputGroupButton>دکمه</InputGroupButton>
</InputGroupAddon>
```
