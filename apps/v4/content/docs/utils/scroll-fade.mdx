## نصب

اگر پروژه را با **`npx farsiui@latest init`** راه‌اندازی کرده باشید، `scroll-fade` از قبل در پروژه شما وجود دارد. این Utility همراه پکیج **`farsiui`** ارائه می‌شود و CLI آن را در فایل CSS سراسری پروژه وارد می‌کند.

در غیر این صورت، پکیج **`farsiui`** را نصب کنید:

```bash
npm install farsiui
```

سپس Utilityهای مشترک را در فایل CSS سراسری پروژه وارد کنید:

```css
@import "tailwindcss";
@import "farsiui/tailwind.css";
```

## استفاده

| کلاس                                  | کاربرد                                           |
| ------------------------------------- | ------------------------------------------------ |
| **`scroll-fade`**                     | محو شدن لبه‌های عمودی و دنبال کردن موقعیت اسکرول |
| **`scroll-fade-y`**                   | مشابه `scroll-fade` برای محور عمودی              |
| **`scroll-fade-x`**                   | محو شدن لبه‌های افقی و دنبال کردن موقعیت اسکرول  |
| **`scroll-fade-t`**                   | محو شدن لبهٔ بالایی                              |
| **`scroll-fade-b`**                   | محو شدن لبهٔ پایینی                              |
| **`scroll-fade-l`**                   | محو شدن لبهٔ چپ                                  |
| **`scroll-fade-r`**                   | محو شدن لبهٔ راست                                |
| **`scroll-fade-s`**                   | محو شدن لبهٔ شروع؛ در RTL معکوس می‌شود           |
| **`scroll-fade-e`**                   | محو شدن لبهٔ پایان؛ در RTL معکوس می‌شود          |
| **`scroll-fade-<number>`**            | تعیین اندازهٔ محو شدن بر اساس spacing            |
| **`scroll-fade-[<value>]`**           | تعیین مقدار دلخواه برای اندازهٔ محو شدن          |
| **`scroll-fade-{t,b,s,e}-<number>`**  | تعیین اندازهٔ جداگانه برای هر لبه                |
| **`scroll-fade-{t,b,s,e}-[<value>]`** | تعیین مقدار دلخواه برای هر لبه                   |
| **`scroll-fade-none`**                | غیرفعال کردن افکت محو شدن                        |

کلاس **`scroll-fade`** یا **`scroll-fade-y`** را روی همان عنصری قرار دهید که قابلیت اسکرول عمودی دارد:

```tsx
<div className="scroll-fade overflow-y-auto">{/* ... */}</div>
```

افکت محو شدن با موقعیت اسکرول هماهنگ است:

- در حالت اولیه، لبهٔ بالا واضح و لبهٔ پایین محو است تا وجود محتوای بیشتر مشخص شود.
- هنگام اسکرول، محو شدن در لبهٔ بالا ظاهر می‌شود و هر دو لبه در میانهٔ مسیر محو می‌مانند.
- در انتهای محتوا، لبهٔ پایین دوباره واضح می‌شود.

این افکت با **`mask-image`** اعمال می‌شود؛ بنابراین خود محتوا را محو می‌کند و روی آن یک رنگ قرار نمی‌دهد. ماسک از یک طیف شفاف تا مشکی استفاده می‌کند و با هر پس‌زمینه‌ای سازگار است.

اگر ناحیهٔ اسکرول داخل یک Card قرار دارد، پس‌زمینه و Border را روی Wrapper قرار دهید و **`scroll-fade`** را روی اسکرولر داخلی بگذارید تا افکت فقط محتوای داخلی را محو کند.

کامپوننت‌های [**`ScrollArea`**](/docs/components/scroll-area) و [**`MessageScroller`**](/docs/components/message-scroller) نیز می‌توانند از `scroll-fade` روی Viewport قابل اسکرول خود استفاده کنند.

## بدون Overflow، بدون محو شدن

اگر محتوا از اندازهٔ کانتینر بیشتر نباشد، هیچ افکت محوی نمایش داده نمی‌شود. بنابراین می‌توانید `scroll-fade` را روی هر لیستی قرار دهید و نیازی نیست ابتدا بررسی کنید که قابل اسکرول است یا نه.

## اسکرول افقی

برای کانتینرهایی که به‌صورت افقی اسکرول می‌شوند، یعنی دارای **`overflow-x-auto`** هستند، از **`scroll-fade-x`** استفاده کنید.

<ComponentPreview
  styleName="base-rhea"
  name="scroll-fade-horizontal"
  previewClassName="h-64"
/>

```tsx
<div className="flex scroll-fade-x overflow-x-auto">{/* ... */}</div>
```

محو شدن افقی با جهت متن هماهنگ است. در Layoutهای RTL، لبهٔ واضح و محو به‌صورت خودکار با جهت خواندن جابه‌جا می‌شوند و نیازی به کلاس اضافی نیست.

کلاس‌های **`scroll-fade-<number>`** و **`scroll-fade-none`** نیز برای هر دو محور به یک شکل کار می‌کنند.

## محو شدن لبه‌ها

وقتی فقط می‌خواهید یک لبه موقعیت اسکرول را دنبال کند، از Utilityهای مخصوص لبه استفاده کنید.

<ComponentPreview
  styleName="base-rhea"
  name="scroll-fade-edge"
  previewClassName="h-auto"
/>

```tsx
<div className="scroll-fade-b overflow-y-auto">{/* ... */}</div>
```

Utilityهای لبه نیز با موقعیت اسکرول هماهنگ هستند. لبهٔ شروع پس از فاصله گرفتن از ابتدای محتوا محو می‌شود و لبهٔ پایان هنگام نزدیک شدن به انتهای محتوا از حالت محو خارج می‌شود.

برای لبه‌های فیزیکی از **`scroll-fade-t`**، **`scroll-fade-b`**، **`scroll-fade-l`** و **`scroll-fade-r`** استفاده کنید.

برای لبه‌های منطقی در محور Inline که در RTL نیز به‌صورت خودکار معکوس می‌شوند، از **`scroll-fade-s`** و **`scroll-fade-e`** استفاده کنید.

## اندازهٔ محو شدن

عمق محو شدن به‌صورت پیش‌فرض **`12%`** از اندازهٔ کانتینر است و حداکثر تا **`40px`** محدود می‌شود تا در اسکرولرهای بلند نیز ظریف باقی بماند.

با **`scroll-fade-<number>`** می‌توانید اندازهٔ ثابتی را بر اساس مقیاس Spacing تعیین کنید؛ مشابه نحوهٔ کار **`scroll-mt-<number>`**.

<ComponentPreview
  styleName="base-rhea"
  name="scroll-fade-size"
  previewClassName="h-auto"
/>

```tsx
<div className="scroll-fade overflow-y-auto scroll-fade-24">{/* ... */}</div>
```

برای مقدارهای دلخواه می‌توانید از مقدار Arbitrary به‌صورت طول یا درصد استفاده کنید:

```tsx
<div className="scroll-fade overflow-y-auto scroll-fade-[15%]">{/* ... */}</div>
```

برای تعیین اندازهٔ متفاوت در لبه‌های مختلف، از Modifierهای **`scroll-fade-t-<number>`**، **`scroll-fade-b-<number>`**، **`scroll-fade-s-<number>`** و **`scroll-fade-e-<number>`** استفاده کنید.

این Modifierها مقدار **`scroll-fade-<number>`** را برای لبهٔ موردنظر Override می‌کنند و مقدار Arbitrary نیز می‌پذیرند:

```tsx
<div className="scroll-fade overflow-y-auto scroll-fade-b-8 scroll-fade-t-2">
  {/* ... */}
</div>
```

برای اسکرولرهای افقی از Modifierهای منطقی **`s`** و **`e`** استفاده کنید تا اندازه‌ها در RTL نیز به‌درستی معکوس شوند.

افکت محو شدن به‌صورت تدریجی ظاهر و ناپدید می‌شود و ناگهان تغییر نمی‌کند. این فاصله توسط متغیر **`--scroll-fade-reveal`** کنترل می‌شود که مقدار پیش‌فرض آن **`96px`** است و مستقل از عمق محو شدن عمل می‌کند.

برای نمایش سریع‌تر، مقدار آن را کاهش دهید و برای انتقال تدریجی‌تر، مقدار بیشتری قرار دهید:

```tsx
<div className="scroll-fade overflow-y-auto [--scroll-fade-reveal:64px]">
  {/* ... */}
</div>
```

## غیرفعال کردن محو شدن

برای حذف افکت از **`scroll-fade-none`** استفاده کنید. این کلاس مستقل از ترتیب کلاس‌ها عمل می‌کند و برای حالت‌های Responsive یا Stateful مناسب است:

```tsx
<div className="scroll-fade overflow-y-auto md:scroll-fade-none">
  {/* ... */}
</div>
```

## Fallback

رفتار هوشمند اسکرول با استفاده از [**CSS Scroll-Driven Animations**](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_scroll-driven_animations) پیاده‌سازی شده و به JavaScript یا Scroll Listener نیاز ندارد.

در مرورگرهایی که از Scroll-Driven Animations پشتیبانی نمی‌کنند، `scroll-fade` به یک محوشدن ثابت در هر دو لبه تبدیل می‌شود و Utilityهای لبه نیز به محوشدن ثابت در لبهٔ انتخاب‌شده برمی‌گردند.

از آنجا که Mask مستقیماً روی کانتینر اسکرول اعمال می‌شود، Scrollbar قابل مشاهده نیز در لبه‌ها همراه محتوا محو می‌شود. اگر می‌خواهید Scrollbar را کاملاً مخفی کنید، **`scroll-fade`** را با **`no-scrollbar`** که در همین پکیج ارائه شده ترکیب کنید.

## RTL

**`scroll-fade-x`** جهت خواندن را دنبال می‌کند. در حالت اولیه، لبهٔ شروع واضح و لبهٔ پایان محو است. در Layoutهای RTL، این حالت به‌صورت خودکار معکوس می‌شود؛ یعنی لبهٔ راست واضح و لبهٔ چپ محو خواهد بود.
