description: استفاده از FarsiUI در پروژه‌های JavaScript.
---

FarsiUI و کامپوننت‌های آن با TypeScript نوشته شده‌اند و اگر امکانش را دارید، پیشنهاد می‌کنیم پروژه خود را هم با TypeScript توسعه دهید.

با این حال، اگر پروژه شما JavaScript است، می‌توانید نسخه JavaScript کامپوننت‌ها را با استفاده از CLI دریافت کنید.

## استفاده از JavaScript

برای استفاده از نسخه JavaScript، مقدار `tsx` را در فایل `components.json` روی `false` قرار دهید.

```json {4} title="components.json" showLineNumbers
{
  "style": "default",
  "rsc": true,
  "tsx": false,
  "tailwind": {
    "config": "",
    "css": "src/app/globals.css",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  }
}
```

بعد از این تغییر، CLI فایل‌های کامپوننت را با پسوند JavaScript تولید می‌کند.

## تنظیم aliasها

اگر در پروژه JavaScript خود از import alias استفاده می‌کنید، می‌توانید مسیرها را در `jsconfig.json` مشخص کنید.

```json {4} title="jsconfig.json" showLineNumbers
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

با این تنظیم، می‌توانید به‌جای مسیرهای نسبی طولانی از aliasهایی مانند `@/components` و `@/lib` استفاده کنید.

<Callout>
  استفاده از JavaScript نیازی به تغییر ساختار کامپوننت‌ها ندارد. تنها کافی است
  `tsx` را در `components.json` غیرفعال کنید.
</Callout>
