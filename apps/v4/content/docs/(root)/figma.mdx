<Callout>
  فایل‌های معرفی‌شده در این صفحه توسط جامعه و تیم‌های مستقل ساخته شده‌اند و بخشی
  از FarsiUI نیستند. برای پرسش‌ها یا بازخورد درباره هر فایل، با سازنده همان فایل
  در ارتباط باشید.

## ساخت فایل Figma برای FarsiUI

اگر قصد دارید یک فایل Figma اختصاصی برای FarsiUI ایجاد کنید، می‌توانید کامپوننت‌های Figma را بر اساس API و Design Tokenهای FarsiUI طراحی کنید.

در این حالت، بهتر است نام‌گذاری Variantها، اندازه‌ها، رنگ‌ها، Radius و Typography با پیاده‌سازی واقعی FarsiUI هماهنگ باشند.
