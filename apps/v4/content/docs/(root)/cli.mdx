## init

از دستور `init` برای راه‌اندازی FarsiUI در یک پروژه موجود استفاده کنید.

این دستور وابستگی‌های موردنیاز را نصب می‌کند و تنظیمات اولیه FarsiUI را انجام می‌دهد.

```bash
npx farsiui@latest init
```

اگر پروژه جدیدی دارید، ابتدا پروژه Next.js خود را ایجاد کنید و سپس FarsiUI را به آن اضافه کنید.

## add

از دستور `add` برای اضافه کردن کامپوننت‌های FarsiUI به پروژه استفاده کنید.

```bash
npx farsiui@latest add button
```

می‌توانید چند کامپوننت را هم‌زمان اضافه کنید:

```bash
npx farsiui@latest add button card dialog
```

کامپوننت‌ها به‌صورت مستقیم وارد پروژه شما می‌شوند و می‌توانید کد آن‌ها را مطابق نیاز پروژه تغییر دهید.

### Options

```bash
Usage: farsiui add [options] [components...]

Add components to your project

Arguments:
  components       نام کامپوننت‌ها

Options:
  -y, --yes        رد کردن تأیید
  -o, --overwrite  بازنویسی فایل‌های موجود
  -c, --cwd <cwd>  مسیر پروژه
  -a, --all        اضافه کردن تمام کامپوننت‌ها
  -h, --help       نمایش راهنمای دستور
```

## build

از دستور `build` برای ساخت فایل‌های Registry استفاده کنید.

```bash
npx farsiui@latest build
```

این دستور فایل Registry پروژه را پردازش کرده و فایل‌های JSON موردنیاز را تولید می‌کند.

برای تعیین مسیر خروجی می‌توانید از `--output` استفاده کنید:

```bash
npx farsiui@latest build --output ./public/registry
```

### Options

```bash
Usage: farsiui build [options]

Build components for a FarsiUI registry

Options:
  -o, --output <path>  مسیر خروجی فایل‌های Registry
  -c, --cwd <cwd>      مسیر پروژه
  -h, --help           نمایش راهنمای دستور
```

## help

برای مشاهده فهرست دستورات و گزینه‌های CLI می‌توانید از `--help` استفاده کنید:

```bash
npx farsiui@latest --help
```

برای مشاهده راهنمای یک دستور مشخص:

```bash
npx farsiui@latest add --help
```

## مسیر پروژه

تمام دستورات CLI به‌صورت پیش‌فرض در مسیر فعلی اجرا می‌شوند.

اگر می‌خواهید دستور را روی پروژه‌ای در مسیر دیگری اجرا کنید، از گزینه `--cwd` استفاده کنید:

```bash
npx farsiui@latest add button --cwd ./my-app
```

این گزینه مخصوصاً در پروژه‌های Monorepo برای مشخص کردن workspace موردنظر کاربردی است.
