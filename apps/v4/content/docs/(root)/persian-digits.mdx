در FarsiUI ارقام فارسی پیش‌فرض محتوای فارسی هستند. جهت متن (`dir`) و سبک ارقام دو مفهوم جدا هستند.

## قانون اصلی

متن معمولی فارسی باید ارقام فارسی نشان دهد:

```tsx
<p>این محصول در سال 2026 منتشر شد.</p>
```

نمایش:

```text
این محصول در سال ۲۰۲۶ منتشر شد.
```

این رفتار برای عنوان، توضیح، پاراگراف، فهرست، جدول، دکمه، برچسب، Pagination، مستندات و محتوای مشابه اعمال می‌شود.

## جهت و سبک ارقام مستقل‌اند

`dir="ltr"` فقط جهت را عوض می‌کند؛ ارقام را لاتین نمی‌کند.

شماره تلفن می‌تواند LTR بماند و همچنان فارسی باشد:

```tsx
<span dir="ltr">09121234567</span>
```

نمایش:

```text
۰۹۱۲۱۲۳۴۵۶۷
```

برای ارقام لاتین صریح:

```tsx
<span dir="ltr" data-persian-digits="false">2026</span>
```

نمایش:

```text
2026
```

| محتوا | جهت | ارقام |
| --- | --- | --- |
| متن فارسی معمولی | RTL | فارسی |
| فارسی با شماره تلفن | LTR | فارسی |
| متن انگلیسی (`lang="en"`) | LTR | لاتین |
| کد، URL، ایمیل | LTR | لاتین |
| عدد صریح با opt-out | هر کدام | لاتین |

## چه زمانی لاتین بماند

این موارد **هرگز** به ارقام فارسی تبدیل نمی‌شوند:

- `code`، `pre`، `kbd`، `samp`
- نمونه کد JSX / TypeScript / JavaScript / JSON / CSS
- دستورهای CLI
- مسیر فایل
- URL
- آدرس ایمیل
- نام پکیج و شناسه‌های API
- هر عنصری با `data-persian-digits="false"` یا `lang="en"`

مثال:

```tsx
const year = 2026
```

باید دقیقاً همان `2026` بماند.

```text
https://example.com/2026
test2026@example.com
```

همچنین لاتین می‌مانند.

## Input و Textarea

در زمینهٔ فارسی، فیلدهای متنی ارقام را فارسی **نمایش** می‌دهند، ولی مقدار منطقی فرم ASCII می‌ماند:

- نمایش: `شماره سفارش ۱۲۳۴۵`
- مقدار واقعی: `شماره سفارش 12345`

برای این نوع‌ها تبدیل ارقام خاموش است:

- `email`
- `password`
- `url`
- `file`
- ورودی‌های مخفی / فنی

`tel` به‌تنهایی جهت یا سبک ارقام را تعیین نمی‌کند؛ می‌توانید `dir="ltr"` بگذارید و همچنان ارقام فارسی داشته باشید.

جزئیات Input را در [ورودی](/docs/components/base/input#اعداد-فارسی) ببینید.

## کنترل صریح

```tsx
{/* خاموش کردن تبدیل در یک زیردرخت */}
<span data-persian-digits="false">2026</span>

{/* یا روی Input / Textarea */}
<Input persianDigits={false} />
<Textarea persianDigits={false} />
```

`persianDigits="auto"` (پیش‌فرض) در زمینهٔ فارسی فعال است.

## خلاصه

1. متن فارسی معمولی → ارقام فارسی
2. `dir="ltr"` → فقط جهت، نه سبک ارقام
3. کد، URL، ایمیل، پکیج → همیشه لاتین
4. لاتین صریح → `data-persian-digits="false"` یا `lang="en"`
5. فرم‌ها → نمایش فارسی، مقدار ASCII
