Here are a few things you can do to get started building with FarsiUI.

## Add Components

Use the CLI to add components to your project.

```bash
npx farsiui@latest add button
```

Then import and use it in your code.

```tsx title="app/page.tsx"
import { Button } from "@/components/ui/button"

export default function Home() {
  return <Button>Click me</Button>
}
```

Unlike traditional component libraries, FarsiUI adds the component source code directly to your project under `components/ui/`. You own the code and can customize it however you want.

You can add multiple components at once or add all available components.

```bash
npx farsiui@latest add button card input label
```

```bash
npx farsiui@latest add --all
```

Browse all components on the [Components](/docs/components) page.

## Customize Your Theme

You can edit your theme directly in your CSS file. Learn more about [Theming](/docs/theming) and how to use CSS variables or utility classes.

If you want to try a new preset, you can create a custom theme and apply it to your project using a preset code. See [Theming](/docs/theming) for details.

```bash
npx farsiui@latest init --preset [CODE]
```

## Add a block

You can add a block to your project using the CLI.

```bash
npx farsiui@latest add login-03
```

This will add the `login-03` block to your project. Import and use it in your code.

```tsx title="app/page.tsx"
import { Login03 } from "@/components/login-03"

export default function Home() {
  return <Login03 />
}
```

## Install from Registries

FarsiUI works with a growing ecosystem of community registries. You can install components from any registry URL using the CLI.

```bash
npx farsiui@latest add @[registry]/[name]
```

## Use AI to Build

FarsiUI is designed to work with AI. Your AI assistant can read the component source code in your project, understand the APIs, and compose them together to build pages and features.

Here are some example prompts to try:

- _"Create a signup page with a form for entering name, email and password."_
- _"Create a settings page with a form for updating profile information."_
- _"Build a dashboard with a header, stats cards, and a data table."_

## Install FarsiUI Skills

Install FarsiUI skills in your AI assistant for Persian UI copy, RTL patterns, Jalali calendar, and more. Browse them on the [Skills](/skills) page.

```bash
npx farsiui@latest add persian-conversational
```

## Connect the MCP Server

The FarsiUI MCP server gives your AI assistant access to the full component registry, documentation, and search. Connect it in your editor for the best experience.

```bash
npx farsiui@latest mcp init
```

Learn more on the [MCP Server](/docs/mcp) page.
