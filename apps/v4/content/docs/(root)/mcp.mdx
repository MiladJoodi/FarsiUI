---

سرور MCP به دستیارهای هوش مصنوعی اجازه می‌دهد با آیتم‌های رجیستری‌ها تعامل داشته باشند. می‌توانید کامپوننت‌های موجود را ببینید، کامپوننت موردنظر را جست‌وجو کنید و مستقیماً با استفاده از زبان طبیعی آن‌ها را به پروژه اضافه کنید.

برای مثال، می‌توانید از دستیار هوش مصنوعی بخواهید:

- «با استفاده از کامپوننت‌های رجیستری FarsiUI یک صفحهٔ فرود بساز.»
- «یک فرم ورود از رجیستری FarsiUI پیدا کن.»

رجیستری‌ها در فایل `components.json` پروژه پیکربندی می‌شوند.

```json title="components.json" showLineNumbers
{
  "registries": {
    "@acme": "https://acme.com/r/{name}.json"
  }
}
```

## MCP چیست؟

[**Model Context Protocol (MCP)**](https://modelcontextprotocol.io) یک پروتکل باز است که به دستیارهای هوش مصنوعی اجازه می‌دهد به‌صورت امن به منابع داده و ابزارهای خارجی متصل شوند.

با سرور MCP مربوط به FarsiUI، دستیار هوش مصنوعی می‌تواند مستقیماً به قابلیت‌های زیر دسترسی داشته باشد:

- **مشاهدهٔ کامپوننت‌ها** — فهرست کامپوننت‌ها، بلوک‌ها و قالب‌های موجود در رجیستری‌های پیکربندی‌شده.
- **جست‌وجو در رجیستری‌ها** — پیدا کردن کامپوننت‌ها بر اساس نام یا کاربرد.
- **نصب با زبان طبیعی** — اضافه کردن کامپوننت‌ها با درخواست‌هایی مثل «یک فرم ورود اضافه کن».
- **پشتیبانی از چند رجیستری** — دسترسی به رجیستری‌های عمومی، خصوصی و شخص ثالث.

---

## نحوهٔ کار

سرور MCP بین دستیار هوش مصنوعی، رجیستری‌های کامپوننت و CLI مربوط به FarsiUI قرار می‌گیرد.

1. **اتصال به رجیستری** — MCP به رجیستری‌های پیکربندی‌شده متصل می‌شود.
2. **درخواست با زبان طبیعی** — نیاز خود را به زبان ساده توضیح می‌دهید.
3. **پردازش توسط هوش مصنوعی** — دستیار درخواست شما را به عملیات مناسب رجیستری تبدیل می‌کند.
4. **دریافت کامپوننت** — منابع دریافت شده و در پروژه نصب می‌شوند.

---

## رجیستری‌های پشتیبانی‌شده

سرور MCP مربوط به FarsiUI با رجیستری‌های سازگار با مشخصات FarsiUI کار می‌کند.

- **رجیستری FarsiUI** — رجیستری اصلی FarsiUI.
- **رجیستری‌های شخص ثالث** — هر رجیستری سازگار با مشخصات رجیستری FarsiUI.
- **رجیستری‌های خصوصی** — کتابخانه‌های کامپوننت داخلی شرکت‌ها.
- **رجیستری‌های نام‌دار** — چند رجیستری با استفاده از سینتکس `@namespace`.

## پیکربندی

می‌توانید از هر کلاینت MCP برای کار با سرور MCP FarsiUI استفاده کنید.

### Claude Code

برای استفاده از سرور MCP FarsiUI در Claude Code، تنظیمات زیر را در فایل `.mcp.json` پروژه قرار دهید:

```json title=".mcp.json" showLineNumbers
{
  "mcpServers": {
    "farsiui": {
      "command": "npx",
      "args": ["farsiui@latest", "mcp"]
    }
  }
}
```

پس از اضافه کردن تنظیمات، Claude Code را Restart کنید و `/mcp` را اجرا کنید. اگر وضعیت سرور `Connected` بود، اتصال برقرار شده است.

جزئیات بیشتر را در [مستندات Claude Code MCP](https://code.claude.com/docs/en/mcp) ببینید.

### Cursor

برای تنظیم MCP در Cursor، سرور FarsiUI را در فایل `.cursor/mcp.json` پروژه اضافه کنید:

```json title=".cursor/mcp.json" showLineNumbers
{
  "mcpServers": {
    "farsiui": {
      "command": "npx",
      "args": ["farsiui@latest", "mcp"]
    }
  }
}
```

سپس سرور MCP مربوط به FarsiUI را در تنظیمات Cursor فعال کنید.

بعد از فعال شدن، باید سرور FarsiUI و ابزارهای در دسترس آن را در فهرست MCP ببینید.

جزئیات بیشتر را در [مستندات Cursor MCP](https://docs.cursor.com/en/context/mcp#using-mcp-json) ببینید.

### VS Code

برای استفاده از MCP در VS Code با GitHub Copilot، فایل `.vscode/mcp.json` را به شکل زیر تنظیم کنید:

```json title=".vscode/mcp.json" showLineNumbers
{
  "servers": {
    "farsiui": {
      "command": "npx",
      "args": ["farsiui@latest", "mcp"]
    }
  }
}
```

سپس فایل `.vscode/mcp.json` را باز کنید و روی **Start** کنار سرور FarsiUI کلیک کنید.

جزئیات بیشتر را در [مستندات VS Code MCP](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) ببینید.

### Codex

<Callout>
  **نکته:** CLI مربوط به FarsiUI نمی‌تواند فایل `~/.codex/config.toml` را به‌صورت خودکار به‌روزرسانی کند. باید تنظیمات را به‌صورت دستی اضافه کنید.
</Callout>

در فایل `~/.codex/config.toml`:

```toml title="~/.codex/config.toml" showLineNumbers
[mcp_servers.farsiui]
command = "npx"
args = ["farsiui@latest", "mcp"]
```

پس از اضافه کردن تنظیمات، Codex را Restart کنید.

## پیکربندی رجیستری‌ها

سرور MCP از چند رجیستری از طریق تنظیمات `components.json` پشتیبانی می‌کند. به این ترتیب می‌توانید به رجیستری‌های خصوصی و شخص ثالث دسترسی داشته باشید.

در `components.json`:

```json title="components.json" showLineNumbers
{
  "registries": {
    "@acme": "https://registry.acme.com/{name}.json",
    "@internal": {
      "url": "https://internal.company.com/{name}.json",
      "headers": {
        "Authorization": "Bearer ${REGISTRY_TOKEN}"
      }
    }
  }
}
```

**نکته:** برای استفاده از رجیستری اصلی FarsiUI نیازی به تنظیمات اضافی نیست.

## احراز هویت

برای رجیستری‌های خصوصی که به احراز هویت نیاز دارند، متغیرهای محیطی را در `.env.local` قرار دهید:

```env title=".env.local" showLineNumbers
REGISTRY_TOKEN=your_token_here
API_KEY=your_api_key_here
```

## نمونه Promptها

بعد از راه‌اندازی سرور MCP، می‌توانید با زبان طبیعی با رجیستری‌ها تعامل داشته باشید.

### مشاهده و جست‌وجو

- همهٔ کامپوننت‌های موجود در رجیستری FarsiUI را نشان بده.
- یک فرم ورود از رجیستری FarsiUI پیدا کن.

### نصب آیتم‌ها

- کامپوننت Button را به پروژه اضافه کن.
- با استفاده از کامپوننت‌های FarsiUI یک فرم ورود بساز.
- قوانین Cursor را از رجیستری acme نصب کن.

### کار با Namespaceها

- کامپوننت‌های رجیستری acme را نشان بده.
- `@internal/auth-form` را نصب کن.
- با استفاده از بخش‌های hero، features و testimonials از رجیستری acme یک صفحهٔ فرود بساز.

## رفع مشکلات

### MCP پاسخ نمی‌دهد

اگر سرور MCP به Promptها پاسخ نمی‌دهد:

1. **تنظیمات را بررسی کنید** — مطمئن شوید سرور MCP به‌درستی پیکربندی و فعال شده است.
2. **کلاینت MCP را Restart کنید** — بعد از تغییر تنظیمات، کلاینت را دوباره اجرا کنید.
3. **نصب FarsiUI را بررسی کنید** — مطمئن شوید FarsiUI در پروژه قابل اجراست.
4. **اتصال شبکه را بررسی کنید** — مطمئن شوید به رجیستری‌های پیکربندی‌شده دسترسی دارید.

### مشکل در دسترسی به رجیستری

اگر کامپوننت‌ها از رجیستری بارگذاری نمی‌شوند:

1. `components.json` را بررسی کنید.
2. آدرس رجیستری را بررسی کنید.
3. احراز هویت رجیستری‌های خصوصی را بررسی کنید.
4. مطمئن شوید Namespace به شکل صحیح استفاده شده است؛ مانند `@namespace/component`.

### نصب کامپوننت ناموفق است

1. تنظیمات پروژه و وجود `components.json` را بررسی کنید.
2. مسیر مقصد کامپوننت‌ها را بررسی کنید.
3. دسترسی نوشتن روی پوشه‌های مقصد را بررسی کنید.
4. وابستگی‌های موردنیاز کامپوننت را بررسی کنید.

### ابزارها یا Promptها نمایش داده نمی‌شوند

اگر پیام `No tools or prompts` را مشاهده کردید:

1. کش `npx` را پاک کنید: `npx clear-npx-cache`
2. سرور MCP را دوباره فعال کنید.
3. لاگ‌های MCP را بررسی کنید. در Cursor از مسیر **View → Output** و گزینهٔ `MCP: project-*` استفاده کنید.
