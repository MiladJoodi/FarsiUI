با یک دستور، دستیار هوش مصنوعی می‌تواند کامپوننت‌های FarsiUI را پیدا و نصب کند.

## راه‌اندازی سریع

کلاینت خود را انتخاب کنید، دستور را در ریشهٔ پروژه اجرا کنید، سپس کلاینت را Restart کنید (در Cursor سرور را در تنظیمات MCP فعال کنید).

  </TabsContent>

  <TabsContent value="vscode" className="mt-4">
    ```bash
    pnpm dlx farsiui@latest mcp init --client vscode
    ```

    فایل `.vscode/mcp.json` را باز کنید و کنار سرور FarsiUI روی **Start** بزنید.

  </TabsContent>

  <TabsContent value="codex" className="mt-4">
    <Callout className="mt-0">
      CLI نمی‌تواند `~/.codex/config.toml` را خودکار بنویسد؛ باید دستی اضافه کنید.
    </Callout>

    ```bash
    pnpm dlx farsiui@latest mcp init --client codex
    ```

    در `~/.codex/config.toml`:

    ```toml
    [mcp_servers.FarsiUI]
    command = "npx"
    args = ["farsiui@latest", "mcp"]
    ```

    سپس Codex را Restart کنید.

  </TabsContent>

  <TabsContent value="opencode" className="mt-4">
    ```bash
    pnpm dlx farsiui@latest mcp init --client opencode
    ```

    سپس OpenCode را Restart کنید.

  </TabsContent>
</Tabs>

بعد از فعال‌سازی می‌توانید بگویید:

- همهٔ کامپوننت‌های FarsiUI را نشان بده.
- Button و Dialog را اضافه کن.
- با کامپوننت‌های FarsiUI یک فرم تماس بساز.

## رجیستری‌های بیشتر

</div>

<DocsCollapsible title="رجیستری شخص‌ثالث و خصوصی">

رجیستری اصلی FarsiUI بدون تنظیم اضافه کار می‌کند. برای رجیستری‌های دیگر در `components.json`:

```json title="components.json" showLineNumbers
{
  "registries": {
    "@acme": "https://registry.acme.com/{name}.json",
    "@internal": {
      "url": "https://internal.company.com/{name}.json",
      "headers": {
        "Authorization": "Bearer ${REGISTRY_TOKEN}"
      }
    }
  }
}
```

برای توکن‌ها در `.env.local`:

```env title=".env.local" showLineNumbers
REGISTRY_TOKEN=your_token_here
```

- کامپوننت Button را به پروژه اضافه کن.
- با استفاده از کامپوننت‌های FarsiUI یک فرم ورود بساز.

**Namespace**

- کامپوننت‌های رجیستری acme را نشان بده.
- `@internal/auth-form` را نصب کن.

## رفع مشکلات

</div>

<DocsCollapsible title="رفع مشکلات">

اگر MCP پاسخ نمی‌دهد:

1. تنظیمات و فعال بودن سرور را بررسی کنید.
2. کلاینت را Restart کنید.
3. مطمئن شوید `npx farsiui@latest mcp` در پروژه اجرا می‌شود.
4. اتصال شبکه به رجیستری را بررسی کنید.

اگر `No tools or prompts` دیدید:

1. `npx clear-npx-cache`
2. سرور MCP را دوباره فعال کنید.
3. در Cursor: **View → Output** و گزینهٔ `MCP: project-*`

</DocsCollapsible>

## MCP چیست؟

</div>

<DocsCollapsible title="MCP چیست و چطور کار می‌کند؟">

[Model Context Protocol (MCP)](https://modelcontextprotocol.io) پروتکلی است که دستیار هوش مصنوعی را به ابزارها و داده‌های خارجی وصل می‌کند.

با سرور FarsiUI می‌توانید:

- کامپوننت‌ها و بلوک‌های رجیستری را ببینید
- جست‌وجو کنید
- با زبان طبیعی نصب کنید
- چند رجیستری (عمومی، خصوصی، `@namespace`) داشته باشید

جریان کار: اتصال به رجیستری → درخواست شما → تبدیل به عملیات → نصب در پروژه.

- [مشخصات MCP](https://modelcontextprotocol.io/)
- [Cursor MCP](https://docs.cursor.com/en/context/mcp#using-mcp-json)
- [Claude Code MCP](https://code.claude.com/docs/en/mcp)
- [VS Code MCP](https://code.visualstudio.com/docs/copilot/chat/mcp-servers)

</DocsCollapsible>
