مارک‌داون را رندر می‌کنید و HTML ساده و بدون استایل برمی‌گردد: عنوان‌ها، پاراگراف‌ها، فهرست‌ها و جدول‌ها. پس عناصر را یکی‌یکی استایل می‌دهید: اندازهٔ فونت، ارتفاع خط، فاصله‌ها.

این کار را برای وبلاگ می‌کنید. بعد دوباره برای مستندات. بعد دوباره برای اپ چت. هر بار با همان مشکل می‌جنگید: اندازه و فاصله.

برای حل این موضوع، **FarsiUI Typeset** را ساختیم. یک فایل CSS است که همه‌چیز داخل ظرف `typeset` را استایل می‌دهد. فایل داخل پروژه شماست، پس هر وقت لازم بود مستقیم تغییرش می‌دهید.

تایپ‌ست فقط یک کلاس preset کوچک است. می‌توانید در اپ چند تایپ‌ست برای زمینه‌های مختلف داشته باشید.

```css
.typeset-docs {
  --typeset-font-body: var(--font-geist);
  --typeset-font-heading: var(--font-geist);
  --typeset-font-mono: var(--font-geist-mono);
  --typeset-size: 15px;
  --typeset-leading: 1.75;
  --typeset-flow: 1.25em;
}
```

## اصول

دربارهٔ تایپ زیاد خواندیم: نسبت مقیاس، tracking، kerning، optical sizing، measure، leading، و فضای بالا و پایین هر عنصر. سعی کردیم همه‌شان را در اختیار بگذاریم؛ زیاد بود. کسی نمی‌خواهد برای درست شدن ظاهر مارک‌داون ده‌ها متغیر تنظیم کند.

پس همه‌چیز را در سه کنترل خلاصه کردیم: اندازه، leading و flow. بقیه — اندازهٔ عنوان‌ها، تورفتگی فهرست، فاصلهٔ زیر عنوان، فضای اطراف خط افقی — از همین‌ها مشتق می‌شوند. سه کنترل. اسمش را ریتم گذاشتیم.

---

## ویژگی‌ها

- **با ظرفش هم‌خوان است.** داخل حباب چت بگذارید و از تایپ کوچک اطرافش پیروی می‌کند. داخل مقاله بگذارید و با صفحه بزرگ‌تر می‌شود. در صفحه‌های کوچک‌تر کمی بزرگ‌تر می‌شود تا خوانایی حفظ شود.
- **از تم شما استفاده می‌کند.** رنگ‌ها، فونت‌ها و radius از اپ می‌آیند. حالت تاریک همان توکن‌ها را دنبال می‌کند.
- **تنظیمش ساده است.** سه مقدار، اندازهٔ پایه، ارتفاع خط و فاصلهٔ بین بلوک‌ها را کنترل می‌کنند. در preset عوضشان کنید؛ کل سند دنبال می‌کند.
- **با استریم خوب کار می‌کند.** وقتی بلوک جدید می‌رسد، Typeset حاشیه، border یا استایل بلوک‌های قبلی را عوض نمی‌کند.

---

## ساخت تایپ‌ست

تایپ‌ست خود را در [سازندهٔ تایپ‌ست](/typeset) بسازید. فونت و ریتم را انتخاب کنید، بعد روی مستندات، چت، مقاله و محتوای واقعی دیگر پیش‌نمایش بگیرید.

پنل فایل `typeset.css`، راه‌اندازی فونت برای فریم‌ورک، کلاس preset با انتخاب‌های شما، و wrapper دور محتوا را می‌دهد.

`typeset.css` را کنار فایل CSS اصلی کپی کنید و بعد از Tailwind ایمپورت کنید:

```css
@import "tailwindcss";
@import "./typeset.css";
```

سپس مارک‌داون رندر‌شده را با `typeset` و کلاس preset بپیچید:

```tsx
<div className="typeset typeset-docs">
  <YourMarkdownRenderer>{content}</YourMarkdownRenderer>
</div>
```

`typeset` استایل‌ها را روشن می‌کند. `typeset-docs` همان presetی است که در سازنده ساختید.

## تایپ‌ست‌های سفارشی

فایل شامل مقادیر پیش‌فرض است، پس می‌توانید فقط از `typeset` استفاده کنید. بخش زیادی از ریتم خواندن از سه مقدار می‌آید:

```css
.typeset {
  --typeset-font-body: inherit;
  --typeset-font-heading: var(--font-heading);
  --typeset-font-mono: var(--font-mono);

  --typeset-size: 1em; /* اندازهٔ فونت بدنه */
  --typeset-leading: 1.75; /* ارتفاع خط */
  --typeset-flow: 1.25em; /* فاصلهٔ بین بلوک‌ها */
}
```

- **`--typeset-size`** اندازهٔ پایهٔ متن را تنظیم می‌کند. `1em` از لایهٔ اطراف پیروی می‌کند. در صفحه‌های کوچک‌تر Typeset کمی بزرگ‌ترش می‌کند.
- **`--typeset-leading`** فاصلهٔ بین خطوط را تنظیم می‌کند.
- **`--typeset-flow`** فاصلهٔ بین بلوک‌ها را تنظیم می‌کند. عنوان‌ها و عناصر دیگر فاصله‌شان را از آن می‌گیرند.

متغیرهای فونت می‌گویند Typeset از کدام خانواده استفاده کند. دست‌نخورده بگذارید تا از اپ پیروی کند. رنگ و radius هم از تم می‌آیند.

Typeset حداکثر عرض تعیین نمی‌کند؛ لایهٔ شما مالک آن است. کنترل Measure در سازنده به‌جای مخفی کردن در stylesheet، `max-width` را روی wrapper می‌گذارد.

می‌توانید چند preset در یک اپ نگه دارید. نمونهٔ فشرده‌تر برای چت و جادارتر برای مستندات:

```css
.typeset-chat {
  --typeset-flow: 1em;
  --typeset-leading: 1.6;
}

.typeset-docs {
  --typeset-size: 15px;
  --typeset-flow: 1.5em;
}
```

```tsx
<div className="typeset typeset-chat">{message}</div>
<article className="typeset typeset-docs">{page}</article>
```

برای تغییر یک‌باره، preset را رد کنید و مقدار را روی ظرف بگذارید:

```tsx
<article className="typeset [--typeset-flow:1.75em]">...</article>
```

## تم‌های سفارشی

یک preset می‌تواند حس کلی محتوا را عوض کند، نه فقط فاصله‌ها. می‌توانید حالت خواندن سریف، حالت UI فشرده، یا هر سبک دیگری که به محصول می‌خورد بدهید.

```css
/* خواندن: سریف، تایپ بزرگ‌تر، ریتم جادار. */
.typeset-reading {
  --typeset-font-body: var(--font-lora);
  --typeset-font-heading: var(--font-lora);
  --typeset-size: 18px;
  --typeset-leading: 1.9;
  --typeset-flow: 2em;
}

/* فشرده: سنس، تایپ کوچک‌تر، ریتم تنگ‌تر. */
.typeset-compact {
  --typeset-font-body: var(--font-geist);
  --typeset-font-heading: var(--font-geist);
  --typeset-size: 14px;
  --typeset-leading: 1.6;
  --typeset-flow: 1em;
}
```

## دسترسی‌پذیری و حالت تاریک

برای خوانندگانی که تایپ بزرگ‌تر و فضای بیشتر می‌خواهند، یک تایپ‌ست جادار بسازید و به‌عنوان تنظیم در اختیار بگذارید:

```css
.typeset-large {
  --typeset-size: 16px;
  --typeset-leading: 2;
  --typeset-flow: 2em;
}
```

حالت تاریک از رنگ‌های تم شما پیروی می‌کند. اگر متن روی سطح تاریک کمی تنگ به نظر می‌رسد، می‌توانید leading را آنجا بازتر کنید:

```css
.dark .typeset {
  --typeset-leading: 1.9;
}
```

---

## جدول واکنش‌گرا

جدول‌ها جدول واقعی می‌مانند و برای جا شدن می‌پیچند. برای اسکرول افقی جدول عریض، آن را در `typeset-scroll` بپیچید:

```tsx
<div className="typeset-scroll">
  <table>...</table>
</div>
```

این کار را در کامپوننت جدول رندرر یا یک پلاگین کوچک rehype انجام دهید. برای هر بلوک عریض کار می‌کند، نه فقط جدول.

---

## بازنویسی (Overrides)

Typeset در لایهٔ `components` زندگی می‌کند و برای انتخابگر عناصر از `:where()` استفاده می‌کند. utilityهای Tailwind روی عنصر بدون `!important` برنده می‌شوند:

```tsx
<div className="typeset typeset-docs">
  <p className="text-lg">...</p>
</div>
```

CSS ساده هم با یک انتخابگر معمولی Typeset را بازنویسی می‌کند.

---

## خارج شدن (Opting Out)

برای خارج کردن یک کامپوننت از Typeset، `not-typeset` یا `data-not-typeset` اضافه کنید:

```tsx
<div className="typeset">
  <p>متن استایل‌شده.</p>
  <Card className="not-typeset">کامپوننت دست‌نخورده.</Card>
</div>
```

هر دو گزینه خود کامپوننت و همه‌چیز داخلش را پوشش می‌دهند. ظرف `typeset` دیگری داخل آن زیردرخت هم خارج‌مانده می‌ماند.

---

## استریم

Typeset طوری نوشته شده که افزودن بلوک جدید استایل بلوک‌های روی صفحه را عوض نکند.

- بدون انتخابگر رو به جلو. `:last-child`، `:has()` و `:empty` از قوانین لایه کنار گذاشته شده‌اند چون با اضافه شدن محتوا ممکن است تطبیقشان عوض شود.
- فاصله فقط در یک جهت جریان دارد و از `margin-block-start` استفاده می‌کند. بلوک جدید فضای خودش را اضافه می‌کند.
- جداکننده‌های جدول روی سلول‌هایی که اضافه می‌شوند هستند، پس ردیف جدید ردیف بالایی را دوباره استایل نمی‌کند.

متنی که هنوز استریم می‌شود می‌تواند عادی رشد کند و بپیچد. Typeset فقط از استایل‌دهی دوبارهٔ بلوک‌های قبلی پرهیز می‌کند.

## پیشینه

کلاس `prose` از `@tailwindcss/typography` در کاری که برایش ساخته شده عالی است: افزودن پیش‌فرض‌های تایپوگرافی زیبا به HTML ساده، از جمله محتوای مارک‌داون یا CMS.

Typeset رویکرد دیگری دارد: اندازهٔ آگاه از ظرف، توکن‌های تم اپ، preset برای زمینه‌های مختلف، و پایداری استریم. تفاوت‌ها:

|              | @tailwindcss/typography                      | Typeset                                          |
| ------------ | -------------------------------------------- | ------------------------------------------------ |
| اندازه       | مقیاس ثابت `rem`، از `prose-sm` تا `prose-2xl` | نسبت به ظرف، هر اندازه‌ای                        |
| حالت تاریک   | `prose-invert`، پالت دوم                     | توکن‌های شما عوض می‌شوند؛ چیزی اضافه نیست        |
| تم‌دهی       | متغیرهای رنگ prose؛ مقیاس پخته‌شده           | توکن‌های تم شما، به‌همراه کنترل فونت و ریتم      |
| بازنویسی     | API مادیفایر `prose-a:` و `prose-headings:`  | utility و CSS ساده برنده می‌شوند                 |
| استریم       | بدون قرارداد پایداری append                  | برای append پایدار طراحی شده                     |
| توزیع        | پلاگین npm، CSS تولیدشده                     | یک فایل CSS که مال شماست                         |

Typeset دو ایدهٔ خوب پلاگین را وام گرفته: الگوی محافظ `:where()` با specificity صفر، و کلاس فرار (`not-typeset`، در روح `not-prose`).
