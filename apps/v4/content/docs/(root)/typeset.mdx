FarsiUI Typeset مجموعه‌ای از استایل‌های آماده برای نمایش محتوای HTML و Markdown است؛ از مقاله و مستندات گرفته تا پیام‌های چت و محتوای استریم‌شده.

وقتی Markdown را به HTML تبدیل می‌کنید، خروجی معمولاً شامل عنوان، پاراگراف، فهرست، جدول، کد و عناصر مختلف دیگری است. برای نمایش مناسب این محتوا باید اندازه فونت، فاصله، ارتفاع خط و سایر جزئیات هرکدام از این عناصر را تنظیم کنید.

Typeset این تنظیمات را یکجا انجام می‌دهد.

کافی است محتوای خود را داخل یک wrapper با کلاس `typeset` قرار دهید تا عناصر داخلی آن به‌صورت یکدست استایل شوند.

```tsx
<div className="typeset">
  <YourMarkdownRenderer>{content}</YourMarkdownRenderer>
</div>
```

تمام CSS مربوط به Typeset در اختیار شماست و می‌توانید در صورت نیاز آن را مستقیماً در پروژه تغییر دهید.

---

## اصول

به‌جای تنظیم ده‌ها مقدار مختلف برای بخش‌های مختلف تایپوگرافی، Typeset کنترل ظاهر محتوا را به سه مقدار اصلی خلاصه می‌کند:

- **Size** — اندازه پایه متن
- **Leading** — ارتفاع خطوط
- **Flow** — فاصله بین بلوک‌های محتوا

سایر فاصله‌ها و اندازه‌ها بر اساس همین مقادیر تنظیم می‌شوند. به این ترتیب می‌توانید ریتم کلی صفحه را بدون تنظیم تک‌تک عناصر کنترل کنید.

---

## ویژگی‌ها

### سازگار با اندازه ظرف

Typeset اندازه محتوا را با محیط اطراف خود هماهنگ می‌کند.

می‌توانید از یک Typeset در مقاله، مستندات یا پیام‌های چت استفاده کنید و با تغییر اندازه محیط، خوانایی محتوا حفظ می‌شود.

### هماهنگ با تم پروژه

رنگ‌ها، فونت‌ها و سایر مقادیر بصری از Design System پروژه استفاده می‌کنند.

بنابراین حالت تاریک نیز بدون نیاز به استایل جداگانه، از Theme Tokenهای پروژه پیروی می‌کند.

### تنظیم ساده

سه مقدار اصلی، ریتم محتوا را کنترل می‌کنند:

```css
.typeset {
  --typeset-size: 1em;
  --typeset-leading: 1.75;
  --typeset-flow: 1.25em;
}
```

با تغییر این مقادیر می‌توانید ظاهر کلی محتوا را تنظیم کنید.

### مناسب برای محتوای استریم‌شده

Typeset طوری طراحی شده است که با اضافه شدن محتوای جدید، استایل بلوک‌های قبلی تغییر نکند.

این ویژگی برای چت‌ها، پاسخ‌های هوش مصنوعی و سایر محتواهای Streaming کاربردی است.

---

## ساخت Typeset

می‌توانید Typeset خود را با [سازنده تایپ‌ست](/typeset) ایجاد و در محیط واقعی پیش‌نمایش کنید.

سازنده به شما امکان می‌دهد فونت، اندازه متن و ریتم محتوا را تنظیم کنید و CSS موردنیاز را دریافت کنید.

پس از ساخت Typeset، فایل CSS را در پروژه قرار دهید و آن را بعد از Tailwind وارد کنید:

```css
@import "tailwindcss";
@import "./typeset.css";
```

سپس محتوای HTML یا Markdown را داخل wrapper قرار دهید:

```tsx
<div className="typeset typeset-docs">
  <YourMarkdownRenderer>{content}</YourMarkdownRenderer>
</div>
```

کلاس `typeset` استایل‌های اصلی را فعال می‌کند و `typeset-docs` یک preset سفارشی برای همان محتواست.

---

## تایپ‌ست‌های سفارشی

اگر به تنظیمات سفارشی نیاز ندارید، می‌توانید فقط از `typeset` استفاده کنید.

```css
.typeset {
  --typeset-font-body: inherit;
  --typeset-font-heading: var(--font-heading);
  --typeset-font-mono: var(--font-mono);
  --typeset-size: 1em;
  --typeset-leading: 1.75;
  --typeset-flow: 1.25em;
}
```

### `--typeset-size`

اندازه پایه متن را مشخص می‌کند.

مقدار `1em` باعث می‌شود اندازه متن از محیط اطراف خود پیروی کند.

### `--typeset-leading`

ارتفاع خطوط متن را کنترل می‌کند.

```css
.typeset {
  --typeset-leading: 1.75;
}
```

### `--typeset-flow`

فاصله بین بلوک‌های محتوا را کنترل می‌کند.

```css
.typeset {
  --typeset-flow: 1.25em;
}
```

عنوان‌ها، پاراگراف‌ها، فهرست‌ها و سایر عناصر از این ریتم استفاده می‌کنند.

---

## چند Typeset در یک پروژه

می‌توانید برای بخش‌های مختلف پروژه presetهای متفاوتی داشته باشید.

برای مثال، یک preset فشرده برای چت و یک preset بازتر برای مستندات:

```css
.typeset-chat {
  --typeset-flow: 1em;
  --typeset-leading: 1.6;
}

.typeset-docs {
  --typeset-size: 15px;
  --typeset-flow: 1.5em;
}
```

سپس هرکدام را در محیط موردنظر استفاده کنید:

```tsx
<div className="typeset typeset-chat">
  {message}
</div>

<article className="typeset typeset-docs">
  {content}
</article>
```

برای یک تغییر موقت نیز می‌توانید مقدار را مستقیماً روی wrapper قرار دهید:

```tsx
<article className="typeset [--typeset-flow:1.75em]">
  ...
</article>
```

## فونت‌های سفارشی

می‌توانید فونت متن، عنوان‌ها و کد را برای هر preset مشخص کنید:

```css
.typeset-reading {
  --typeset-font-body: var(--font-body);
  --typeset-font-heading: var(--font-heading);
  --typeset-font-mono: var(--font-mono);
  --typeset-size: 18px;
  --typeset-leading: 1.9;
  --typeset-flow: 2em;
}
```

این امکان به شما اجازه می‌دهد برای بخش‌های مختلف محصول، تایپوگرافی متفاوتی داشته باشید، بدون اینکه CSS اصلی Typeset را تغییر دهید.

---

## عرض محتوا

Typeset حداکثر عرض محتوا را تعیین نمی‌کند.

کنترل عرض باید توسط layout یا wrapper صفحه انجام شود.

برای مثال:

```tsx
<article className="typeset mx-auto max-w-3xl">
  {content}
</article>
```

این جداسازی باعث می‌شود Typeset مسئول تایپوگرافی باشد و layout مسئول اندازه و موقعیت محتوا.

---

## دسترسی‌پذیری و حالت تاریک

اگر کاربران شما به متن بزرگ‌تر یا فاصله بیشتر نیاز دارند، می‌توانید یک preset با ریتم بازتر ایجاد کنید:

```css
.typeset-large {
  --typeset-size: 16px;
  --typeset-leading: 2;
  --typeset-flow: 2em;
}
```

حالت تاریک نیز از Theme Tokenهای پروژه استفاده می‌کند و نیازی به تعریف پالت جداگانه برای Typeset ندارد.

در صورت نیاز می‌توانید تنظیمات Typeset را در حالت تاریک تغییر دهید:

```css
.dark .typeset {
  --typeset-leading: 1.9;
}
```

---

## جدول‌های واکنش‌گرا

جدول‌ها همچنان به‌صورت جدول واقعی HTML باقی می‌مانند.

برای جدول‌های عریض که نیاز به اسکرول افقی دارند، می‌توانید از `typeset-scroll` استفاده کنید:

```tsx
<div className="typeset-scroll">
  <table>
    ...
  </table>
</div>
```

این wrapper برای سایر محتوای عریض نیز قابل استفاده است.

---

## بازنویسی استایل‌ها

استایل‌های Typeset با specificity پایین تعریف شده‌اند تا بتوانید آن‌ها را به‌راحتی در پروژه override کنید.

برای مثال، می‌توانید اندازه یک پاراگراف را با utilityهای Tailwind تغییر دهید:

```tsx
<div className="typeset typeset-docs">
  <p className="text-lg">
    ...
  </p>
</div>
```

همچنین CSS معمولی پروژه می‌تواند استایل‌های Typeset را override کند.

---

## خارج کردن محتوا از Typeset

اگر نمی‌خواهید یک کامپوننت یا بخشی از محتوا توسط Typeset استایل شود، از `not-typeset` یا `data-not-typeset` استفاده کنید:

```tsx
<div className="typeset">
  <p>این متن توسط Typeset استایل می‌شود.</p>

  <Card className="not-typeset">
    این بخش بدون استایل Typeset نمایش داده می‌شود.
  </Card>
</div>
```

این ویژگی برای کامپوننت‌هایی مفید است که باید استایل مستقل خودشان را حفظ کنند.

---

## استریم

Typeset برای محتوایی که به‌صورت تدریجی به صفحه اضافه می‌شود طراحی شده است.

برای جلوگیری از تغییر ناگهانی ظاهر محتوای قبلی:

- استایل‌ها به محتوای قبلی وابستگی ندارند.
- فاصله‌ها در یک جهت جریان محتوا اعمال می‌شوند.
- اضافه شدن یک بلوک جدید باعث محاسبه مجدد فاصله بلوک‌های قبلی نمی‌شود.
- جدول‌ها با اضافه شدن ردیف‌های جدید، استایل ردیف‌های قبلی را تغییر نمی‌دهند.

این رفتار Typeset را برای محتوای Streaming مانند چت و پاسخ‌های تولیدشده توسط AI مناسب می‌کند.

## Typeset در مقایسه با Typography

اگر قبلاً از `@tailwindcss/typography` و کلاس `prose` استفاده کرده باشید، Typeset هدف متفاوتی دارد.

| ویژگی | `@tailwindcss/typography` | FarsiUI Typeset |
| --- | --- | --- |
| اندازه متن | مقیاس‌های ثابت | قابل تنظیم بر اساس محیط |
| حالت تاریک | نیازمند `prose-invert` | استفاده از Theme Tokenهای پروژه |
| تم‌دهی | تنظیمات مخصوص Typography | هماهنگ با Theme پروژه |
| ریتم محتوا | presetهای آماده | کنترل با Size، Leading و Flow |
| استریم | تمرکز اصلی نیست | طراحی‌شده برای محتوای Streaming |
| سفارشی‌سازی | از طریق API Typography | CSS و presetهای قابل تغییر |

`@tailwindcss/typography` برای اضافه کردن استایل‌های پیش‌فرض به HTML و Markdown انتخاب مناسبی است.

FarsiUI Typeset زمانی مفید است که علاوه بر تایپوگرافی، به **کنترل ریتم محتوا، هماهنگی با Theme، presetهای مختلف و رفتار پایدار هنگام Streaming** نیاز دارید.
