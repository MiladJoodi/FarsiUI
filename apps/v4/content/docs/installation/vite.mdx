## استفاده از CLI

<Steps>

### ساخت پروژه

دستور **`init`** را اجرا کنید تا یک پروژه جدید Vite ساخته شود. در ادامه می‌توانید تنظیمات پروژه مانند base، preset، monorepo و موارد دیگر را انتخاب کنید.

```bash
npx farsiui@latest init -t vite
```

**برای پروژه‌های monorepo از فلگ `--monorepo` استفاده کنید:**

```bash
npx farsiui@latest init -t vite --monorepo
```

### افزودن کامپوننت‌ها

کامپوننت **`Card`** را به پروژه خود اضافه کنید:

```bash
npx farsiui@latest add card
```

اگر پروژه را به‌صورت monorepo ساخته‌اید، دستور را از مسیر **`apps/web`** اجرا کنید یا workspace را از ریشه پروژه مشخص کنید:

```bash
npx farsiui@latest add card -c apps/web
```

دستور بالا کامپوننت **`Card`** را به پروژه اضافه می‌کند. سپس می‌توانید آن را به شکل زیر import کنید:

```tsx showLineNumbers title="src/App.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

function App() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>نمای کلی پروژه</CardTitle>
        <CardDescription>
          پیشرفت و فعالیت‌های اخیر اپلیکیشن Vite خود را دنبال کنید.
        </CardDescription>
      </CardHeader>
      <CardContent>
        سیستم طراحی شما آماده است. ساخت کامپوننت بعدی را شروع کنید.
      </CardContent>
    </Card>
  )
}

export default App
```

اگر پروژه را به‌صورت monorepo ساخته‌اید، فایل **`apps/web/src/App.tsx`** را ویرایش کنید و کامپوننت را از **`@workspace/ui/components/card`** import کنید.

</Steps>

## پروژه موجود

<Steps>

### ساخت پروژه

اگر به یک پروژه جدید Vite نیاز دارید، ابتدا یک پروژه بسازید و قالب **React + TypeScript** را انتخاب کنید. در غیر این صورت، از این مرحله عبور کنید.

```bash
npm create vite@latest
```

### افزودن Tailwind CSS

اگر Tailwind CSS از قبل در پروژه شما پیکربندی شده است، از این مرحله عبور کنید.

```bash
npm install tailwindcss @tailwindcss/vite
```

تمام محتوای فایل **`src/index.css`** را با کد زیر جایگزین کنید:

```css title="src/index.css"
@import "tailwindcss";
```

### ویرایش فایل tsconfig.json

اگر alias مربوط به **`@/*`** از قبل در پروژه شما تنظیم شده است، از این مرحله عبور کنید.

Vite تنظیمات TypeScript را بین چند فایل تقسیم می‌کند. ویژگی‌های **`baseUrl`** و **`paths`** را به بخش **`compilerOptions`** در فایل‌های **`tsconfig.json`** و **`tsconfig.app.json`** اضافه کنید:

```ts title="tsconfig.json" {11-16} showLineNumbers
{
  "files": [],
  "references": [
    {
      "path": "./tsconfig.app.json"
    },
    {
      "path": "./tsconfig.node.json"
    }
  ],
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### ویرایش فایل tsconfig.app.json

همان alias را به **`tsconfig.app.json`** اضافه کنید تا ویرایشگر کد بتواند importها را به‌درستی تشخیص دهد:

```ts title="tsconfig.app.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### به‌روزرسانی vite.config.ts

**`@types/node`** را نصب کنید و فایل **`vite.config.ts`** را به‌روزرسانی کنید تا Vite بتواند alias مربوط به **`@`** را resolve کند:

```bash
npm install -D @types/node
```

```typescript title="vite.config.ts" showLineNumbers {1,2,8-13}
import path from "path"
import tailwindcss from "@tailwindcss/vite"
import react from "@vitejs/plugin-react"
import { defineConfig } from "vite"

// https://vite.dev/config/
export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
})
```

### اجرای CLI

دستور **`init`** را اجرا کنید تا FarsiUI در پروژه شما پیکربندی شود:

```bash
npx farsiui@latest init
```

### افزودن کامپوننت‌ها

حالا می‌توانید کامپوننت‌های موردنیاز خود را به پروژه اضافه کنید:

```bash
npx farsiui@latest add button
```

دستور بالا کامپوننت **`Button`** را به پروژه اضافه می‌کند. سپس می‌توانید آن را به شکل زیر import کنید:

```tsx showLineNumbers title="src/App.tsx"
import { Button } from "@/components/ui/button"

function App() {
  return (
    <div className="flex min-h-svh flex-col items-center justify-center">
      <Button>کلیک کنید</Button>
    </div>
  )
}

export default App
```

</Steps>
