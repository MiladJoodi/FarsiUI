## نصب با CLI

ساده‌ترین راه برای راه‌اندازی FarsiUI استفاده از CLI است.

```bash
npx farsiui@latest init
```

با اجرای این دستور، تنظیمات اولیه FarsiUI در پروژه انجام می‌شود. سپس می‌توانید کامپوننت‌های موردنیاز خود را اضافه کنید.

## پروژه موجود

اگر از قبل یک پروژه React یا Next.js دارید، می‌توانید FarsiUI را به همان پروژه اضافه کنید.

```bash
npx farsiui@latest init
```

سپس کامپوننت‌های موردنیاز را اضافه کنید:

```bash
npx farsiui@latest add button
```
